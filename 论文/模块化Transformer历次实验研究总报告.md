# Transformer 层功能与模块化公共通信：历次实验研究总报告

**整理日期：2026 年 11 月 20 日**  
**范围：9 项独立研究实验，覆盖 GPT-2 层功能坐标、功能向量、功能特征提取，以及模块化 Transformer 至第七轮的实验。**  
**来源：用户提供的 Markdown 实验报告；《中文研究报告(2).md》与《中文研究报告(3).md》正文完全一致，合并计为一项。**
## 1. 总体结论

研究主线逐渐从“不同 Transformer 层能否用少量功能坐标表示”，转向“多个独立 Transformer 能否通过公共消息协作，并允许其中一个低成本独立升级”。截至第七轮，已经验证了同步公共通信、双向转发、数学可逆接口和冻结换装的工程可行性，但**尚未验证新 F1′ 经低成本独立训练后能够改善整个系统的预测质量**。

最有意义的诊断来自第七轮：将新 F1′ 发给其他模块的消息恢复为旧 F1 消息，平均可恢复约 **0.214 NLL**；仅恢复最终读出所接收的 F1 消息，只恢复约 **0.0175 NLL**。这说明接收方通信路径与换装性能退化密切相关，但不能据此直接断言问题一定来自某个特定模块、RealNVP 或补零操作。

## 2. 前期探索：层功能能否压缩或参数化

### 2.1 实验一：GPT-2 低维功能坐标

**研究目标：** 判断预训练 Transformer 不同层的残差更新，能否由少数真实基础层在相同输入上的更新，通过固定线性系数重建，并实际替换其他层。

**实验配置：** 冻结 GPT-2（12 层、隐藏 768），使用 WikiText-2；取第 1、6、11 个 Block 的输入作为共同探针，分别送入 12 个完整 Block；比较 K=1/2/3/4/6 个基础层的线性拟合。以 3 个随机初始化模型作对照，并进行未见文本重建与真实换层测试。

**实验成果：** 原始残差更新的前三个 SVD 方向覆盖 **91.6%** 测试能量，但各层等权归一化后只覆盖 **57.2%**。K=3 的非基础层测试宏平均 NMSE 为 **71.2%**，K=6 仍为 **60.2%**。联合替换非基础层时，K=3 导致 **NLL +3.349**，K=6 导致 **NLL +2.657**；相应调用 30/42 次 Block，原模型只需 12 次。

**主要发现：** 存在部分共同响应结构，但**低秩能量集中不等于可以准确替代各层的计算**。固定线性组合既未保住预测质量，也未降低计算次数。负结果针对本次线性函数族，不否定非线性功能表征的可能性。

**来源：**《中文实验报告(3).md》。

### 2.2 实验二：少量功能隐向量控制共享 Transformer

**研究目标：** 检验把 8 个不同层共享为同一 Transformer Block 后，能否靠每层少量隐向量 z（经 FiLM 调制）表示层功能，获得接近独立层的能力。

**实验配置：** TinyStories；8 层等深计算，隐藏 256、4 头、FFN 1024；比较 A（8 层独立）、B（完全共享）、C（1×16、1×32、2×16、4×16 功能向量）、D（同参数预算普通适配器）、E（等参数小型标准模型）、F（固定随机向量）。每模型 3 种子，各训练 1024 步、约 210 万目标 Token。

**实验成果：** 测试 PPL：A **38.39**，B **46.65**，C 约 **46.64**，D **46.47**。功能向量相对于完全共享，仅降低 **0.010%～0.032%** PPL，低于普通适配器约 **0.401%** 的相对收益。调制向量距离和功能响应距离的 Spearman 相关可达 **0.989**，但随机固定向量对照也约为 **0.989**。

**主要发现：** 权重共享能降低存储参数量，却不能减少仍然执行的 8 次计算。功能 z 确实能微弱地连续控制输出，但**没有证明它超越层编号或普通适配器，也没有形成有用的可解释功能坐标**。本次训练预算较短，不代表充分训练上限。

**来源：**《中文研究报告(2).md》《中文研究报告(3).md》（相同正文）。

### 2.3 实验三：从真实层行为提取功能特征 Z

**研究目标：** 不再直接假设每层有固定 z，而是训练特征提取器 E，从一组输入与层残差更新中提取 32 维 Z，供共享预测器预测该层在新输入上的更新；重点检验未见层泛化。

**实验配置：** 独立参数的 8 层 Transformer（隐藏 256）；TinyStories；3 个种子，每个 4096 步。比较 A（不使用 Z）、B（固定层 ID）、C（预测器 + Z）、D（预测器 + Z + 一致性/防坍缩）。每种子仅用 6 层监督，留出 2 层；主语言模型的训练轨迹在各组相同，辅助学习与主干梯度隔离。

**实验成果：** D 在已见层的残差预测 NMSE **0.3734**，优于无 Z 的 **0.3903**，但不优于层 ID 的 **0.3721**；在留出层，D 为 **1.3256**，无 Z 为 **1.2301**，零残差预测基线为 **1.0000**。D 同层跨输入 Z 余弦相似度约 **0.9936**，跨层约 **0.2545**。

**主要发现：** 提取器确实学到稳定、可区分的层标识相关信息，且预测器使用了 Z；但**留出层预测比不预测残差还差**，没有证据支持可跨层泛化的功能表征。一致性损失没有解决这一问题。

**来源：**《中文研究报告(4).md》。

## 3. 模块化 Transformer：从有序路由到同步公共消息

### 3.1 实验四：原第二阶段——串行、双 MLP、软路由和硬路由

**研究目标：** 检验每层独立入口/出口 MLP 与可学习 Router，能否建立新通信路径、动态跳过模块，并改善质量—计算权衡。

**实验配置：** 4 个独立 Block，隐藏 256、4 头、FFN 1024；公共空间 256 维，8 个残差 MLP 接口 256→128→256。TinyStories，3 种子、合计 4096 步。A 为标准串行，B 为串行+双 MLP，C 为前向有序软 Router，D 为 REINFORCE 硬 Router；另有固定 2/3 模块对照 S2/S3。

**实验成果：** 测试 PPL 分别为 A **19.914**、B **19.939**、C **20.044**、D **20.471**。C 阻断全部非相邻边，NLL 增加约 **0.0364**，证明网络在用部分新连接；但 D 的确定性策略平均仍执行 **4.0** 个 Block，实际跳过比例为 **0%**。逐接口干预的主要效果集中在 F1 入口。

**主要发现：** 学到了部分有效软通信，但**没有证明统一公共语言，也没有获得动态跳层收益**。更重要的是，这一版仍然按编号前向流动，属于有序链式架构，**不能视为之后无固定顺序公共网络的实验结果**。

**来源：**《中文研究报告(5).md》。

### 3.2 实验五：修正版第三轮——四个平级模块的同步公共消息

**研究目标：** 纠正上一版的固定顺序限制，验证四模块平级、任意方向读取、同轮快照、跨轮反馈、广播和多源融合的真实可执行性。

**实验配置：** 仍是 4 个独立 256 维单 Block；公共空间 256 维，每模块独立入口 D_i / 出口 E_i；同轮读取上轮快照、计算后统一提交。比较 A（串行）、B（双 MLP 串行）、C4/C2（可学习公共网络，4/2 轮）、D4/D2（固定公共网络，4/2 轮）。3 种子，各 **256 步**短程训练，属于验证阶段而非正式收敛性能对比。

**实验成果：** 14 项 CPU 结构测试及真实 MPS 测试通过；C4 每序列实际执行 **16** 次 Block，验证 PPL **84.766**，D4 为 **88.346**，串行 A 为 **80.735**。C4 阻断全部跨模块边，NLL 增加约 **1.600**；阻断全部逆编号边增加约 **0.0467**，说明通信路径实际被使用。

**主要发现：** **无固定顺序、双向跨轮通信的计算图真正成立**；但小规模测试质量未胜串行，而且 4 轮执行 16 次 Block，不能以“并行可调度”冒充已经获得实际加速。

**来源：**《中文研究报告(6).md》。

### 3.3 实验六：第四轮——公共翻译和功能分工

**研究目标：** 验证回译一致性、轻度通信遮蔽、按实际贡献竞争路由及弱稳态约束，能否使模块形成稳定公共语言和有差异的功能组织。

**实验配置：** 继承四模块、四轮同步通信、256 维公共空间、独立残差接口；TinyStories，3 种子，每组 4096 步。A 仅语言模型损失；B 加公共回译约束；C 加功能组织目标；D 两者都加。所有 Block 和接口共同优化，不冻结。

**实验成果：** 测试 PPL：A **14.682**、B **14.936**、C **14.685**、D **14.936**。D 相对 A 的 NLL 增加约 **0.0172**。回译机制没有稳定提高出口的任务贡献；功能组织项没有一致形成更清晰的任务分工，弱稳态保护条件在本轮未触发。

**主要发现：** **回译精确、参数收到梯度、Router 有变化，都不能单独证明公共语义或功能分化。** 训练目标可能被简单复制或保持冗余等方式满足；任务效果必须通过固定策略的内容替换、阻断及换装测试验证。

**来源：**《中文研究报告(7).md》。

## 4. 可逆公共协议与独立升级

### 4.1 实验七：第五轮——B/C/D 翻译接口与模块替换

**研究目标：** 用具有明确数学关系的入口/出口替代普通双 MLP，比较正交、可逆流补零和学习补维；检验冻结其他模块后能否只升级 F1。

**实验配置：** 4 个独立 256 维 Block，公共消息维度扩到 **512**，仍为四轮同步网络；3 种子，每组从头训练 4096 步。A：独立线性；B：入口行正交、出口转置；C：4 层 RealNVP + 固定零补维；D：RealNVP + 学习补维；E/E_LM：独立双 MLP 的附加对照。换装 R1 只更新 F1、冻结接口；R2 更新 F1 及其接口；R3 全模型更新；R4 为 LoRA 对照。R1/R2 仍需完整运行其他冻结模块参与训练。

**实验成果：** 原模型测试 PPL：B **15.7268**、C **15.4140**、D **15.4513**，C 最低。C 的私有向量往返归一化平方误差约 **1.56×10⁻¹²**。C 组换装新任务 NLL 改善：R1 **0.0199**、R2 **0.0206**、R3 **0.0547**；R1/R2/R3 训练开销分别为 **240.8 / 248.2 / 339.9 TFLOPs**。B、D 的 R1/R2 也均有正向改善。

**主要发现：** 证明了**冻结其他模块参数、局部更新 F1 并改善整机任务**可以做到，但训练仍执行完整系统，计算开销没有显著降低。R1 与 R2 收益接近，说明更新接口并非获得局部收益的必要条件。C 的原始建模质量最好，但**数学互逆不等于跨模块语义相容，更不等于独立离线换装成功**；补零是否阻碍升级尚无直接证明。

**来源：**《中文研究报告_五组汇总.md》。

### 4.2 实验八：第六轮——低计算量独立 F1′、辅助读出与半层 IG

**研究目标：** 通过缓存真实公共消息，只训练 F1′ 及局部接口，不在每步执行 F2–F4；探索半层 Attention 弱预测、完整 Block 强预测和 IG 是否改善低成本独立升级。

**实验配置：** 使用第五轮 C 组预训练基座；256 隐藏、512 公共消息、四轮同步通信。F1′ 从旧 F1 深拷贝初始化；离线缓存其他模块的消息；每种子训练 512 步，3 种子。P1 基础独立训练+辅助 LM 读出；P2 增加半层弱预测；P3 增加 IG/EMA；P4 冻结原翻译接口；P5 取消部分旧任务回放及兼容项，并有附加消融。正式装回系统后执行完整四轮。

**实验成果：** 原系统旧/新任务 NLL 为 **2.7353 / 3.2159**。P1 换装后 **2.9136 / 3.4214**；P3 为 **2.9297 / 3.4456**；P4 为 **2.9115 / 3.4304**，反而好于 P3。P3 总训练约 **32.79 TFLOPs**，只相当于第五轮 C 组 R3 的 **9.65%**（训练数据与计算协议不等价）。辅助头下 P3 完整层 NLL **3.7900**，半层 **4.4237**，但这不等于整机结果。

**主要发现：** **缓存训练成功降低 FLOPs，但独立 F1′ 换装失败**。冻结接口比联合更新接口损害更小，提示接口漂移值得研究。辅助头能预测得好，不等于冻结的其他模块能利用新消息。P3 对 P2 的微小差异还混杂 EMA 与 IG，不能证明 IG 本身有效或无效。

**来源：**《中文研究报告(8).md》。

### 4.3 实验九：第七轮——冻结原读出与消息换回诊断

**研究目标：** 检验第六轮失败是否主要由新训练的辅助预测头与原系统读出不一致造成；进一步分离 F1′ 消息的接收方路径与直接读出路径。

**实验配置：** 延续第五轮 C 组基座与第六轮缓存训练；A 为旧辅助读出+IG，B 为冻结原系统最终读出且不加 IG，C 为冻结原读出+IG。训练时每次只更新一个 F1 通信轮次的提案，使用缓存的末轮槽位，完整换装评价仍运行全部四轮。3 种子，另做同样本旧消息恢复干预。

**实验成果：** 换装新任务 NLL 相对原系统的恶化：A **+0.2297**、B **+0.2706**、C **+0.2699**；旧任务分别恶化 **+0.1944 / +0.1641 / +0.1636**。B/C 的训练 FLOPs 分别为 **23.39 / 32.07 TFLOPs**，即 R3 的 **6.88% / 9.43%**。IG 对 B 的新任务改善仅约 **0.00072 NLL**，3 种子置信区间包含零。对 P3 插件，把其他模块接收的 F1′ 新消息换回旧 F1 消息，平均可恢复 **0.2140 NLL**；只换最终读出接收的 F1 消息仅恢复 **0.0175 NLL**。

**主要发现：** **换成冻结原读出仍未解决低成本换装**。最大退化线索在其他模块消费 F1′ 消息的路径，而不是直接读出 F1 消息的路径。但这一干预合并了 F2/F3/F4 的影响，也混有跨轮状态与非线性交互；尚不能确定是哪一个接收模块、哪一层翻译器或哪一种编码机制导致失败。冻结读出下的半层/完整层预测并无稳定强弱差异，不能将此直接推广到 DiT 图像生成实验。

**来源：**《中文研究报告(9).md》。

## 5. 跨实验的确定性发现与尚未解决的问题

| 主题 | 已有证据支持 | 尚未得到证明 |
|---|---|---|
| 层功能压缩 | 不同层存在共同响应结构和部分可提取层特征 | 少量线性坐标可准确替代各层；Z 能泛化到未见层 |
| 公共网络 | 四模块同步、任意方向、跨轮广播、冻结换装的工程实现成立 | 比标准 Transformer 具有更好质量—计算权衡 |
| 统一语言 | B/C/D 可建立数学配对的编码接口；正常网络确实使用跨模块消息 | 共享 512 维空间等于形成通用、可迁移的公共语义协议 |
| 局部升级 | 第五轮完整系统反传时，更新 F1 可提升任务；冻结接口也有效 | 不频繁执行其他模块时，F1′ 仍能稳健提升整机 |
| IG | 已实现半层/完整层对照；第七轮差异收益很小 | IG 的独立因果收益、最佳系数或在 DiT 上的收益 |
| 退化定位 | 第七轮接收方消息恢复有明显效果 | 退化必然由补零、RealNVP、出口参数漂移或某个接收模块单独导致 |

## 6. 对下一轮工作的建议（研究判断，非既有实验结论）

1. **先完全移除 IG**，用相同基座、数据和评估协议研究普通 F1′ 独立升级，避免把两种科研问题混合。
2. **并行检查“独立出口 vs 四模块共享出口”与 B/C/D 接口**。共享出口必须在基座训练时共同学习；换装阶段若修改共享出口，会同时改变 F2–F4 的消息，违反仅替换 F1 的目标。应将共享出口冻结、训练私有适配器作为明确对照，而不是默认其有效。
3. **把“F1′ 真正更强”和“整机能使用 F1′”分开验证**。独立辅助预测 NLL 不能直接和整机 NLL 比较；新旧任务均需实测。
4. **先做低成本的接收路径诊断，不引入固定模块执行顺序**。分别替换 F1→F2/F3/F4 的消息，保留真实四轮同步语义，以确认退化位置。
5. **成本与泛化共同汇报**。按训练 Token、FLOPs、缓存开销和实际整机质量比较；旧任务回放与新任务泛化不可省略。缓存梯度或其他代理反馈都应视为尚未验证的新假设。

## 7. 来源与可比性说明

此总报告仅整理已有实验数据，不将主观机制推测写成实验事实。各报告中的 PPL、NLL、NMSE、重建误差以及训练 FLOPs 不能跨不同模型、数据划分、训练阶段直接排行；尤其是第五轮完整系统更新和第六、七轮缓存训练，训练样本暴露与执行图并不相同。上一版有序串行路由不是当前平级无序同步架构。第五轮的 B/C/D 是正交/可逆流接口组，第六、七轮的 B/C 是另一套消融编号，不能混淆。
