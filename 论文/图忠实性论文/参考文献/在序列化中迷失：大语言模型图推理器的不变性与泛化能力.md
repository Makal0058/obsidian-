# 一、研究背景（前人做到哪一步）
## 1.1 图归纳偏置与图神经网络

图神经网络（Graph Neural Networks，GNN）是当前处理图数据最主流的方法。

GNN 的一个核心归纳偏置：对**节点重新标记，也就是节点置换保持不变**。这种不变性能够保证模型依赖的是图的**同构类别**，而不是某种任意的图编码方式，因此有助于提升模型的泛化能力和样本效率。不过，对于计算复杂度可控的 GNN 而言，这种归纳偏置也会限制模型的表达能力。
## 1.2 大语言模型与图推理

现有方法大致可以分为两类：

- 将 LLM 与 GNN 结合起来的混合方法；
- 将图直接编码为文本，交给 LLM 处理的方法。

越来越多的研究开始关注**图推理**，即在图结构上进行推断。这些任务一方面可以代表**具有复杂依赖关系的推理问题**，另一方面也可以用于**检验 LLM 是否能够捕捉图的结构规律**，并突破传统 GNN 的某些表达能力限制。

- 早期研究发现，未经专门训练的通用 LLM 在图任务上的表现并不理想。于是，后续工作开始提出新的图推理基准和模型训练方法。

- Guo 等人在 2025 年提出了 G1。G1 以 Qwen 为基础模型，在经过人工整理的 Erdős 数据集上进行了两阶段微调：监督微调、强化学习微调。
## 1.3 对文本编码方式的敏感性

与 GNN 不同，LLM 并不天然具有对图同构变换和图序列化方式的不变性。

早期研究已经发现，LLM 的图推理表现会受到以下因素影响：使用边列表还是邻接表、节点采用什么名称或编号。后续研究进一步指出，边的排列顺序也会影响模型的表现。

# 二、创新点与贡献
## 2.1 提出图序列化的系统分解框架

作者把图序列化分解为三个变化维度：节点标记、边编码、语法格式。

提出一个统一框架，把以往零散研究的节点名称、边顺序、邻接表/边列表、JSON/代码格式等因素系统归类，用来评估模型对图表示对称变换的敏感性。
## 2.2 系统研究微调对不变性和泛化能力的影响

一项覆盖多模型、多任务、多种序列化因素的大规模系统**实证研究**，尤其考察图推理微调究竟增强还是削弱表示鲁棒性。

使用现有的 Erdős 基准，比较：

- 未经图任务微调的 Qwen
- 经过图任务微调的 G1
- 更大规模、未经专项微调的 gpt-oss

他们系统改变：节点编号、边编码与边顺序、文本语法格式，并测量模型输出与准确率的变化。
## 2.3 提出一套新的图谱推理任务

新增了 12 个谱图理论任务，用于测试模型能否泛化到训练时没有见过的、不同于传统组合图任务的新任务。

新测试集贡献：从路径、连通性、计数等组合任务，扩展到特征值、特征向量、热迹等谱图任务，从而检验微调模型是否获得了更一般的图推理能力。

# 三、实验与结论（数据说明了什么、有什么局限性）

1. 微调降低了模型对**节点重新标记**的敏感性，但这主要可能来自总体准确率提升，而不是真正获得了普遍的置换不变性。

2. 微调反而**可能增加**模型对**边内部顺序**和**文本格式**的敏感性，说明专用模型可能过度适应训练时的序列化模板。

3. 图任务微调不能稳定提高未见任务上的泛化能力。

4. 更大的未经专项微调的模型，整体上对节点编号、边顺序和语法格式更加鲁棒，但计算成本更高。
