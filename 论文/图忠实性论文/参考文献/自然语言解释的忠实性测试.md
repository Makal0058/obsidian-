# 一、研究背景（前人做到哪一步）
## 1.1 针对显著性图的忠实性测试

显著性图会**为输入中的各个部分分配重要性分数**。例如，在文本分类任务中，显著性图可以为每个单词分配一个分数，表示该词对模型预测的重要程度。
### 1.1.1 完备性与充分性

DeYoung 等人提出两个用于评价显著性图忠实性的指标：完备性（Comprehensiveness）、充分性（Sufficiency），通过删除输入中的不同词语，观察模型预测置信度或性能发生多大变化。

1. 完备性测试：**删除重要信息后，预测是否明显改变**。删除显著性图认为最重要的词。如果这些词确实是模型作出预测的重要依据，那么删除它们以后，模型的预测置信度或性能应当明显下降。
2. 充分性测试：**只保留重要信息后，预测是否仍然成立**。只保留显著性图认为最重要的词，删除其他输入内容。如果这些词足以支持原预测，那么仅保留这些词后，模型仍应给出相同答案。
### 1.1.2 ROAR

Madsen 等人提出了另一种显著性图忠实性指标 ROAR。

基本过程：根据解释方法找出所谓的重要词 $\to$ 将这些词从训练数据中遮蔽 $\to$ 使用遮蔽后的训练数据重新训练模型 $\to$ 观察重新训练后的模型性能下降多少

- 重新训练是为了降低简单删除词语所造成的分布偏移。

如果被遮蔽的内容确实包含重要信息，那么即使模型在修改后的数据上重新训练，其**性能仍应明显下降**。
### 1.1.3 对抗性输入操纵

基本假设：模型预测应当对**显著性图标记的重要区域**更加敏感。**修改这个词**，应当比修改一个低重要性词**更容易改变模型预测**。如果模型反而对低重要性词更加敏感，就说明显著性图未必准确反映模型的预测行为。
### 1.1.4 显著性图可能被操纵

已有研究发现，显著性图可能被人为操纵，从而掩盖模型对某些数据属性的依赖，例如：性别偏见、种族偏见、其他敏感属性偏见。模型可能实际上**利用敏感属性**作出预测，但解释方法生成的显著性图却突出其他无关因素，使模型看起来更加公平。
## 1.2 为什么显著性图测试不能直接用于自然语言解释

显著性图和输入之间通常存在一一对应关系：$\text{输入词}\leftrightarrow\text{显著性分数}$。例如：$\text{输入词 movie}\leftrightarrow\text{重要性 0.1}$、$\text{输入词 excellent}\leftrightarrow\text{重要性 0.9}$。但自然语言解释不存在这种严格的一一对应关系，可能包含原输入中没有出现的概念、推论或抽象表达。例如，输入为：一名男子正在跑步。解释可能为：他可能正在参加体育活动。其中体育活动并没有直接出现在原输入中，而是模型根据输入生成的抽象概念。因此，针对显著性图设计的诊断方法不能直接应用于自由文本形式的自然语言解释。
## 1.3 针对自然语言解释的研究

### 1.3.1 过去研究主要关注合理性

**解释在人类看来合理，并不能证明解释反映了模型真实的决策过程**。

合理性（Plausibility）：解释在人类看来是否通顺、可信、容易理解并且符合常识。但合理性并不等于忠实性，模型可能生成一段在人看来非常合理的解释，但在作出预测时实际上并没有使用解释中的理由。例如，预测：这部电影是正面的、解释：因为演员的表演非常优秀。这段解释听起来很合理，但模型作出正面预测的真实原因可能只是看到了输入中的评分10/10。
### 1.3.2 自然语言解释能否帮助预测

Sun 等人研究了以下问题：人类生成或模型生成的自然语言解释所提供的额外上下文，是否能够像帮助人类一样帮助模型进行预测。但是解释能够提高预测性能，不等于解释忠实反映了原模型的决策过程。
### 1.3.3 可模拟性

Hase 等人提出从可模拟性（Simulatability）的角度评价自然语言解释的效用。核心问题：给定模型生成的解释，观察者能否预测出该模型将会给出什么答案？

观察者可以是：另一个机器学习模型、人类

例如，模型生成解释：因为前提中只有两个人，所以假设中的三个人与前提矛盾。观察者读完解释后，是否能够推测模型的答案为矛盾。如果观察者能够根据解释准确预测模型的输出，说明解释具有较高的可模拟性。

可模拟性主要衡量：解释是否包含足够的信息，使观察者能够预测模型的输出。不能直接证明：解释中的内容就是模型产生原答案时实际使用的内部依据。

# 二、创新点与贡献
## 2.1 提出反事实输入编辑测试

训练了一个编辑器，能够自动寻找使**模型预测发生指定变化**的输入插入内容。随后，作者检查模型生成的解释是否反映了这些导致预测变化的内容。因此，该测试可以用于构造模型预测发生变化的反事实样本，并检查解释是否同步反映变化原因。

研究问题：自然语言解释是否反映了导致模型产生反事实预测的原因？

判断逻辑：如果某项输入编辑导致模型改变预测，那么忠实的解释原则上应当反映这项编辑对预测的作用。如果解释完全忽略真正导致答案变化的内容，就说明解释可能只是在为新答案生成一个事后合理化的理由。
## 2.2 提出输入重构测试

作者**从模型生成的自然语言解释中提取理由**，并根据这些理由**重新构造输入**。随后，作者检查模型是否会在重构输入上维持原预测。该方法将一个较抽象的问题：解释中的理由是否足以支持模型的预测？转化为一个可以实际运行的模型测试：根据解释重构输入后，模型能否重现原答案？

核心问题：如果解释中陈述的理由确实足以支持模型的预测，那么根据这些理由构造出的输入，是否仍会使模型作出相同预测？

判断逻辑：如果模型解释中给出的理由确实是原预测的充分依据，那么仅保留或重构这些理由后，模型原则上应当维持原预测。相反，如果模型在重构输入上改变了答案，则可能说明：解释没有包含足够的预测依据；解释中陈述的理由并不是模型真正使用的信息；解释只是一个表面合理的事后说明。
## 2.3 系统测试多种模型设置

论文并未只研究单一模型，而是在：4 种自然语言解释模型、3 个自然语言解释数据集上系统应用两种测试。

# 三、实验与结论（数据说明了什么、有什么局限性）

四种自然语言解释模型都会生成大量无法通过忠实性测试的解释，而且没有哪一种模型结构能够稳定地比其他结构更忠实。
## 3.1 反事实测试发现了大量解释没跟上答案变化的情况

作者向输入中插入一些词，使模型预测发生变化，再检查新解释有没有提到这些词。结果显示：
- 训练得到的反事实编辑器最多能在约 **56.7%** 的样本上成功改变预测
- 在成功改变预测的样本中，很多新解释**没有提到插入内容**
- 将随机插入和编辑器插入的结果合并后，某些设置下最多能检测到约 **59.04%** 的样本存在这种问题
 
也就是说，模型可能因为某个新词改变了答案，但生成的解释仍在谈别的理由。不过，这个 59.04% 不能直接说成“模型总体有 59.04% 不忠实”，因为测试只能覆盖一种特定的不忠实现象。
## 3.2 输入重构测试说明：解释中说出的理由经常不足以支撑原答案

作者根据解释中的理由重新构造输入，再让模型预测。如果解释真的充分反映了决策依据，那么重构后应该保持原预测。但结果显示：

- e-SNLI 上约 **7.7%–9.7%** 的全部样本预测发生变化
- ComVE 上约 **22.7%–40.3%** 的样本预测发生变化

这说明**不少解释虽然听起来合理，但把其中的理由单独拿出来时，连模型自己不再支持原来的答案**。
## 3.3 两种测试发现的是不同问题

反事实测试和输入重构测试在不同数据集上的结果差异较大。

例如 ComVE（常识验证与解释）在输入重构测试中的不忠实率明显高于 e-SNLI（自然语言推理），但在反事实测试中差距没有那么突出。

e-SNLI：
前提：两名女性在酒吧喝酒。  
假设：三名女性在酒吧。
答案：contradiction，矛盾
解释：两名女性不是三名女性。
e-SNLI 检查：两句话之间是什么逻辑关系？为什么？

ComVE：每个样本给出两个句子
判断：哪一个句子违反常识，并生成解释。
句子 1：人饿的时候会吃东西。  
句子 2：人饿的时候只喝水，完全不吃东西。
原因：水不能完全满足人的饥饿。
ComVE 检查：哪句话不符合常识？为什么？
## 3.4 四种模型没有稳定的忠实性排名

MT-Re、MT-Ra、ST-Re、ST-Ra 实验没有发现稳定排序。所以，模型结构看起来更像“先推理再回答”，并不意味着解释真的更忠实。

- MT：Multi-Task，多任务联合模型。预测标签和生成解释由同一个联合模型完成
- ST：Single-Task，单任务分离模型。解释生成和任务预测由两个不同模型完成。
- Re：Reasoning，推理型。生成解释时，**不把预测标签作为条件**告诉解释模型。先根据输入形成解释，再预测答案。
- Ra：Rationalizing，合理化型。生成解释时，**将某个标签作为条件**提供给解释模型。已经有了答案，再生成支持这个答案的理由。
