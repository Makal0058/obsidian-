# 一、研究背景（前人做到哪一步）

## 1.1 核心矛盾：理论 vs 实证

前人工作分成两派，结论是冲突的：

- **理论派**：证明 **LLM 原则上能解图任务**
- **实证派**：实测**发现 LLM 经常失败**

这个 gap 就是本文的出发点

---
## 1.2 理论派做到哪一步

- Feng et al. (2024)：如果一个任务能拆解成子任务，LLM 就能解 → 等价于能模拟动态规划（DP）
- Wu et al. (2024)：把图上的 message-passing 转化成节点间的子任务，证明 **图连通性** 和 **最短路径** 都属于 LLM 可解的范畴
- de Luca & Fountoulakis (2024)：looped transformer 能模拟图算法的每一步
- Sanford et al. (2024a)：单层 transformer 就够做朴素的连通性判断

> [!note] 连通性可拆解 转移函数 $F(i,j) = \mathbb{1}_{k \in \mathcal{N}_{v_j}}(F(i-1,k) \cap F(k,j))$ → 可拆成子任务 → 理论上 LLM 可解

---
## 1.3 实证派做到哪一步

- **GPT4Graph** (Guo et al., 2023)、**NLGraph** (Wang et al., 2024a)：发现 LLM 在图任务上会失败

- **NLGraph**：评测了 8 个基础图任务，认为 LLM 有 _初步_ 图推理能力

- **GraphInstruct** (Luo et al., 2024)：扩展到 21 个经典图任务，提出 step masking 增强

- **VisionGraph** (Li et al., 2024)：多模态版本

---
## 1.4 前人的局限（本文要补的坑）

> [!warning] 关键缺陷 已有评测**主要只看图的规模（节点数）**，连通性类型覆盖**极其有限**，导致评测有偏

- 之前基本只测 1-hop、2-hop 连接 → 准确率虚高
- 忽略了 3/4/5-hop，以及不连通的几种情况（Singleton、Isolated Component、Asymmetric）
- baseline 数据集分布**不均衡**，掩盖了真实的失败模式

本文要做的：构造一个 **balanced & comprehensive** 的基准来重新评测

---
# 二、拟解决的问题（为什么现有方法不行）

本文不提新模型，而是**指出现有评测方法的根本缺陷**，并据此重新评测。核心问题有三层：

## 2.1 评测维度单一

只盯着**图规模**。现有工作（NLGraph、GraphInstruct）默认用**节点数**当难度标尺，认为"图越大越难"。但这掩盖了真正影响推理的因素。本文主张：除了图规模，**连通性类型**和**图描述方式**同样关键，甚至更关键

---
## 2.2 连通性类型覆盖不全

制造**虚高准确率**。前人主要测 1-hop、2-hop 这种短连接，得到的高准确率是"幸存者偏差"。一旦扩展到 3/4/5-hop，准确率明显下滑。更重要的是，"不连通"被笼统处理，其实该细分成三类，而 LLM 在它们上表现差异极大：

- **Singleton**：孤立单点
- **Isolated Component (IC)**：两节点分属不同连通分量
- **Asymmetric**：有向图里 A→B 通但 B→A 不通

> [!note]
> 一个有意思的"捷径"现象：Singleton 不受难度影响、永远答得好，说明 LLM 学到的是"描述里没提到的节点=孤立"这种偷懒规则，而非真正理解结构

## 2.3 baseline 数据集分布不均衡

**评测本身就有偏**。NLGraph 只有无向图；GraphInstruct 各连通类型样本数严重不均（见原文 Table 11）。分布一歪，平均准确率就失真，根本反映不出 LLM 在不同情形下的真实能力

**还有一个被忽视的盲点：LLM 是否真"懂"图结构？** 现有评测只看连通性答案对不对，不验证 LLM 给出的**推理路径**是否站得住。本文认为这正是漏洞——高准确率可能是蒙的。于是引出两个新指标（FidelityAcc、PCR）来戳穿"答案对但路径错"的幻觉

---
## 2.4总结

现有方法的问题不在模型，而在**评测得太粗**——维度单一、类型不全、分布失衡、只看答案不看过程，于是高估了 LLM 的图推理能力。本文要解决的就是"如何公平、全面地评测"这件事

---
# 三、创新点与贡献

本文的贡献都围绕"重新、公平地评测"这件事展开，可归为四点：
## 3.1 提出平衡且全面的连通性基准

针对前人"只看图规模、连通类型不全、分布失衡"的问题，构造了一个新数据集：

- 按节点数分 Easy / Medium / Hard 三档难度
- K-hop 从 1 到 5 每档各取 50 个样本，正负样本平衡（连通 / 不连通各 250）
- 系统覆盖四种连通类型：K-hop、Singleton、Isolated Component、Asymmetric
- 同时含无向图和有向图

---
## 3.2 设计两个新评测指标

戳穿**答案对、推理错"的幻觉**。不只看连通性答案对不对，还验证推理路径是否可信：

- **FidelityAcc (Facc)**：答案对**且**路径真实可达才算对 → 高 ACC 但低 Facc = LLM 在蒙
- **PCR (Path Consistency Ratio)**：路径长度 / 最短路径长度 → 衡量 LLM 是否倾向找更短的路

---
## 3.3 系统性地识别出影响图推理的关键因素

通过受控实验，把**什么让 LLM 在图任务上变难**拆解清楚，并从连通性扩展到最短路径、知识图谱实体连接等任务，验证结论的普适性。关键发现包括：

- 连通类型、图描述方式（Node List vs Edge List）、节点命名方式都显著影响表现，不只是图规模
- Node List 普遍优于 Edge List $搜索复杂度 O(N^2)\ vs\ O(N|E|)$
- 有意义的节点命名 + BFS/Dijkstra 提示能明显提升表现

---
## 3.4 探究训练数据、模型规模、微调的影响，并给出机制解释

- 从零训练不同规模的 GPT-2 做 K-hop 推理：准确率随**数据量**和**模型规模**同步提升（最终约 80%），证明架构本身有潜力，瓶颈在数据和参数

- 用 LoRA 微调 LLaMA3.2-3B，少量数据即见效

- 用 t-SNE 分析注意力层，揭示 LLM **不是直接抽取路径，而是依赖学到的"节点组合模式"**——这也解释了为什么把节点 ID 换成随机字符后准确率会掉

---
## 3.5 一句话概括

**本文的创新不在模型，而在"评测体系"**——用平衡基准 + 路径可信度指标，第一次把 LLM 图推理的真实能力和失败模式量化清楚，并从**训练/规模/注意力**三个角度给出了"为什么"的解释

---
# 四、方法与模型

本文没有提出新模型，"方法"指的是**整套评测框架**：三个任务、三种图描述、数据集构造、评测指标，外加用于机制分析的 GPT-2 训练
## 4.1 三种图描述方式（实验的基础变量）

同一张图用三种方式喂给 LLM，看它是否"换个说法就不认识了"：

- **邻接矩阵（Adjacency Matrix）**：$A \in \mathbb{R}^{N \times N}$，需 $N \times N$ 个 token，图一大就爆 → 只在小图、且只作翻译任务的目标格式
- **Node List**：以中心节点列邻居，如 "Node $v_i$ is connected to {邻居}"
- **Edge List**：逐条列边，如 "Node $v_i$ is connected to Node $v_j, \epsilon_{ij}$"

> [!note] 连通性和最短路径任务只用 Node List 和 Edge List。

---
## 4.2 三个评测任务

- **图描述翻译**：让 LLM 把一种描述转成另一种 → 检验它是否真懂结构（懂的话应与描述方式无关）
- **图连通性**：判断两点间是否有路径，并要求输出路径
- **最短路径**：在连通基础上还要算边权，更难

---
## 4.3 数据集构造（核心创新所在）

- 难度按节点数分 Easy / Medium / Hard
- 先穷举某节点数下所有图，再随机抽图和节点对
- K-hop（k=1..5）每档各 50 个连通样本
- 负样本：无向图取 200 IC + 50 Singleton；有向图取 100 连通 + 100 Asymmetric + 50 Singleton
- 目标：连通类型分布尽量均匀、正负样本平衡（各 250）

---
## 4.4 两个新指标

> [!important] FidelityAcc (Facc) $$\text{Facc} = \frac{1}{M}\sum_{i=1}^{M}(\hat{y}_i = y_i) \wedge (\hat{p}_i \in P)$$ 答案对**且**预测路径 $\hat{p}_i$ 属于可达路径集 $P$ 才算对。 高 ACC + 低 Facc = 在蒙

> [!important] Path Consistency Ratio (PCR) $$\text{PCR} = \frac{1}{M}\sum_{i=1}^{M}\frac{|p_i|}{|\hat{p}_i|}$$ 最短路长 / 预测路长，只在路径正确时计算，越接近 1 说明越会找短路
## 4.5 评测的模型

零样本、temperature = 0：

- **GPT-3**（gpt-3.5-turbo-0301）
- **GPT-4**（gpt-4-0125-preview）
- **LLaMA3.0-70B**

---
## 4.6 机制分析用的训练 / 微调（Section 5）

这部分才真正"训模型"，目的是解释能力来源，不是刷分：

- **从零训 GPT-2**（Baby 80M / Small 124M / Medium 350M 三档）做 K-hop 推理，21 万问答对，单卡 H100，lr 1e-4→1e-5，dropout 0.2 → 看数据量和模型规模的影响
- **LoRA 微调 LLaMA3.2-3B** 增强最短路径推理
- **t-SNE 分析**：对 GPT-2 各注意力层、各推理步的输出做聚类，给节点打特殊标签（源 `<S>`、目标 `<T>`、路径 `<PATH>i`、其他 `<O_N>` 等），观察 LLM 到底是"抽路径"还是"凑组合模式"

> [!summary] 一句话概括 方法 = 用"三描述 × 多连通类型 × 三难度"的平衡基准做受控实验，配 Facc / PCR 验证路径可信度，再用小规模 GPT-2 的训练和 t-SNE 反推能力来源。受测主力是 GPT-3/4 和 LLaMA3-70B，自训的只有 GPT-2 和微调的 LLaMA3.2-3B

# 五、实验与结论（数据说明了什么、有什么局限性）
## 5.1 图描述翻译（Table 1）—— LLM 并不真懂结构

- 只有当**源描述 = 目标描述**时准确率才高（复读机式）；一旦跨格式翻译就掉
- 例：Node→Node 几乎满分，但 Node→Edge、Edge→Node 明显下滑
- 图越大掉得越狠；预测邻接矩阵因输出 token 多，准确率最低
- 翻译本是简单任务却仍出错（漏边、加边）→ 归因为 **faithfulness hallucination**

> [!warning] 推论 连翻译这种不需要复杂推理的任务都会幻觉，更复杂的推理任务只会更糟

---
## 5.2 图连通性（Table 2 无向 / Table 3 有向）

- **GPT-4 全面最强**，不论难度、描述方式、连通类型
- **路径越长越难**：ACC 和 Facc 随 K-hop 增加而下降，IC（K=∞）最差
- **Singleton 永远答得好**，不受难度影响 → 暴露捷径：

> [!note] 捷径现象 "描述里没提到的节点 = 孤立" —— LLM 靠这条规则蒙对 Singleton，并非真懂。

- **Node List 普遍优于 Edge List**：搜索复杂度 $O(N^2)$ vs $O(N|E|)$
- **有向图整体更差**，尤其 Asymmetric：GPT-4 在 Hard 上 ACC 掉到 0.55 ≈ 随机猜
    - 呼应 **reversal curse**："A→B" 不等于 "B→A"
- LLM 不用固定策略：k 大时 Node 描述更好，IC 场景 Edge 描述更好 → 策略由输入上下文塑造

---
## 5.3 最短路径（Table 4）

- 趋势与连通性一致：路径越长越差，无向 > 有向
- **带权 vs 不带权差距显著** → LLM 倾向忽略/误读边权
- 加 **Dijkstra-CoT** 提示能明显提升（Table 12）

## 5.4 知识图谱实体连接（Table 5）—— 结论可迁移到真实应用

- K 越大越差、Node > Edge 的规律依旧成立
- **有意义的节点命名（Entity names）优于随机 ID** → 命名占用预训练空间
- **加入 BFS-CoT 提升最大**（Node 平均 ACC 0.77→0.85）

---
## 5.5 训练数据 / 模型规模 / 微调（Fig 4-5, 9）

- 从零训 GPT-2：测试 loss 随**数据量**和**模型规模**同步下降，最终准确率约 **80%** → 证明 transformer 架构本身有潜力，瓶颈在数据和参数
- Node List 比 Edge List 更稳（Edge 句子更长，达 400 字符，长上下文难处理）
- LoRA 微调 LLaMA3.2-3B：少量数据即见效

---
## 5.6 机制：LLM 到底怎么"推理"的（t-SNE, Fig 6）

> [!important] 核心机制发现 LLM **不是直接从句子抽取路径**，而是依赖学到的**节点组合模式（node combination patterns）**

- 最后一层会重组这些组合，识别源 / 目标 / 预测节点
- 这解释了为什么把节点 ID 换成随机字符后准确率会掉（破坏了学到的组合）
- Node List 与 Edge List 推理过程不同：
    - **Node List**：中间层先抓源/目标，再据此找路径模式
    - **Edge List**：跳过中间步，直接匹配源目标到组合模式

---
## 5.7 数据说明了什么

1. LLM 的图推理高分**部分是假象**——靠捷径和模式匹配，而非真正理解结构（Facc 揭穿）
2. 失败有**系统性规律**：路径越长、有向、带权、Edge 描述、随机命名 → 越差
3. 能力**可随数据和规模提升**，架构非瓶颈
4. 描述方式会改变 LLM 的**内部推理路径**，说明它没有统一的图算法策略

---
## 5.8 局限性

> [!caution] Limitation 算力有限，无法充分探索训练 / 微调 LLM 做图推理的**能力上界**

- 自训部分只到 GPT-2 和 LLaMA3.2-3B，规模偏小
- 主力评测依赖闭源 API（GPT-3/4），可复现性和版本漂移存疑
- 任务局限于连通性、最短路径等基础图任务，未覆盖更复杂的图算法
