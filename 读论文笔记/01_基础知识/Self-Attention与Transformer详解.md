## 前置知识

### 向量与矩阵

现实中的东西要喂给模型，必须变成数字。一组数字排成一列叫**向量**：

$$x = \begin{bmatrix} 0.2 \\ 0.8 \\ -0.5 \end{bmatrix}$$

比如一帧音频，测了80个频率的能量，80个数排在一起，就是一个80维向量。

两个向量可以做**点积**：
$$a \cdot b = a_1 b_1 + a_2 b_2 + a_3 b_3$$

点积的核心性质：**方向越接近，点积越大**。方向相反为负，垂直为0。这个性质在Attention里直接用到。

### 线性变换

矩阵乘向量本质是：**把每个输出维度，定义为输入所有维度的加权求和**。

$$W \cdot x = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = \begin{bmatrix} 1x_1 + 2x_2 + 3x_3 \\ 4x_1 + 5x_2 + 6x_3 \end{bmatrix}$$

可以理解为：从一种"语言"翻译成另一种"语言"。矩阵里的数字就是模型要学的**参数（权重）**。

模型文件本质上就是一堆矩阵。7B模型就是这些矩阵里总共有70亿个数字，训练完参数固定，就是你下载的那个文件。

### 激活函数

纯线性叠多层没有意义，因为 $W_2(W_1 x) = (W_2 W_1)x$，可以合并成一个矩阵，深度消失了。

解决方案是加**非线性函数**，最常用的是ReLU：
$$\text{ReLU}(x) = \max(0, x)$$

正数保留，负数变0。插入后矩阵无法合并，深度有了实际意义。Transformer里用的是GELU，比ReLU平滑，但核心思想一样。

## 神经网络基础

### 前向传播

$$h = \text{ReLU}(Wx + b)$$

- $x$：输入向量
- $W$：权重矩阵
- $b$：偏置（加常数偏移，让模型更灵活）
- $h$：隐藏层表示

### 训练过程

1. 随机初始化参数
2. 前向传播算出输出
3. 用**损失函数**衡量输出有多错（越小越好）
4. **反向传播**：用链式法则从输出层往前算每层的梯度
5. **梯度下降**：$W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}$
6. 重复直到收敛

梯度告诉你每个参数往哪个方向调能让损失下降。学习率 $\eta$ 控制步长，太大震荡，太小收敛慢。

## 分词（Tokenization）

文字进模型之前先切成**Token**。主流方法是**BPE（字节对编码）**：

1. 从单个字符开始
2. 统计哪两个相邻字符最频繁出现
3. 把最频繁的组合合并成一个Token
4. 反复执行直到词表达到目标大小

"苹果"在中文里大量出现，就会被合并成一个Token。分词器是单独训练的，LLM训练和推理用同一个分词器。

---

## 词嵌入（Word Embedding）

每个Token对应一个向量，叫词嵌入。这个对应关系是训练出来的：

```
"我"   → [0.2, -0.5, 0.8, ...]  （512维）
"苹果" → [0.9,  0.1, -0.3, ...]
```

意思相近的词，向量方向也相近。词嵌入给每个词一个**静态向量**，不管上下文。

## Self-Attention（自注意力机制）

### 问题背景

词嵌入阶段"方便"只有一个固定向量，无法区分"这个工具很方便"和"我去方便一下"。需要让每个词能"看到"整个序列，根据上下文动态调整含义。

### Q K V 的设计

每个词的向量 $x_i$ 乘三个不同的矩阵，投影到三个不同的子空间：

$$Q_i = W^Q x_i \quad K_i = W^K x_i \quad V_i = W^V x_i$$

三个角色：
- **Q（Query，查询）**：我想找什么
- **K（Key，键）**：我能被匹配到什么
- **V（Value，值）**：我被匹配到后实际贡献的内容

类比搜索引擎：Q是搜索词，K是网页标签，V是网页实际内容。

**为什么K和V要分开**：K决定你能被找到，V决定被找到后给出什么。标题和内容可以不一样，模型更灵活。

**几何含义**：QKV的数字本身没有人类可读的含义，含义在它们之间的相对方向里——训练完后"我"的Q和"苹果"的K方向接近，说明"我"应该关注"苹果"。

### 计算过程

**第一步**：用 $Q_i$ 和所有 $K_j$ 做点积，得到相关性分数：

$$\text{score}(i,j) = \frac{Q_i \cdot K_j}{\sqrt{d_k}}$$

除以 $\sqrt{d_k}$ 的原因：若Q和K每个分量均值0方差1，点积的方差为 $d_k$，数值过大会让softmax饱和，梯度消失。除以 $\sqrt{d_k}$ 把方差归一化为1。

**第二步**：softmax归一化成概率（注意力权重）：

$$\alpha_{ij} = \text{softmax}(\text{score}(i,j))$$

**第三步**：加权求和V，得到新向量：

$$o_i = \sum_j \alpha_{ij} V_j$$

### 具体例子（数字演示）

句子"我喜欢苹果"，简化成3维向量：

```
"我"   → x1 = [1, 0, 0]
"喜欢" → x2 = [0, 1, 0]
"苹果" → x3 = [0, 0, 1]
```

假设 $W^Q = W^K = W^V$ = 单位矩阵（方便演示）：

"我"的Q1和所有K做点积：
- Q1·K1 = 1（我关注自己）
- Q1·K2 = 0（我关注喜欢）
- Q1·K3 = 0（我关注苹果）

真实训练后 $W^Q, W^K, W^V$ 不是单位矩阵，会让"我"的Q和"苹果"的K方向接近，点积更大，从而关注苹果。

### 公式总结

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

这个公式不是推导出来的，是**设计**出来的：
- $QK^T$：设计，点积衡量相关性
- $/ \sqrt{d_k}$：推导，方差控制
- softmax：设计，归一化成概率
- $\times V$：设计，加权求和

### Attention之后

经过Attention，"方便"在不同句子里的向量已经不一样了，上下文信息融进去了。词嵌入是静态向量，Attention把它变成**动态向量**。

## Multi-Head Attention（多头注意力）

### 为什么需要多头

单头只有一组 $W^Q, W^K, W^V$，只能学到一种关注模式，处理复杂句子时顾此失彼。

例："小明喜欢他的老师，因为他很耐心"
- 同时需要知道语法结构
- 同时需要知道"他"指谁
- 同时需要知道喜欢的原因

单头训练时这几种需求互相打架，最终学到一个四不像。

### 多头的做法

用 **h组不同的矩阵**，同时跑h次Attention：

$$\text{head}_i = \text{Attention}(QW_i^Q,\ KW_i^K,\ VW_i^V)$$

$$\text{MultiHead} = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

**线性代数视角**：每个头把x投影到不同的子空间，在那个子空间里独立找关系，最后把h个子空间的结果拼回来。不同的基"照亮"了输入的不同侧面。

**注意**：头1学语法、头2学指代这种说法是**事后解释**，实际上哪个头学什么是训练出来的，没人规定。

---

## 位置编码（Positional Encoding）

Attention计算只看向量内容，不看位置。"我打了他"和"他打了我"词一样，Attention结果完全一样，模型分不出区别。

解决方案：把位置信息直接加到词向量上：

$$\text{最终输入} = \text{词向量} + \text{位置向量}$$

原论文用正弦函数生成位置向量，性质是相对位置可从绝对位置推算出来。现在大多数模型用**可学习的位置编码**——直接作为参数训练，效果相当，更灵活。

## Transformer完整结构

### 编码器一层的流程

```
输入
 ↓
[Multi-Head Self-Attention]
 ↓
Add & Norm（残差 + LayerNorm）
 ↓
[Feed Forward Network（FFN）]
 ↓
Add & Norm
 ↓
输出
```

重复N层（原论文6层，GPT-3用96层）。

### Add & Norm

$$\text{输出} = \text{LayerNorm}(x + \text{Sublayer}(x))$$

**残差连接（+x）**：反向传播时梯度多了一条"+1"的直通路，不管乘多少层都不会消失。没有它，几十层网络根本训不起来。

**LayerNorm**：把每层输出归一化（均值0方差1），防止数值爆炸或消失，稳定训练过程。

### FFN（前馈网络）

$$\text{FFN}(x) = \text{ReLU}(xW_1 + b_1)W_2 + b_2$$

就是两层全连接（MLP）。每个位置用同一个FFN，但**独立计算**，位置之间没有交互。

**分工**：
- Attention：负责位置之间的信息交换（线性操作）
- FFN：负责每个位置内部的特征变换，引入非线性

可以理解为：Attention是开会收集信息，FFN是散会后自己消化吸收。经验上FFN存了大量事实性知识，参数量占模型大头。

### 完整信息流（以GPT为例）

```
输入文字
  ↓ 分词（查字典）
Token序列
  ↓ 词嵌入
向量序列
  ↓ + 位置编码
  ↓ N层 [Multi-Head Attention → Add&Norm → FFN → Add&Norm]
  ↓ 输出层（线性变换 + Softmax）
下一个Token的概率分布
  ↓ 选概率最高的词
  ↓ 把已生成的全部重新过一遍
  ↓ 循环直到结束
```

### 编码器 vs 解码器

| | 用途 | 代表模型 |
|---|---|---|
| 只用编码器 | 理解文本 | BERT |
| 只用解码器 | 生成文本 | GPT |
| 两个都用 | 翻译/摘要 | T5 |

解码器多了一个**Cross-Attention**：解码器当前状态作为Q，编码器输出作为K和V，实现"生成时参考输入"。

## 为什么Transformer能统治一切

| 问题 | 解决方案 |
|---|---|
| 长距离依赖 | Attention直接连任意两点 |
| 串行瓶颈（RNN必须逐步算） | 全并行，GPU利用率高 |
| 梯度消失 | 残差连接 |
| 训练不稳 | LayerNorm |
| 顺序信息丢失 | 位置编码 |
| 单一关注模式 | 多头注意力 |

理论深度不在"为什么有效"，在"为什么能scale"——Transformer的结构设计让它能撑住几千亿参数的规模，RNN做不到。

## 本质总结

Transformer是**工程师拼出来的**，不是科学家推导出来的：
- 残差连接：从ResNet借来的
- LayerNorm：之前就有
- Attention：之前就有
- 多头：试出来有效
- FFN：标准操作

没有一个零件是原创的，拼在一起效果好，然后scale上去更好。理论是后人的作业。

深度学习整个领域的气质：**工程先用着，理论留给后人**。
