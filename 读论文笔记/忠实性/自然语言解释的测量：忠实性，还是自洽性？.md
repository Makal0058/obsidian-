# 一、研究背景（前人做到哪一步）

现有工作通过修改输入、扰乱思维链或比较特征贡献来判断解释是否忠实，但这些方法都无法直接观察模型产生答案时真实发生的内部计算过程。现有所谓的忠实性测试，实际上测量的是不同形式的输出自洽性。

## 1.1 自然语言解释的忠实性定义

已有研究通常沿用 Jacovi 和 Goldberg（2020）的定义：忠实的自然语言解释，应当准确反映模型产生预测时真实使用的决策或推理过程。

- 合理性（plausibility）：解释在人类看来是否合理、是否容易理解。
- 忠实性（faithfulness）：解释是否真实对应模型产生答案时所使用的内部过程。

模型完全可能生成一段听起来非常合理的解释，但这段解释只是事后编造的，并不是模型真正得出答案的原因。
## 1.2 已有忠实性测量方法

### 1.2.1 反事实编辑

Atanasova 等人通过修改模型输入，构造反事实样本。如果**输入修改改变了模型答案，但解释没有提到被修改的内容，则该解释被视为不忠实**。

问题：

- 答案变化不一定是由被编辑的内容直接造成的。
- 编辑可能改变模型对其他输入部分的关注。
- 需要判断解释是否在语义上提到了修改内容。
- 通常需要针对具体数据集训练辅助模型。
### 1.2.2 根据解释重新构造输入

**从模型生成的解释中提取理由，并根据这些理由重新构造输入**。如果模型仅根据解释中提供的理由，**无法重现原来的答案**，那么该解释可能没有充分反映原始预测依据。

问题：

- 输入重构规则往往依赖特定任务。
- 很难推广到其他数据集或任务。
- 不同数据集上的实验结果差异较大。
- 重构失败可能来源于规则设计，而不一定说明解释不忠实。
### 1.2.3 噪声稳健性与特征重要性等价

Wiegreffe 等人提出了两个必要条件：答案和解释应当**对输入噪声表现出相似的稳健性**；对**答案重要的输入特征，也应当对解释生成重要**，反之亦然。核心思想：模型生成答案时依赖哪些输入，与模型生成解释时依赖哪些输入。

问题：
- 判断相似性的阈值较为宽松。
- 噪声类型和超参数的选择缺乏充分依据。
- 部分实验设计没有经过完整的消融验证。
### 1.2.4 偏置特征

Turpin 等人在提示中加入人为设计的偏置线索，例如：建议答案是 A、答案总是 A、与刻板印象相关的信息。如果**这些偏置线索改变了模型答案**，但**模型生成的思维链没有承认自己受到偏置影响**，则解释会被判定为不忠实。

问题：
- 无法确认模型是否将该输入识别为偏置。
- 不能要求模型说明一个它自己都没有识别出的影响因素。
- 需要人工或语义模型判断解释是否提到了偏置。
### 1.2.5 扰乱思维链

Lanham 等人通过修改思维链，观察最终答案是否发生变化。具体操作：截断思维链、在思维链中插入错误内容、改写思维链的前半部分、使用省略号等无意义内容替换思维链。判断逻辑：如果**思维链被严重修改**后，**模型答案仍然保持不变**，那么模型可能并未真正依赖这条思维链。

问题：模型忽略思维链，可能是因为思维链不忠实，也可能是因为模型仅根据原始问题就能够得出答案。

因此，这类测试无法区分以下两种情况：模型不依赖所生成的思维链；模型完成任务时根本不需要思维链。
## 1.3 提高忠实性的研究

另一类研究并不直接测量模型解释是否忠实，而是通过改变推理流程，使模型输出的结果更加可信。
## 1.4 可解释性方法

### 1.4.1 基于梯度的方法

基于梯度的方法根据输出相对于输入的梯度，估计不同输入特征的重要性。

问题：
- 容易受到对抗性输入的影响。
- 梯度中可能包含较强噪声。
- 局部梯度不一定能够准确反映全局贡献。
### 1.4.2 基于注意力的方法

基于注意力的方法使用注意力权重判断不同输入内容的重要性，但注意力是否等于解释仍存在较大争议：高注意力权重并不一定代表该输入对模型输出具有真正的因果贡献。
### 1.4.3 基于扰动的方法

基于扰动的方法通过遮蔽、删除或替换部分输入，观察模型输出如何变化。代表性方法包括：RISE、SHAP

# 二、创新点与贡献

## 2.1 重新界定现有忠实性测试的性质

论文首先提出了一个概念层面的核心主张：现有针对自然语言解释和思维链解释的**忠实性测试**，实际上并没有直接测量解释是否忠实于模型的内部推理过程，而主要测量模型在输出层面的**自洽性**。现有方法通常通过干预输入、解释或思维链，并观察答案与解释是否发生相应变化，这些实验能够说明模型不同输出之间是否保持一致，但不能直接证明：模型生成的解释真实反映了产生答案时使用的内部计算过程
## 2.2 提出新的细粒度自洽性指标 CC-SHAP

CC-SHAP（ConsistenCy measure based on SHAPley values）：基于 Shapley 值的一致性指标。分别计算两类输入贡献：每个输入词元对**模型预测答案**的贡献；每个输入词元对**模型生成解释**的贡献。随后，CC-SHAP 比较这两组词元贡献分布是否一致。基本思想：如果模型生成答案和生成解释时依赖相似的输入词元，那么**答案与解释之间具有较高的贡献一致性**。

假设输入包含 $n$ 个词元，答案和解释对应的 SHAP 贡献向量分别为：$\boldsymbol{\phi}^{A}=(\phi_1^{A},\phi_2^{A},\ldots,\phi_n^{A})$、$\boldsymbol{\phi}^{E}=(\phi_1^{E},\phi_2^{E},\ldots,\phi_n^{E})$。CC-SHAP 通过比较这两个贡献向量，衡量答案和解释对输入的依赖是否一致。

作者仍将 CC-SHAP 定位为：自洽性指标。原因在于，即使答案和解释表现出高度相似的输入贡献分布，也仍然不能直接证明自然语言解释完整地反映了模型内部真实发生的推理过程。因此，CC-SHAP 仍然不能直接测量内部忠实性，只是相较于单纯比较表面输出，更接近模型处理输入时的特征依赖过程。
## 2.3 构建比较一致性库 CCB

作者声称 CCB 是首次在统一实验条件下，对已有解释忠实性测试和自洽性测试进行系统比较的实验框架。将不同测试放入统一的模型、任务和实验条件中，从而使研究者能够进行更加直接的横向比较。

# 三、实验与结论（数据说明了什么、有什么局限性）

1. **现有针对事后自然语言解释和思维链自然语言解释的所谓忠实性测试，实际上并没有真正判断解释是否忠实**。原因在于，这些测试并不了解模型的内部运作过程，而只是将评估限制在模型输出层面的自洽性上。

2. 不同测试在同一模型和同一数据上，可能得出差异很大的结论。

3. CC-SHAP 比单纯比较表面输出更加细致，但它仍然只能测量自洽性。

4. 未来应当将答案与解释之间的关系作为分析单位，而不能脱离答案单独研究解释。
