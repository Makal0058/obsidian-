# 一、方法
1. **range()**
函数 range() 让 Python 从你指定的第一个值开始数，并在到达你指定的第二个值后停止，因此输出不包含第二个值。
```python
for value in range(1, 6):
    print(value)

>>>1
>>>2
>>>3
>>>4
>>>5
```
`range(开始, 结束, 步长)` 还能指定步长。
```python
even_numbers = list(range(2, 11, 2))
print(even_numbers)

>>>[2, 4, 6, 8, 10]
```
2. **list()**
`list()` 把“可以一个个取出元素的东西”转换成列表。
```python
numbers = list(range(1, 6))
print(numbers)

>>>[1, 2, 3, 4, 5]
```
