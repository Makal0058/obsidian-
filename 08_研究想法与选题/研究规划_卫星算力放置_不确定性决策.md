# 研究规划：面向卫星 Agent 的不确定性感知算力放置决策

> 起点：批判 Thummala & Falco "When to Compute in Space"（AIAA SciTech 2026）的静态 MCDM 方法
> 目标：两篇论文，第一篇（IEEE，给导师交差）→ 第二篇（ICLR 级，真正的方向）
> 状态：idea 阶段，地基实验未跑。本文件是路线图，不是结论。

---

## 0. 一句话命题

> 异构算力放置（星上/轨道/地面）本质是**信息不完整、容错代价高**的决策问题。现有方法（这篇）用确定性的多准则打分 + 对缺失信息的线性惩罚来处理，丢掉了"决策本身有多可信"这一关键维度。我们把效用从**点估计升级为分布**，用**风险敏感准则**选层，并进一步让 agent **主动决定是否补测信息**（VoI），在相同数据上系统性降低决策后悔值。

完整逻辑链（三步，一个东西的三个面）：
**估不确定性（效用分布）→ 用不确定性选层（风险敏感准则）→ 主动降低不确定性（VoI 补测）**

## 1. 靶子：这篇论文的真实缺陷（你打的就是这些）

定位：它是 baseline 和 motivation，不是敌人。它的框架（四层 FC/ODC/GSE/TDC、归一化、硬约束、加权和）全部继承，只升级它最弱的"确定性假设"。

| 缺陷 | 具体表现 | 你怎么打 |
|---|---|---|
| **点估计** | $U_{\text{eff}}(j)$ 是一个确定数，看不出可信度 | 升级为分布，带方差 |
| **缺数据只会扣分** | $U_{\text{eff}}=U_{\text{base}}-\lambda(1-\phi)$，封顶是 $U_{\text{base}}$，信息充分不加分 | 风险准则下"高确定性"自然占优 |
| **惩罚 ad hoc** | $\lambda$ 手设、线性、不区分缺哪个、不管缺了不确定性多大 | 分布化后缺失=高方差，$\lambda/\phi$ 被自然吸收 |
| **指标事后凑数** | 十几个指标无生成原则，多个标 optional/omitted | （ICLR 篇）指标/权重从任务推导 |
| **权重拍脑袋** | IDS 和 Suncatcher 两套权重无依据，结论对权重极敏感（IDS 差 0.003） | 做敏感性分析；权重可学习/可推导 |

**打靶的分寸**：不是"它有人为判断所以不好"（那 MCDM 全得枪毙），而是"它的人为判断**隐性、不可追溯、且结论对它高度敏感却未加分析**"。你的贡献是把这部分判断从"工程师私下拍"变成"显式 + 带不确定性量化 + 可做鲁棒性检验"。不假装能消灭偏好，而是把它摆上台面做体检。

## 2. 第一篇（IEEE）：效用分布化 + 风险敏感选层

定位：最轻、最快、单步、不涉及 LLM/序贯/强化学习。纯计算实验，一两周能出主结果。够交差、够发、且严格是第二篇的特例和组件。

### 2.1 方法（三步）

**第 1 步 — 指标从"值"变"分布"**
- 已知但有噪声的指标：以观测值为均值、按测量精度（或 ±10% 相对误差）定方差
- 缺失指标：给宽先验分布（高方差），用同类系统历史范围/物理边界定 —— **缺失 = 宽分布，不是被扣掉的常数**
- 第一篇**不上 LLM**，纯规则/先验造分布。更稳、更好交差。

**第 2 步 — 蒙特卡洛传播成效用分布**
- $U=\sum w_i s_i$，每个 $s_i$ 现在是随机变量 → $U$ 是随机变量
- 从每个指标分布采样 $N$≈1000 次 → 每层得到 $N$ 个效用样本 → 经验分布 → 取均值 $\mu(j)$、标准差 $\sigma(j)$
- 几十行代码，无需解析式
- **关键**：缺指标多/噪声大 → $\sigma$ 自然大 → 原文的 $\phi$ 惩罚被自然吸收，不用再拍 $\lambda$

**第 3 步 — 风险敏感选层**
$$j^\star = \arg\max_j \big[\mu(j) - \kappa\,\sigma(j)\big]$$
- $\kappa=0$ 退化成只看均值（≈原文）；$\kappa>0$ 时"均值略低但很确定"反超"均值略高但全是猜"
- 这就是"有把握加分、不确定扣分"，是均值-方差准则的自然结果，不是贴上去的 ad hoc 项
- 硬约束层（延迟/成功率/成本越界=出局）完全照搬原文，不动

### 2.2 数据

不需要真实卫星数据（这篇的数据也全是 hypothetical，表3 自标）。这反而给了干净的对照基础：
- **直接复用这篇的 IDS、Suncatcher 指标表作为"真值"** —— 同一套数据，对比才公平，reviewer 无话可说
- 在真值上**程序化注入不确定性**：加噪声、随机遮蔽部分指标（模拟缺失），生成大量带不确定性的场景（如 500 个）
- 因为有真值，可算出每个场景的**真正最优层**（完整无噪声数据 argmax）= ground truth
- 答案：以这篇 hypothetical 表为种子，程序化生成带噪声/缺失的场景集。零采集成本，一台笔记本搞定。

### 2.3 实验（三组）

1. **主实验 — 你 vs 原方法的决策质量**：500 个带噪声/缺失场景，两种方法各自选层，对比 ground truth，看**决策正确率**和**后悔值 regret**。预期：信息不全时你选错更少、后悔更小。← 核心卖点
2. **鲁棒性/敏感性分析**：扫噪声水平 × 缺失比例，画"正确率随不确定性增加怎么变"。预期：原文迅速劣化，你的更平缓。← 核心图，专打原文"对权重敏感却不分析"
3. **$\kappa$ 的作用**：扫 $\kappa$ 从 0 到大，看决策从激进→保守的过渡，说明卫星高容错代价场景下适度 $\kappa>0$ 净收益为正

### 2.4 叙事结构

> 现有方法（引这篇）把异构计算放置建模成确定性多准则打分，对信息不全只做线性惩罚、对决策可信度不建模。我们指出在信息不完整、容错代价高的空间场景下这会导致系统性次优；我们提出效用分布化 + 风险敏感选层，在相同数据上显著降低决策后悔值，且自然统一了原方法手工设计的缺数据惩罚项。

### 2.5 第一篇的纪律（最重要）

**只做"点估计 → 分布 + 风险准则"这一步。** 别碰 LLM、别碰 VoI、别碰序贯——每一个都会让 scope 和风险翻倍。做出那张"随不确定性上升你的方法更稳"的图，就够了。

## 3. 第二篇（ICLR 级）：序贯 + 主动信息获取 + LLM 估分布

定位：第一篇的完整化。从 one-shot 升级为**带信息获取动作的、预算受限的序贯决策**。这才是配得上你兴趣的形态。

### 3.1 问题类型的真正变化（不是"静态换动态"那么轻）

准确说法：把 *one-shot 多准则打分* 重构成 *带信息获取动作的、预算受限的序贯决策*；**静态那篇只是这个序贯问题"不允许补测、只能用当前信息拍一次"的退化特例**。三层变化：
- **决策结构**：one-shot argmax → 序贯闭环（观察→要不要补测→获取→更新→再决策）
- **新动作维度**：原问题里 agent 只能"选哪层"；你新增一整类动作"**要不要花代价补测某缺失指标**"（VoI / active sensing 核心）
- **目标函数**：从"最大化效用"→"在观测预算约束下平衡决策质量与信息获取成本"

### 3.2 核心机制：Value of Information，不是元认知

agent 面对缺失关键指标，算的是：**补测代价 vs 可能的决策改善**。
> 如果拿到这个缺失指标的真值，决策会不会翻盘？翻盘收益值不值回补测成本？
- 无论该指标取何值最优选择都不变 → 无信息价值 → 别补，先跑
- 不同取值导致选不同层且选错代价大 → 高信息价值 → 必须补测

**不是看指标重不重要，是看它会不会改变这次决策。** 一个绝对重要但好坏都不影响选择的指标，照样不用补。

卫星场景让"补测代价"真实且有特色：重传=占稀缺下行带宽+等下一窗口（可能等一整圈 90 分钟）；重测=耗电/占机时/挤别的任务；"先跑"的代价=决策错则任务失败。agent 在**通信窗口 + 功率预算 + 时间紧迫**的真实约束下权衡。

### 3.3 守住边界：VoI（做）vs 元认知（先别碰）

判据：判断依据是**关于外部世界的不确定性**（缺失指标可能是什么、会不会改决策），还是**关于 agent 自己推理过程的不确定性**（我想得对不对、要不要重想）？
- 前者 = VoI / active sensing = **你该做的**，硬、可评测、有 baseline
- 后者 = meta-reasoning / 元认知 = **先别碰**，抽象难评测易变 demo

你所有推进（周期性、物理先验、补测代价、窗口）都指向前者——关于卫星这个外部系统，不是 agent 的脑子。能动性来自"动作空间变大 + 会算代价"，不是"会自我反思"。

### 3.4 LLM 在哪里进来（两处，都不是端到端决策器）

1. **估缺失指标的分布**：LLM 结合任务语境 + 物理约束，推断缺失指标可能落在什么范围。比纯规则先验更贴任务。
2. **指标/权重从任务推导**：LLM 读任务描述推断该看重什么 —— 偏好仍来自任务需求，但推导显式、可复现，替掉原文"工程师私下拍权重"。

**定位选择**：LLM 当"约束/权重/分布的解析器"（轻、易落地、对接 RAG），而非"端到端决策器"（重、需 reward/评测设计）。前者更稳、更易在毕业时间线内出东西。VoI 的硬骨架由决策论撑，LLM 只负责估分布这一块。

### 3.5 双层不确定性（卫星 agent 独有的贡献点）

UQ 方法（semantic entropy、STC、几何法）在你框架里的准确位置：**不是量"卫星指标的不确定性"（那是物理/先验给的），而是量"LLM 估这个指标时自己有多没把握"。**
- 第一层不确定性：卫星指标本身的噪声/缺失（物理先验给）
- 第二层不确定性：LLM 估这个指标时的可信度（UQ 方法量，如 semantic entropy 高=LLM 也没把握→放大该指标在效用分布里的方差）
- 两层叠加 = 最终效用方差的完整来源
- 地面 LLM UQ 文献没这层（他们没有外部物理层），是你场景独有，可写成清楚的贡献点

**术语纪律**：别说"用 semantic entropy 做元认知"（会被抓），准确说"用 UQ 量化 LLM 指标估计的可信度，作为效用不确定性的一个来源"。这些 UQ 方法是"测量仪"，停在测量、没进调控，全在安全区。

### 3.6 置信度投票的角色

confidence-weighted voting（CISC 那类）对**候选答案/决策**打分（不是对推理过程），属安全区。在你框架里：
- LLM 多次采样估缺失指标 → 采样离散程度 = 天然的方差估计，不用额外造模型
- 对"选哪层"做置信度投票：收敛=高把握（"有把握加分"的来源）；摇摆=该补测的信号（VoI 触发）
- 串起来：置信度投票既给"效用分布/确定性"估计来源，又给"该不该补测"触发信号，还给"有把握"的加分依据 —— 是工具，嵌进已搭好的框架，不是新方向
- **坑**：LLM 自报置信度有校准问题（常过度自信）。卫星高代价场景依赖它前，须验证校准（reliability diagram、ECE）或做后处理校准。这本身可作论文一个扎实实验点。
