## 语义三层（白话版）

| 层次 | 问的问题 | 白话类比 | 对应我的系统 |
|------|---------|---------|------------|
| **显著性** | 有没有必要说这句话？ | 门口摄像头：有人才录像，平时待机 | 遥测数据越阈值才采样+传输 |
| **含义** | 把这件事说清楚 | 把视频传给保安看 | 提取异常征兆的语义特征 |

> [!tip] 效用导向 = 我的系统设计哲学
> 不重建完整遥测数据，直接从征兆输出决策。Q&A知识库格式天然匹配效用层——存的是"征兆→处理动作"，不是"数据长什么样"。

## PCCAIP 框架

**感知→通信→计算→执行→反馈→感知** 的完整闭环：

```
传感器感知物理世界
        ↓ 显著性判断（要不要传）
语义提取 + 传输
        ↓
边缘服务器决策
        ↓
执行动作（改变物理世界）
        ↓
环境变化反馈回传感器（影响下一轮感知）
```

**海上救援例子**：UAV发现溺水者 → 只传"位置+紧急程度" → 地面站直接生成"派救援船到X坐标"指令 → 不需要传完整视频、不需要人工判断。

> [!tip] 我的系统是 PCCAIP 的具体实例
> 监控遥测（感知）→ 提取异常征兆（通信）→ RAG推理（计算）→ 执行预案（执行）→ 验证效果更新知识库（反馈）
> 写论文时可以明确说这是 PCCAIP 在卫星故障管理场景的实例化。

## 显著性指标体系（AoI 家族）

| 指标 | 衡量什么 | 白话 |
|------|---------|------|
| **AoI** | 信息新鲜度 | 信息多久了 |
| **AoII** | 发收双方状态同步程度 | 双方理解一致吗 |
| **UoI** | 紧迫性（考虑环境状态） | 同一事件在不同环境下紧迫性不同 |
| **GoT** | 三维张量，统一以上所有 | 最通用，可退化为上面任意一个 |

## 误报代价问题（重要的工程约束）

> [!warning] 误报在 SAGSIN 场景代价极高
> - 门口摄像头误报：保安走过去看，2分钟
> - 海上救援误报：救援船出动半天来回，油耗+人力+耽误真实救援
> - 卫星任务迁移误报：重新规划星座覆盖，连锁影响其他用户服务

现有系统的困境：阈值太低→误报多；阈值太高→漏报真实故障。

**我的解法**：两层设计 + 因果验证：
- 第一层：轻量检测，高阈值，宁可漏报轻微异常
- 第二层：因果验证阈值附近的模糊地带，确认因果链完整才触发高代价执行

这是论文 motivation 的核心段落。

## 💡 核心 Idea：多源因果链 + 地域自适应阈值

> [!tip] 方向一最完整的设计，把所有散落的idea串起来了

### 多源证据因果链验证

不是单一信号触发，而是多个证据能串成完整因果链才触发：

**海上类比**：
```
天气预报（暴风雨）+ 遥测（求救信号）+ 历史数据（深水区、常年风浪大）
        ↓
因果链：暴风雨 → 高浪 → 翻船概率上升 → 求救信号
因果链完整 + 区域高危 → 高置信度 → 触发救援
```

**对应卫星**：
```
太阳风暴预报（外部环境）+ 功率骤降+误码率异常（遥测）+ 历史故障模式（本地记忆）
        ↓
因果链：太阳风暴 → 辐射增强 → 电子元件异常 → 功率骤降
因果链完整 → 触发预案
```

**为什么比单阈值好**：单一信号可能误报，多源因果链同时成立的误报概率极低。

### 地域自适应动态阈值（RL学习）

RL根据每个区域的历史数据学出专属阈值：
- 低风险区域（低辐射轨道/平静海域）→ 阈值高
- 高风险区域（高辐射轨道/危险海域）→ 阈值低

**对比现有工作**：全局统一阈值，既有误报也有漏报。我的系统让 RL 自动学习区域最优阈值。

### 完整系统流程

```
多源信息输入（遥测 + 外部预报 + 区域历史特征）
        ↓
显著性判断（GoT指标 + RL动态阈值）
        ↓
多源因果链验证（有序Q&A检索 + 证据累积）
        ↓
置信度评估
  高 → 自动执行预案
  中 → 上报人工确认
  低 → 继续监控
        ↓
执行结果写回知识库（动态更新）
```

## 多模态问题和 Multi-Agent 的连接

SAGSIN 数据是多模态的（数值+文本+图像+时序），现有指标各管一块，没有统一度量。

→ 解法和 Multi-LLM 思路一样：每种模态一个专职模型计算本模态显著性分，一个汇总模型加权合并，RL 学习加权策略。

→ 又回到了方向二的 RL 触发机制。
