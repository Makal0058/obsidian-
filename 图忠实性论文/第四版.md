# 摘要（abstract）


下面这版已经纳入前面确认的口径：正式引入GIF、删除重复、明确E6支撑出度结论，并统一贡献三的结果变量。

# 1 引言

大语言模型已被广泛应用于多种图推理任务，例如知识图谱增强问答 [1]、图上搜索 [2] 和工具增强推理 [3]。这些任务具有一个共同前提：模型的回答应当受到输入图结构的约束。尽管关于模型忠实性的研究已经较为丰富 [4]，图推理忠实性仍面临一个特殊问题：大语言模型通常需要先将图序列化为文本。序列化必然为边和节点附加原图本身不包含的线性位置与排列属性，而模型是否会将这些表面属性用作非结构线索，则需要通过实验检验 [5,6]。

已有研究通过替换、打乱或扰动输入图，观察模型答案、准确率或答案概率是否相应变化，并将这种输出敏感性用作模型利用图信息或图解释忠实性的代理证据 [7]。另一类工作通过图上检索或搜索获得支持答案的路径，并利用这些路径辅助回答 [8]。然而，前一种信号可能受到序列化线索混淆：模型的答案虽然随反事实图改变，却可能只是分别抽取了两份文本中的显著末位节点。对于由图上检索或搜索产生的路径，其逐边合法性可以由检索过程保证；但当显式路径由模型直接生成时，路径能够导向答案，或者路径末节点与答案一致，并不能保证其中每一步都是输入图中的真实边。因此，答案对图干预敏感和生成路径与答案自洽，都不足以单独证明模型真正遵循了图结构。

在测量上，答案层诊断可以在任何要求报告最终答案的固定输出契约下计算，路径层诊断则只有在模型显式输出完整路径时才有定义。由于输出契约本身可能改变模型行为，且两层检验的结构属性不同，本文分别报告其结果，而不构造跨契约或跨层的统一忠实性分数。

为区分现象发现与解释检验，本文采用两阶段设计：主实验在多种拓扑、路径长度与输出契约上确定这些失败是否构成稳定的经验异常，随后以受控实验分别检验输出契约、末次同源竞争与不可满足状态下可用响应的影响。

具体而言，本文的贡献如下。

第一，本文发现，输出契约不是忠实性的被动测量窗口，而是会改变图推理行为的因果变量：在图结构、候选集合、问题表述与边序保持不变时，仅将答案输出改为路径—答案联合输出，DeepSeek 的准确率便由 2.4% 升至 85.6%。基于这一发现，本文提出 Graph-Intervention Faithfulness（GIF），一个以输出契约为条件的双层诊断框架：答案层检验反事实正确响应能否跨序列化控制保持，路径层通过逐边符号验证区分轨迹—答案自洽与图上合法性。两层估计不同的结构属性，本文分别报告其诊断缺口，而不构造跨契约或跨层的统一忠实性分数。

第二，本文识别出一种跨模型的末次竞争瓶颈：候选数相同的局部选择在长路径中并非同等困难，三个模型的条件失败风险均在最后一次同源终止竞争处达到最高。将完整长路径任务替换为从该位置开始的 oracle 局部任务后，同一选择明显改善，但该对照仅表明完整任务与局部任务之间存在可恢复差距，不被解释为对单一前缀机制的识别。另一项全路径等出度干预显示，最大的行为变化出现在竞争从无到有时，继续增加候选的影响明显减小。由此，本文将笼统的“长路径更难”具体化为末次竞争选择处集中暴露的结构性脆弱点，并揭示候选竞争具有显著的出现效应。

第三，本文发现，当给定前缀已使剩余长度要求无法通过合法转移完成时，模型倾向于维持可由当前输出直接检查的形式要求，而牺牲需与输入图逐项比对的边合法性。在该状态下，加重合法性措辞最多只使非法续写率下降 1.4 个百分点；而在允许显式退出动作的输出契约中，该率由 98.6%–100.0% 降至 0%–7.1%。这一变化是失败行为向显式退出或停止的重新分配，而非恢复合法完整路径。结果表明，不可满足状态下的失败处置不仅取决于规则的声明方式，还取决于输出契约提供了哪些可执行响应。
# 2. 相关工作
## 2.1 忠实性的参照对象与测量方法

在自然语言解释与 CoT 领域，已积累了大量大语言模型的忠实性研究。在概念界定上，早期研究 [4] 区分了合理性（plausibility）与忠实性（faithfulness），指出表面自洽不能替代独立的忠实性检验；Parcalabescu 与 Frank [9] 指出，仅比较可观察输出之间的一致关系，只能说明输出层面的自洽，而不能证明其忠实于模型内部计算。

在测量方法上，Turpin 等人 [10] 从模型解释中构造两类反事实预期：解释声称依赖的证据被改变时预测应相应改变；解释未提及的偏置信号被改变时预测应保持稳定；Breaking the Chain [11] 则编辑模型自生成的中间结构，检验答案是否随之更新，本文与其共享表面自洽不足这一诊断思路。二者都属于干预式诊断。RAGAS [12] 将生成回答分解为若干陈述，并逐项判断各陈述是否能够由检索上下文推出。

本文借鉴干预式诊断与逐项核验，但将答案层的参照对象由模型内部决策依据转为外部可验证的输入图。在路径层，本文进一步将语义支持关系替换为路径跳转与输入图边集合之间的确定性符号关系。
## 2.2 序列化线索与路径证据

图任务的特殊之处在于，图结构通常需要先被线性化为文本，而这一过程可能引入原图本身不包含的序列化线索。已有研究表明，在图结构不变的情况下，仅改变节点标号、边的排列或描述格式，模型预测就可能显著变化 [5]；图描述的呈现顺序同样影响模型表现 [6]。

路径层面，已有工作通过图上检索或搜索获得支持答案的路径，并由该过程事前保证其逐边合法性：RoG 通过关系路径规划与知识图谱检索获得具体路径 [8]，FiDeLiS 则在图上逐步搜索构造推理路径 [13]。这类方法区分了模型生成的轨迹与经图上检索或搜索得到的路径，而未将二者直接等同。G-Retriever [14] 则检索与问题相关的子图，为生成提供显式结构依据，并观察到缺少此类依据时，模型可能生成图中不存在的节点或边。
 
在 GCR 撤去图约束的案例中，可以观察到模型生成的路径终止于一个与同一输出中的答案字段不同的实体 [GCR]；对于答案与路径的联合评估，与本文最接近的工作是 Dai 等人 [15] 将答案正确与路径合法的合取作为更严格的成功判据，不同的是，本文的路径层检验不以答案正确为前提，因而在答案错误的样本上仍有定义。
## 2.3 输出契约与约束竞争

已有研究表明，无论是仅改变 prompt 的表面形式，还是改变模型必须遵守的输出规则，都会影响其行为。Sclar 等人 [16] 表明，在语义基本不变的情况下，仅改变分隔符、大小写等表层格式，也可能造成显著的性能差异；Tam 等人 [17] 则发现，将自由回答改为 JSON 等受约束输出，会显著改变模型在推理任务中的表现。这些结果说明，输出接口不仅规定回答形式，也会改变模型的生成义务。本文由此考察输出契约在忠实性测量中的双重角色。

在指令遵循方面，IFEval [18] 选取可由确定性程序检验的指令，以减少人工或模型裁判带来的主观性。本文采用相同的确定性程序核验，但不同于 IFEval 中仅凭响应文本即可判定的自足约束，本文对逐边合法性的判定必须将生成路径与当前实例的输入图逐跳比对。

关于多约束执行困难，ComplexBench [19] 考察多项约束的组合结构；Control Illusion [20] 则构造了彼此互斥且可程序验证的约束，并指定其中一项具有更高优先级，发现模型不能稳定服从该优先级，其选择还会受到约束类型偏好的影响。本文采用一种相近的实验设定：这些约束起初可以同时满足，只有当模型自身的生成决策使其进入特定状态后，才变得无法兼顾。本文仅在行为层面分析这种取舍。
# 3 问题定义与双层诊断

本文考察以序列化图文本为输入的图推理任务，并在其上定义两类假忠实性的诊断指标及其解释边界。实例生成的具体参数见附录 A.1。
## 3.1 任务与结构参照

给定有向图 $G=(V,E)$，其中 $E\subseteq V\times V$，以及起点 $v_0\in V$ 与规定跳数 $k$。从 $v_0$ 出发、沿 $E$ 中有向边恰好移动 $k$ 跳的节点序列称为合法 $k$-hop 路径，全体构成

$$
\mathcal{W}(G,v_0,k)=\left\{(v_0,\ldots,v_k)\mid (v_i,v_{i+1})\in E,\ 0\leq i<k\right\}.
$$

本文只保留满足 $|\mathcal{W}(G,v_0,k)|=1$ 的实例，唯一合法路径记为黄金路径 $p^{\ast}=(v_0,v_1^{\ast},\ldots,v_k^{\ast})$，其末节点 $y:=v_k^{\ast}$ 称为黄金答案。唯一性使结构参照完全确定：任何偏离 $p^{\ast}$ 的轨迹都不是合法解，无需在多条正确路径之间做归属判断。

图 $G$ 以边列表形式序列化为文本。对 $\alpha\in\left\{\mathrm{first},\mathrm{middle},\mathrm{last}\right\}$，令 $\sigma_\alpha(G)$ 表示将黄金终边 $(v_{k-1}^{\ast},v_k^{\ast})$ 分别置于边列表开头、中部与末尾的三种文本版本；其余边在各版本中独立随机排列。三者共享同一边集合，因此不改变 $G$ 及其唯一合法路径，但彼此之间的差异不限于黄金终边的位置。

此外设 $\mathrm{last\_decoy}$ 对照：在基础边集上追加诱饵边 $(y,z)$ 并置于末尾，其余边重新随机排列；诱饵节点 $z$ 在 $k+1$ 跳到达，违背恰好 $k$ 跳的任务要求。该条件同时改变了边集合与文本排列，因此不是同一图上的序列化变换。

本文以反事实图对 $(G_1,G_2)$ 为数据生成单位。两图共享起点、跳数、拓扑和生成参数，但黄金路径自第二跳起分离，并具有不同的黄金答案。该设计排除了始终提交同一节点的简单策略，并降低了偶然猜测同时通过两图检验的概率，却不能排除模型分别抽取两图中的显著序列化节点，因此仍需序列化控制。答案层以图对为统计单位，路径层以单个图文本任务为单位。

本文将模型被要求提交的输出结构称为输出契约，记为 $\pi$。`answer_only` 只要求报告最终答案；`path_basic` 与 `path_strict` 额外要求显式路径，二者的区别在于是否逐条声明结构要求；prompt 原文见附录 A.2。所有估计量均以契约 $\pi$ 为条件定义。
## 3.2 答案层诊断：序列化控制与忠实性缺口

在固定契约 $\pi$ 下，答案层诊断只使用模型报告的预测答案 $\hat y$；对路径契约，$\hat y$ 取其答案字段。

对第 $j$ 个反事实图对，若模型在序列化条件 $\alpha$ 下于两图上均输出各自的黄金答案，记 $C_\alpha^{(j)}=1$，否则为 $0$。由此定义三个成功信号：

$$
S_{\mathrm{last}}^{(j)}:=C_{\mathrm{last}}^{(j)},\qquad
S_{\mathrm{serial}}^{(j)}:=\prod_{\alpha\in\Sigma_{\mathrm{serial}}}C_\alpha^{(j)},\qquad
S_{\mathrm{full}}^{(j)}:=\prod_{\alpha\in\Sigma_{\mathrm{full}}}C_\alpha^{(j)}.
$$

其中

$$
\Sigma_{\mathrm{serial}}=\{\mathrm{first},\mathrm{middle},\mathrm{last}\},\qquad
\Sigma_{\mathrm{full}}=\Sigma_{\mathrm{serial}}\cup\{\mathrm{last\_decoy}\}.
$$

$S_{\mathrm{last}}$ 是本文对宽松表面信号的操作化：模型在基线序列化下，对反事实图对中的两张图均给出各自的黄金答案。它与已有工作常用的“答案随输入图干预而改变”这一判据相对应 [7]，但不是对其具体指标的直接复现。本文以 $\mathrm{last}$ 作为高敏感度基线——该条件有意使末位抽取策略足以产生表面正确的响应，从而检验这种响应能否在其他受控条件下保持。$S_{\mathrm{serial}}$ 要求该响应在三种共享同一边集合的序列化版本下同时成立；$S_{\mathrm{full}}$ 进一步要求它在追加末位诱饵边后仍然成立。

答案层的两个诊断缺口定义为基线信号与受控信号之差：

$$
\Delta_{\mathrm{serial}}^{(j)}=S_{\mathrm{last}}^{(j)}-S_{\mathrm{serial}}^{(j)},\qquad
\Delta_{\mathrm{full}}^{(j)}=S_{\mathrm{last}}^{(j)}-S_{\mathrm{full}}^{(j)}.
$$

数据集层面在当前固定契约下的 $N$ 个八格完整反事实图对上取均值，例如 $\Delta_{\mathrm{serial}}=\frac{1}{N}\sum_j\Delta_{\mathrm{serial}}^{(j)}$。统计推断以反事实图对为重采样单位。

$\Delta_{\mathrm{serial}}$ 衡量模型的反事实正确响应能否跨多种受控序列化保持。由于非黄金终边在三个版本中亦独立重排，本文不将该缺口单独归因于黄金终边的位置。$\Delta_{\mathrm{full}}$ 进一步纳入本文预设的诱饵条件，但 last_decoy 同时改变边集合与文本排列，因此新增缺口不解释为诱饵边的独立因果效应。两项指标仅表示模型是否通过本文实施的控制，而不排除其他未经检验的非结构策略。

由定义可得 $0\leq\Delta_{\mathrm{serial}}\leq\Delta_{\mathrm{full}}\leq S_{\mathrm{last}}$。因此，当 $S_{\mathrm{last}}$ 接近零时，两个缺口均受上界约束，较低的 $\Delta$ 不能用于判断序列化依赖是否存在。本文报告缺口时同步报告 $S_{\mathrm{last}}$，以支持联合解读。

为刻画诱饵条件下的具体失败形态，进一步定义终点锚定率

$$
\mathrm{EAR}^{(j)}=\frac{1}{2}\sum_{r=1}^{2}\mathbb{1}\!\left[\hat y_{r,\mathrm{last\_decoy}}^{(j)}=z_r^{(j)}\right].
$$

其中 $z_r^{(j)}$ 为第 $r$ 张图的末位诱饵节点，数据集层面取均值。$\mathrm{EAR}$ 描述模型在 $\mathrm{last\_decoy}$ 条件下选择末位诱饵节点的频率，但本文不将该频率解释为诱饵边本身的独立因果效应。
## 3.3 路径层诊断：符号验证与非法轨迹缺口

在路径契约下，模型除 $\hat y^{(j)}$ 外还提交显式路径 $\hat p^{(j)}=(\hat v_0^{(j)},\ldots,\hat v_{m_j}^{(j)})$。`answer_only` 不要求路径，路径层指标在该契约下无定义，相应单元格记为 N/A。对于未能解析出非空路径的输出，本文约定 $\mathrm{TAC}^{(j)}=\mathrm{PathValid}^{(j)}=0$；对于其余输出，轨迹—答案一致性定义为

$$
\mathrm{TAC}^{(j)}:=\mathbb{1}\!\left[\hat y^{(j)}=\hat v_{m_j}^{(j)}\right].
$$

$\mathrm{TAC}$ 只检验模型输出内部自洽。模型可以生成一条包含图外跳转的路径，再将其末节点报告为答案，此时 $\mathrm{TAC}=1$，但轨迹并不属于输入图。为检验结构合法性，本文以符号程序核验三项条件：

$$
\mathrm{PathValid}^{(j)}
:=
\mathbb{1}\!\left[
\hat v_0^{(j)}=v_0
\ \wedge\
m_j=k
\ \wedge\
\forall\,0\leq t<k,\
(\hat v_t^{(j)},\hat v_{t+1}^{(j)})\in E
\right].
$$

即起点正确、路径含 $k+1$ 个节点，且每对相邻节点均为图中真实有向边。该判定是确定性的，不依赖人工或模型裁判。

由 §3.1 的唯一性设定，$\mathrm{PathValid}^{(j)}=1\Longleftrightarrow\hat p^{(j)}=p^{\ast(j)}$。

路径层核心诊断量为

$$
\Delta_{\mathrm{illegal}}^{(j)}
=
\mathrm{TAC}^{(j)}\bigl(1-\mathrm{PathValid}^{(j)}\bigr).
$$

数据集层面，$\Delta_{\mathrm{illegal}}=\Pr(\mathrm{TAC}=1)-\Pr(\mathrm{TAC}=1\wedge\mathrm{PathValid}=1)$，即自洽但结构非法的轨迹所占比例。与答案层以反事实图对为单位不同，路径层指标以单个图文本任务为单位计算。

同样地，$0\leq\Delta_{\mathrm{illegal}}\leq\mathrm{TAC}$，故当 $\mathrm{TAC}$ 接近零时，$\Delta_{\mathrm{illegal}}$ 必然接近零，此时不能据此判断路径层结构失败是否较少。本文报告 $\Delta_{\mathrm{illegal}}$ 时同步报告 $\mathrm{TAC}$ 与 $\mathrm{PathValid}$。
## 3.4 两种测量边界

§3.2 与 §3.3 均以较弱行为信号与对应的更强检验之差构造诊断缺口。答案层检验反事实正确响应能否跨本文实施的序列化控制保持；路径层则检验生成轨迹是否满足输入图的起点、长度与逐边合法性。前者用于排除已测试的非结构线索，后者直接检查图上合法性，二者的证据强度并不相同。

所有诊断量均以输出契约 $\pi$ 为条件解释。输出契约可能改变模型的作答行为，因此不同契约下获得的描述性指标不能被视为对同一潜在状态的可互换读数。跨契约差异仅在契约被明确设为干预变量、其余条件保持配对一致时作因果解释。

即使在路径—答案联合契约下可以同时计算两层指标，路径层指标在 `answer_only` 下仍无定义，且两层的估计对象不同。本文因此分别报告两类缺口，而不构造跨契约或跨层的统一忠实性分数。
# 4 实验设计

本章说明各项结论的识别依据。核心指标见 §3，基础图实例的生成规则见附录 A.1。

## 4.1 总体识别策略

本文采用两阶段设计。第一阶段为主实验，用于确定答案层序列化失稳、末次竞争失败和终止状态后的非法续写是否构成跨模型、跨任务设置出现的经验异常，并刻画其规模与位置分布。第二阶段针对这些异常构造后续配对实验，分别检验输出契约、任务边界、同源候选竞争和不可满足状态下可用响应的影响。

不同实验的识别强度并不相同。E1 和 E2 直接操纵输出字段、约束声明或可用响应；E5 同时改变任务起点、有效搜索范围与终端窗口，因此被解释为诊断性边界对比；E6 和 E7 通过结构控制考察同源候选竞争，但分别作用于全路径决策点和最后一次竞争位置。本文逐项限定这些实验能够支持的结论，不将所有对比统一解释为单因素机制识别。

主实验异常、后续实验与三条贡献的对应关系如下。

| 主实验中的异常 | 后续检验及其作用 | 对应贡献 |
|---|---|---|
| 输出显式路径后，准确率与错误形态大幅改变 | E1：配对操纵输出字段 | 贡献一 |
| 条件失败风险集中于最后一次同源竞争选择 | E5：任务边界诊断；E6：全路径竞争结构重接；E7：末次位置 $D=2\to4$ 局部干预 | 贡献二 |
| 抵达零出度节点后，为补足长度而生成图外边 | E2：长度要求 × 合法性要求 × 退出动作 | 贡献三 |

这些实验并非全部使用独立于主实验的新图实例。E1 和 E2 复用主实验基础图并重新构造提示与模型调用；E5 的 F-task 单元复用既有完整任务输出，其他三个条件重新调用；E6 使用的 400 个样本中，前 200 个与对应主实验数据相同，后 200 个为扩展样本；E7 使用独立生成的图实例。因此，第二阶段应被理解为针对主实验异常的配对后续检验，而非严格意义上的独立复现。本文未预注册这些假设，也不将其表述为预先设定的确认性验证。

## 4.2 主实验

### 任务矩阵

主实验覆盖链式图和分叉图两类拓扑。链式图采用 $k\in\{3,4,5,6\}$，起点可达部分仅包含黄金路径，每个非终点黄金节点的出度为 1。分叉图采用 $k\in\{4,6,8,10,12\}$，其中 $v_0,\ldots,v_{k-2}$ 各有三个出邻居：一个黄金后继和两个零出度终止节点；$v_{k-1}$ 仅通过黄金终边连接答案 $v_k$。

两类图均包含 $2k$ 条与任务起点不连通的孤立干扰边。每个拓扑—跳数组合包含 200 个反事实图对，每张图生成四种文本版本：

$$
\left\{
\mathrm{endpoint\_first},
\mathrm{endpoint\_middle},
\mathrm{endpoint\_last},
\mathrm{decoy\_last}
\right\}.
$$

因此，每个拓扑—跳数组合产生

$$
200\times2\times4=1600
$$

个基础图文本任务。这里的 1600 表示每种输出契约可调用的基础任务数，不等于跨模型和输出契约汇总后的总调用数。

### 输出契约与实际覆盖

本文使用三种主要输出契约：

- $\mathrm{answer\_only}$，对应任务文件中的 `direct_minimal`，只提交答案；
- $\mathrm{path\_basic}$，对应 `jsoncot_basic`，提交路径与答案，但不逐条强调结构约束；
- $\mathrm{path\_strict}$，对应 `jsoncot_strict`，明确要求起点正确、路径长度正确、逐边合法且答案等于路径末节点。

主实验评估 DeepSeek-V4-Flash、Qwen-Max 和 GPT-5.4-mini。实际运行矩阵不是拓扑、跳数、契约与模型之间的完整笛卡尔积，覆盖情况如下。

| 输出契约 | DeepSeek-V4-Flash、Qwen-Max | GPT-5.4-mini |
|---|---|---|
| answer_only | 全部链式与分叉设置 | 全部链式与分叉设置 |
| path_basic | chain-4；branching-4/6/8/10/12 | branching-4/6/8/10 |
| path_strict | chain-4；branching-4/6/8/10/12 | branching-4/6/8/10/12 |

跨契约或跨模型汇总只在相应单元实际存在时进行；没有观测的单元记为 N/A，不以其他设置补齐。

### 主实验的识别作用

分叉图中 $v_0,\ldots,v_{k-2}$ 的局部出度均为 3。该设计排除了“某个位置仅因候选数量更多而失败”的直接解释，使不同位置上的条件失败风险可以在相同局部候选数下比较。因此，主实验能够定位失败风险是否集中于特定决策位置，而不只报告最终准确率随路径长度下降。

不过，等出度并不保证不同位置具有完全相同的理论失败风险，因为路径位置、已有前缀和剩余步数仍然不同。主实验因而承担现象定位与规模估计；任务边界、竞争结构和输出契约的具体作用由以下配对实验进一步检验。

## 4.3 后续配对实验

### E1：输出契约干预

E1 使用 branching-4hop 的 200 个反事实图对，并将其中的 $G_1/G_2$ 展开为 400 个图实例。在每个图实例上，只改变模型被要求提交的字段：$\mathrm{answer\_only}$ 只提交 `answer`；$\mathrm{path\_answer}$ 提交 `path` 与 `answer`，但不逐条声明严格结构要求。

$\mathrm{path\_answer}$ 在约束强度上对应主实验的 $\mathrm{path\_basic}$，但使用为 E1 配对设计单独生成的提示模板。E1 内部两个输出条件共享相同的问题正文，只改变输出说明与 schema。

图结构、问题表述、跳数和基础边序在两个输出条件间保持一致。实验同时交换起点 $v_0$ 处两条结构等价终止边的相对文本次序，形成

$$
2\text{（输出契约）}\times2\text{（终止边顺序）}
$$

的配对设计，每格 400 个图实例。该实验用于估计输出契约对答案准确率、起始分支选择和位置偏好的因果影响，而不是把不同契约下的描述性诊断量视为同一忠实性状态的重复测量。

### E5：任务边界的 $2\times2$ 诊断

E5 以 branching-8hop 为基础，围绕最后一次竞争位置 $v_{k-2}$ 构造四个条件：

| 条件 | 起点 | 终端窗口 |
|---|---|---|
| F-task | 原始起点 $v_0$ | 原始窗口 |
| R-task | 原始起点 $v_0$ | 替换后的延展窗口 |
| O-local | $v_{k-2}$ | 原始窗口 |
| O-full | $v_{k-2}$ | 替换后的延展窗口 |

F-task 为完整长路径基线；R-task 保留完整前段任务，但以延展链替换原始终端窗口；O-local 和 O-full 直接从 $v_{k-2}$ 开始，分别对应原始窗口与替换窗口。四格在样本身份和局部候选窗口上配对，共包含 400 个基础样本，每个样本具有四种序列化版本。

E5 分别报告三类诊断量：沿黄金前缀抵达 $v_{k-2}$ 的概率 $q_{\mathrm{reach}}$、条件于抵达后选择黄金后继的概率 $p_{\mathrm{cond}}$，以及二者的联合成功率

$$
p=q_{\mathrm{reach}}p_{\mathrm{cond}}.
$$

对于直接从 $v_{k-2}$ 开始的 O 系列任务，抵达条件由任务边界保证。

贡献二主要使用原始终端窗口下的边界对比 $O\text{-local}-F$。该对比以全样本联合成功率 $p$ 为结果变量：F-task 中未抵达 $v_{k-2}$ 的样本记为 0，O-local 则直接从该位置开始。因此，它衡量完整任务与局部边界任务之间的总体可恢复差距，不被解释为条件于抵达后的纯局部选择效应。

平行对比 $O\text{-full}-R$ 检验该差距在替换终端窗口后是否仍然存在；条件于抵达的局部选择率，以及 $R-F$、$O\text{-full}-O\text{-local}$ 和交互项，作为终端窗口效应与模型异质性的辅助诊断，不承担贡献二的核心识别，完整结果见附录。

E5 不是严格的单因素因果消融。O 系列条件在移除前段生成过程的同时，也改变了起点、输入分布、上下文长度和有效搜索范围；R 系列则改变了后续任务结构。因此，E5 结果仅被解释为任务边界上的诊断性恢复，不被解释为对“前缀状态维护”或“终端约束”单一内部机制的识别。

### E6：全路径竞争结构扫描

E6 使用 branching-6hop 的 400 个 $G_1$ 样本，同时改变黄金路径上所有可竞争决策点的出度：

$$
d\in\{1,2,3,4,5\}.
$$

$d=1$ 时只保留黄金后继；$d>1$ 时，在每个决策点加入 $d-1$ 个同源零出度终止候选。路径契约在全部五个出度条件上运行，答案契约运行 $d\in\{1,3,5\}$。每个可运行单元包含 400 个样本。

不同出度条件保持黄金路径与总边行数不变。对于较低出度，多余终止边被改接到与起点不连通的新源节点；对于较高出度，增加同源终止边并相应减少背景干扰边。全部条件采用与样本绑定的确定性排序规则。

该操作在保持总边数不变的同时，也改变了断连边的数量、路径节点在文本中的出现频次和局部可达结构。因此，E6 识别的是一次完整的结构转换，本文将其称为保持总边数不变的竞争结构重接效应，不解释为纯候选数量效应。相应地，$d=1\to2$ 的对比支持任务从无局部竞争转变为存在局部竞争时发生显著行为变化，不支持“单独增加一个候选的纯效应”这一更强表述。

此外，出度是在全部竞争决策点上同时变化的，因此 E6 不能把 $d=1\to2$ 的效应单独归因于 $v_{k-2}$。E6 提供竞争结构出现的全路径证据，末次位置上的局部响应由 E7 刻画。

### E7：末次位置的同源竞争

E7 在独立生成的 4、6 和 8-hop 图上，只改变最后一次竞争位置 $v_{k-2}$ 的同源候选数，其余路径结构保持不变。每个跳数包含 400 个基础样本。

路径层 $G_1$ 在 $\mathrm{path\_basic}$ 和 $\mathrm{path\_strict}$ 下运行

$$
D\in\{2,3,4\},
$$

用于刻画竞争已经存在后，最后一次竞争位置随候选数量变化的局部响应。答案层 $G_2/G_3$ 则用于比较加入同源竞争前后的末位锚定行为。

当前 E7 路径层没有与 $D=2,3,4$ 同契约的 $D=1$ 基线：$D=1$ 仅存在于答案接口的 $G_3$。因此，E7 不能独立识别路径层最后一次竞争位置上的 $D=1\to2$ 效应，也不能与不同接口下的 $D=1$ 结果拼接。贡献二中关于竞争结构从无到有的证据来自 E6；E7 只负责刻画末次位置在 $D=2\to4$ 范围内的局部响应。

### E2：不可满足状态下的可用响应

E2 将 branching-12hop 的 200 个反事实图对展开为 400 个合格单图实例，并全部纳入实验。模型被给定固定前缀

$$
\tilde p=(v_0,\ldots,v_{k-2},u^0),
$$

其中 $u^0$ 是通过图中合法边抵达的零出度终止节点。模型在该状态下已无法同时满足“补足规定长度”和“每一步均为图中合法边”。

在图、边序、固定前缀与终止分支身份保持不变时，实验交叉操纵三个因素：

1. 是否要求恰好完成规定长度；
2. 是否明确要求逐边合法；
3. 输出契约是否提供“无合法后继”的显式退出动作。

前两个因素形成 $2\times2$ 设计，每格 400 个图实例；提供退出与不提供退出的两套任务使用相同图实例和固定前缀。可解析响应被归入四个互斥类别：

- 显式报告无合法后继；
- 保留固定前缀并停止；
- 保留固定前缀后继续生成图外边；
- 其他不合规响应。

E2 固定了模型抵达零出度状态之前的分支选择过程，因此只解释模型进入该状态后的响应分配，不解释模型为何在自然生成中选择终止分支。退出动作引起的非法续写下降也不被解释为恢复了合法完整路径，而是停止、退出与非法续写之间的重新分配。

### 补充分析

终点边出现频次对末次竞争选择的影响作为序列化线索的稳健性分析置于附录。E6 与 E7 的完整分层结果亦置于附录，正文只报告支撑贡献二的核心对比。

## 4.4 模型、解码、统计单位与分母

### 模型与解码

| 模型 | 接口 | 推理模式 | temperature |
|---|---|---|---:|
| DeepSeek-V4-Flash | DeepSeek API | thinking 关闭 | 0 |
| Qwen-Max | Qwen API | thinking 关闭 | 0 |
| GPT-5.4-mini | 第三方 OpenAI 兼容接口 | 不传 thinking 字段 | 0 |

每个任务保留一个规范响应，不采用多次采样投票或 self-consistency。因技术失败产生的重试不被视为新的独立样本。除 temperature 和推理模式外，不同服务商未统一暴露的解码参数不作跨平台等值声明。

### 统计单位

答案层的 $S_{\mathrm{last}}$、$S_{\mathrm{serial}}$、$S_{\mathrm{full}}$、$\Delta_{\mathrm{serial}}$ 和 $\Delta_{\mathrm{full}}$ 以反事实图对为统计单位。同一基础样本必须具有

$$
G_1/G_2\times
\left\{
\mathrm{endpoint\_first},
\mathrm{endpoint\_middle},
\mathrm{endpoint\_last},
\mathrm{decoy\_last}
\right\}
$$

共八个任务记录，才进入答案层的完整格估计。$\Delta_{\mathrm{serial}}$ 与 $\Delta_{\mathrm{full}}$ 在同一批八格完整样本上计算，以保证二者之差是严格的样本级分解。缺失任务导致的完整格损失单独报告，不以其他样本补齐。

路径层的 TAC、PathValid 和 $\Delta_{\mathrm{illegal}}$ 以单个图文本任务为单位。无法解析出非空路径时，按 §3 约定令 TAC 与 PathValid 均为 0。

E1 和 E2 以单个图实例为配对单位；E5、E6 和 E7 以基础 `sample_id` 为聚类单位，将同一样本下的重复序列化、出度和实验条件共同聚类。

### 失败、条件指标与有效分母

无条件主指标原则上以预定任务为审计分母。请求失败、超时、JSON 解析失败和 schema 失败分别记录；当结果行存在但未通过相应解析或结构检查时，该指标按定义记为未通过，而不因输出错误而事后剔除。若结果记录本身缺失，则该任务计入覆盖缺口；依赖完整配对格的估计量不纳入该基础样本。

条件行为指标使用各自预先定义的风险集：

- E5 的局部选择率以正确抵达 $v_{k-2}$ 的样本为条件；
- E6 和 E7 的末次选择率以正确到达该决策位置且能识别下一跳的样本为条件；
- E2 的四类响应分解以请求成功且输出可解析的样本为行为分母。

这些条件指标均同时报告原始调用数、解析数、有效分母和无条件对应指标，避免把幸存者子集误读为全样本表现。E2 另以全部调用为审计口径报告技术失败和解析失败，不将其解释为模型选择了某一种退出行为。

### 区间估计与多重比较

因果实验套件和 E7 中报告的主要风险差及比例区间，以任务预先指定的基础样本为聚类单位，采用 cluster bootstrap（$B=2000$），报告 95% 百分位区间。只有预先声明为同一比较族的对比采用 Holm 校正；未纳入比较族的结果报告未校正区间或描述性估计。

E5 的四格边界对比与 E2 退出条件对比报告配对点估计、单元比例和有效样本数，不报告 bootstrap 区间。因此，相关结果按描述性效应量解释，不使用显著性语言。

各指标的完整分母、条件风险集与有效子集索引见附录中的分母索引表。





# Appendix A 图生成细节

## A.1 图实例生成规则

第 $j$ 个基础样本由一对反事实图 $\mathcal{G}^{(j)}=(G_1^{(j)},G_2^{(j)})$ 组成。两图共享起点 $v_0$、规定跳数 $k$、拓扑类别和生成参数，但其黄金路径的后半段及黄金答案不同。以下省略图索引 $r\in\{1,2\}$。
### A.1.1 节点命名

节点名称采用“字母—数字—字母—数字”的四字符随机格式，例如 `N7Q9`。在同一基础样本中，除 $G_1$ 与 $G_2$ 明确共享的黄金路径前缀外，所有新生成节点的名称均不重复，以减少节点名称本身携带的顺序或语义线索。
### A.1.2 反事实黄金路径对

生成程序首先生成随机起点 $v_0$ 和第一 hop 节点 $v_1$。两张图的黄金路径均包含 $k+1$ 个节点，并共享前两个节点 $p_r^*=(v_0,v_1,v_2^{*(r)},\ldots,v_k^{*(r)}), r\in\{1,2\}$。两条路径从第二 hop 开始分开，分开后的节点互不重复。因此，两张图的黄金答案分别记为 $y_1$​ 和 $y_2$​，并满足 $y_1\neq y_2$。
### A.1.3 序列化版本

记 $e^* :=(v_{k-1},v_k)$。每张基础图生成以下四种文本版本：

last：随机排列除 $e^*$ 外的全部基础边，并将 $e^*$ 置于边列表末尾；
first：随机排列除 $e^*$ 外的全部基础边，并将 $e^*$ 置于边列表开头；
middle：随机排列除 $e^*$ 外的全部基础边，并将 $e^*$ 插入边列表中部；
last_decoy：在黄金答案 $y$ 后加入诱饵边 $(y,z)$，$z$ 是不属于基础图节点集的新节点，随机排列全部基础边，并将 $(y,z)$ 置于边列表末尾。

前三种版本具有完全相同的边集合，但除 $e^*$ 外的其他边在各版本中分别重新随机排列。last_decoy 则在基础边集合上额外加入诱饵边 $(y,z)$，因此不是同一图上的纯序列化变换。
### A.1.4 孤立干扰边

每张图额外生成 $m_{\mathrm{distractor}}=2k$ 条孤立干扰边。每条干扰边的源节点和目标节点均为新生成节点，不与黄金路径节点或分叉节点重合。不同背景边使用的节点也互不重复，因此它们构成与任务起点 $v_0$ 不连通的独立单边组件。背景干扰边只增加序列化文本中的无关信息，不形成从任务起点可达的结构竞争，不改变从 $v_0$ 出发的合法路径集合。

两类基础图的边数如下表所示。

| 拓扑  | 黄金边 |      分叉边 | 孤立干扰边 |  基础边总数 |
| --- | --: | -------: | ----: | -----: |
| 链式图 | $k$ |      $0$ |  $2k$ |   $3k$ |
| 分叉图 | $k$ | $2(k-1)$ |  $2k$ | $5k-2$ |

last_decoy 在基础图上额外加入一条诱饵边，因此链式图和分叉图的边数分别变为 $3k+1$ 和 $5k-1$。
### A.1.5 链式图

除孤立干扰边外，链式图从起点 $v_0$ 可达的部分仅包含黄金路径。对于除黄金答案之外的所有黄金路径节点，其唯一出边为 $(v_i,v_{i+1})$。
### A.1.6 分叉图

分叉图在黄金路径前 $k-1$ 个节点 $v_0,v_1,\ldots,v_{k-2}$ 上各加入两个非终止分支$e_{dead}^A$、$e_{dead}^B$，且所有终止分支均没有出边。

倒数第二个黄金路径节点 $v_{k-1}$ 不设置分叉，仅通过黄金终边连接黄金答案 $v_k$。这是因为在该节点加入其他出边会产生额外的合法 $k$-hop 路径。由此，每张分叉图包含 $2(k-1)$ 条非黄金分叉边。
### A.1.6 程序验证

生成程序对反事实图对中的两张图及其四种序列化版本分别执行完整路径枚举，验证完整路径的唯一性，并仅保留同时满足以下条件的实例，同时也排除了多条不同路径汇聚到同一黄金答案的情况。：

1. 图中不存在重复边；
2. 黄金答案作为边终点仅出现一次；
3. 从 $v_0$ 出发、恰好移动 $k$ 跳的完整合法路径只有一条；
4. 该唯一路径与预设黄金路径完全一致；
5. 唯一路径的末节点为预设黄金答案；
6. 诱饵节点 $z$ 不是恰好 $k$ 跳可达的终点；
7. 在 first、middle 和 last 中，黄金终边位于预设位置；
8. 在 last_decoy 中，最后一条边的终点为诱饵节点 $z$。
### A.1.7 实验规模

主实验采用以下数据设置：

| 拓扑  | 跳数 $k$        | 每个设置的基础样本数 |
| --- | ------------- | ---------: |
| 链式图 | $3,4,5,6$     |      $200$ |
| 分叉图 | $4,6,8,10,12$ |      $200$ |

每个基础样本包含两张反事实图，每张图生成四种序列化版本。因此，每个拓扑—跳数组合共产生 $200\times2\times4=1600$ 个图文本任务。

链式图在 $k=3,4,5,6$ 时分别使用随机种子 $4203$、$4204$、$4205$ 和 $4206$；分叉图在 $k=4,6,8,10,12$ 时分别使用随机种子 $4404$、$4406$、$4408$、$4410$ 和 $4412$。

## A.2 错误状态与轨迹来源归类

## Error-State and Error-Source Assignment

本文区分验证器错误状态 ErrorType 与机制性轨迹来源 ErrorSource。ErrorType 描述输出在解析、schema 与符号验证管线中的失败阶段；ErrorSource 仅在 TAC 成立但 PathValid 失败的样本中进一步描述非法轨迹的可观测来源。二者不应合并。

### A.2.1 ErrorType 互斥归类

API 调用状态首先分为 `request_failure`、`timeout` 与 `returned`。仅对 `returned` 输出执行下列互斥 ErrorType 归类，按顺序自上而下匹配，匹配即止：

|优先级|ErrorType|定义|
|---|---|---|
|1|`json_parse_failure`|无法从返回文本中获得合法 JSON 对象|
|2|`schema_failure`|JSON 可解析，但未满足对应 prompt 接口的字段与类型要求|
|3|`wrong_start`|路径首节点不等于指定起点 $s$|
|4|`wrong_length`|路径节点数不等于 $k+1$|
|5|`illegal_edge_at_hop_i`|起点与长度正确，但第 $i$ 跳首次出现输入图中不存在的有向边|
|6|`trace_answer_mismatch`|路径每条边均合法，但预测答案不等于路径末节点|
|7|`valid`|路径满足起点、长度、逐边合法性与路径-答案一致性|

该优先级保证每条 returned 输出最多归入一个 ErrorType；JSON 解析失败与 schema 失败不会被重新归类为非法路径；FailureHop 仅在 `illegal_edge_at_hop_i` 类样本上定义。

### A.2.2 ErrorSource 轨迹来源分类

当本文进一步分析 TAC 成立但 PathValid 失败的样本时，主分母为 $N_{\mathrm{TAC\text{-}illegal}}=#{j:\mathrm{TAC}^{(j)}=1\land \mathrm{PathValid}^{(j)}=0}$。

|ErrorSource|分母|定义|
|---|---|---|
|`dead_branch_mediated`|$N_{\mathrm{TAC\text{-}illegal}}$|首次偏离黄金路径是一条合法终止分支边，随后才出现非法边或无法完成合法 $k$-hop 轨迹|
|`legal_dead_stop`|$N_{\mathrm{TAC\text{-}illegal}}$|合法进入终止分支后停止或无法继续完成合法 $k$-hop 轨迹|
|`early_dead_illegal_continue`|$N_{\mathrm{TAC\text{-}illegal}}$|早期进入终止分支后继续生成非法边|
|`last_branch_dead_illegal_continue`|$N_{\mathrm{TAC\text{-}illegal}}$|在最后分叉处进入终止分支后继续非法生成|
|`immediate_illegal_from_gold_prefix`|$N_{\mathrm{TAC\text{-}illegal}}$|模型仍位于黄金路径前缀时，下一跳直接生成非法边|
|`terminal_directed_jump`|immediate-illegal 子集|直接跳向预测答案或终点类节点|
|`gold_suffix_shortcut`|immediate-illegal 子集|直接跳到黄金路径后缀节点，表现为跳步捷径|

# Appendix B. 因果机制干预实验

## B.1 输出接口与等价分支顺序

E1 关注两个层次的问题：首先，E1 在所有有效输出上检验输出接口 $z$ 是否改变模型的整体选择行为，包括模型是否更容易命中终止分支 $D$、是否更容易提交后位终止分支 $c_{\mathrm{late}}$，以及是否更容易选择黄金局部后继 $c_{\mathrm{gold}}$。E1 主实验采用 4hop；稳健性实验采用 6hop（每个 cell 调用 200 个样本），实验矩阵如下。

首先在全部分配调用（N = 400）中区分输出是否可解析，定义可解析性指标 $P$（即 parseable 简写）为第 $j$ 次调用 API 成功，且返回响应可被解析为 JSON，即$P_j=\mathbb{1}\{\mathrm{api\_ok}_j=1\land \mathrm{json\_parse\_ok}_j=1\}$；其次关注 $P = 1$ 时，能否从可解析输出中提取候选节点 $\hat c$，即 $O=\mathbb{1}[\hat{c}\text{ 可从输出中定义}]$；当 $O=1$ 时，为将两种接口下的可观察输出统一描述，定义候选节点 $\hat c$，需要注意的是，$\hat c$ 是从模型外部输出中读取的行为指标，而非模型内部真实机制的直接观测。对于 answer_only 接口，$\hat c$ 定义为模型输出的答案节点，即 $\hat c = \hat y$；对于 path_answer 接口，若模型从起点 $v_0$ 出发且至少包含一个后续节点 $\hat v_1$，则 $\hat c$ 定义为路径第一跳节点（即生成路径的第二个节点），即 $\hat c = \hat v_1$；在此基础上，进一步将 $\hat c$ 映射为三个二值指标。第一，若 $\hat c$ 落入两条终止分支 A / B 之一，则命中终止分支（$D = \mathbb{1}\!\left[\hat{c} \in \{c_{\mathrm{early}}, c_{\mathrm{late}}\}\right] = 1$）；第二，若 $\hat c$ 等于当前序列化条件下文本位置较晚的终止分支目标节点，则选择无条件后位（$L = \mathbb{1}\!\left[\hat{c} = c_{\mathrm{late}}\right] = 1$）；第三，若 $\hat c$ 等于黄金局部后继节点，则选择黄金局部（$C_{gold} = \mathbb{1}\!\left[\hat{c} = c_{\mathrm{gold}}\right] = 1$）。对于无法从可解析输出中提取候选节点 $\hat c$ 的样本，即 $O=0$ 时，不再定义 $\hat c$，仅将该样本保留在主分析分母中，并令 $D=0$、$L=0$、$C_{gold}=0$。上述条件作为主分析，分母为所有可解析输出，即 $P = 1$；此外还报告条件于 $O=1$ 的敏感性分析，分母为可解析且能读出 $\hat c$ 的所有输出，即 $P=1\land O=1$，用于排除主分析由于可能的 $O=0$ 样本太多，导致不再主要反映“模型选前位/后位”，而是反映“模型有没有给出可观察的选择”的问题。

本实验还额外报告辅助诊断的身份指标模型 $H_A$，表示模型这次选中的候选节点是否为 A 分支的目标节点 $a$，即 $H_A = 1[ĉ = a]$，用于区分模型偏好“相对前位/后位”与模型偏好某个固定分支身份 A / B。具体比较 A 在前时，模型在命中 A / B 后选择 A 的比例 $\Pr(H_A=1\mid D=1,z,\text{branch-a-early})$ 与 A 在后时，模型在命中 A / B 后选择 A 的比例 $\Pr(H_A=1\mid D=1,z,\text{branch-b-early})$。定义 $\Delta_A(z)=\Pr(H_A=1\mid D=1,z,A\prec B)-\Pr(H_A=1\mid D=1,z,B\prec A)$，由于 $\Delta_A(z)\approx 0$ 可能对应固定身份偏好或无明显偏好，本文同时报告两种位置条件下的原始比例。

| 情况  | $\Delta_A(z)$ | 两个原始概率      | 解读    |
| --- | ------------: | ----------- | ----- |
| 1   |          $>0$ | A 早时高，B 早时低 | 偏相对前位 |
| 2   |          $<0$ | A 早时低，B 早时高 | 偏相对后位 |
| 3   |   $\approx 0$ | 两格都接近 1     | 固定偏 A |
| 4   |   $\approx 0$ | 两格都接近 0     | 固定偏 B |
| 5   |   $\approx 0$ | 两格都接近 0.5   | 无明显偏好 |
由于输出接口 $z$ 会影响 $D$，因此在总体行为层，E1 的主指标为无条件后位选择率 $\Pr\!\left(L=1\right)$（由于 $L=1 \Rightarrow D=1$，因此无条件后位提交率 $\Pr(L=1)$ 等价于联合概率 $\Pr(D=1\land L=1)$；下文按需互换使用），用于检验所有有效输出中，模型有多大比例直接提交了后位终止分支。同时报告 $\Pr\!\left(C_\mathrm{gold} = 1\right)$，判断模型是否更容易选择黄金局部后继；$\Pr\!\left(D=1\right)$ ，判断接口是否改变模型陷入终止分支的总体倾向。总体层主要因果估计量是 $RD^{\mathrm{total}}_{X}=\frac{1}{2}\sum_{r\in\{A\to B,\;B\to A\}}\left[\Pr(X=1\mid Z=\mathrm{path\_answer},R=r)-\Pr(X=1\mid Z=\mathrm{answer\_only},R=r)\right]$，用于判断不管 A / B 谁在前，path_answer 相比 answer_only 是否整体改变了 X=1 的概率。其中 $X$ 表示待考察的二值结果变量，可取 $X=L$、$X=D$ 或 $X=C_{\mathrm{gold}}$，分别表示是否选择相对后位终止分支、是否命中两条终止分支之一，以及是否选择黄金局部后继。

其次，E1 希望检验当模型可观测选择已经命中终止分支 A / B（即 $D=1$）时，输出接口是否会改变模型在两条结构等价终止分支 A / B 间前位/后位偏好。由于只关注位于终止分支的子样本内，输出接口 $z$ 会如何影响 $L$，因此条件层主指标为条件后位选择率 $\Pr\!\left(L=1 \mid D=1\right)$；为检验输出接口是否改变前位/后位选择比例，本文进一步报告在命中终止分支的条件下，后位选择率的接口差异 $RD^{cond}_{L|D}$，定义为 path_answer 下的条件后位选择率减去 answer_only 下的条件后位选择率，即 $RD^{\text{cond}}_{L \mid D} = \Pr(L=1 \mid D=1, \text{path\_answer}) - \Pr(L=1 \mid D=1, \text{answer\_only})$。若 $RD^{cond}_{L|D}<0$，则表示在已经命中两条终止分支之一的输出中，path_answer 比 answer_only 更少选择后位终止分支，即其选择构成更接近前位偏好；若 $RD^{cond}_{L|D}>0$，则表示 path_answer 相比 answer_only 更偏向后位终止分支；同时报告辅助诊断指标 $\Pr\!\left(D=1\right)$ ，区分模型更容易进入终止分支，还是进入终止分支后更倾向选择后位。由于 D 是处理后的行为变量，$RD^{\mathrm{cond}}_{L\mid D}$ 不解释为 principal-stratum causal effect，仅作为终止分支命中输出内部选择构成的描述性分解。接口的总体因果效应由无条件配对 RD 识别，包括后位终止分支提交率 $\Pr(D=1\land L=1)$、终止分支命中率 $\Pr(D=1)$ 以及黄金分支提交率 $\Pr(C_{\mathrm{gold}}=1)$。

本实验设定每个图实例从起点 $v_0$ 出发，存在三种候选边。第一，正确（黄金）边：$e_g=(v_0,v_1)$；第二，终止分支 A：$e_A=(v_0,a)$；第三，终止分支 B：$e_B=(v_0,b)$。其中节点 $a$，$b$ 均无后继边，且 A / B 的局部结构角色等价。为避免分支身份与文本位置混淆，本文按边字符串词典序为两条终止分支固定身份，记词典序较小者为 A，较大者为 B。A / B 仅用于固定终止分支身份并构造位置交换条件，主要统计量不以模型选 A 还是 B 为条件，而是在每个序列化条件下将 A / B 映射为 $c_{\mathrm{early}}$ 与 $c_{\mathrm{late}}$（$c_{\mathrm{early}}$ 与 $c_{\mathrm{late}}$ 仅指 A / B 两条终止分支之间的相对前后位置），通过模型选择“当前文本中位置靠前的那个”还是“位置靠后的那个”计算主要统计量。同时，对于 $\Pr(D=1\land L=1)$、$\Pr\!\left(D=1\right)$  以及 $\Pr\!\left(C_{gold} = 1\right)$，为说明分母构成与条件指标的稳定性，本文同时报告每个条件下的全部调用数、有效输出数、终止分支命中数，以及用于配对统计的共同有效 cluster 数。为排除分支身份、图结构、图序列化长度和非目标边顺序等替代解释，E1 采用 2 × 2 的配对干预设计，两个位置条件间，除 A / B 两条边在文本中的先后顺序被交换，其他输入内容均不变。

| 输出接口        | branch-a-early | branch-b-early |
| ----------- | -------------: | -------------: |
| answer_only |        400 次调用 |        400 次调用 |
| path_answer |        400 次调用 |        400 次调用 |
表注：
1. 两个输出接口之间的 schema 文本及其长度差异属于接口处理本身
2. 400 次调用即 400 个样本（N = 400），每个样本 $2 \times 2$ 配对干预。

实验仅交换 A 与 B 在边列表中的文本位置，生成 branch-a-early 与 branch-b-early 两种情况，其中 branch-a-early 指 A / B 两条终止分支里相对更早的那条；branch-b-early 同理。随后在该位置干预下切换两种输出接口：answer_only 要求模型仅输出 {"answer": "..."}；path_answer 要求模型输出 {"path": [...], "answer": "..."}。由此形成文本位置 × 输出接口的 2 × 2 实验组合。该实验的设计逻辑是，若模型偏好固定分支身份，则 A / B 位置交换后模型仍应持续选择同一分支；若模型受文本位置影响，则被选中的分支应随 A / B 的位置交换而改变；若输出接口改变位置偏好，则两种接口下的条件后位选择率会出现系统差异。本文将结果解释为行为层面符合后位显著性驱动的终点抽取（recency-driven endpoint extraction）与类首个匹配的下一跳边检索（first-match-like next-edge retrieval）的差异，而不强断言模型内部真实执行了“末位 token 抽取”或“从前向后扫描”等具体算法。总体而言，E1 识别的是输出接口 $z$ 对等价终止分支整体选择行为的影响，而非模型内部算法的直接证据。无条件指标 $\Pr(L=1)$、$\Pr(D=1)$ 和 $\Pr(C_{\mathrm{gold}}=1)$ 用于刻画总体行为变化；条件后位选择率 $\Pr(L=1\mid D=1)$ 及 $RD^{cond}_{L|D}$ 仅描述命中两条终止分支之一的输出中，选择相对前位/后位的构成，不解释为独立条件因果效应。A / B 位置交换用于检验选择是否跟随两条终止分支之间的相对文本位置，而非固定分支身份。因此，本文仅将该结果解释为当前受控分叉图与边列表序列化条件下，输出接口会在行为层面改变模型在两条等价终止分支之间的相对位置偏好。

## B.2 预先指定的终止前缀、长度要求与合法性要求

在 §4.2.2 终止分支集合的基础上，定义零出度终止分支集合 $\mathcal{E}_{\mathrm{term}}^{0}$（上角标表示节点出度为 $0$）为下一跳节点没有任何出邻居的集合，即 $\mathcal{E}_{\mathrm{term}}^{0}=\left\{(v_i,u^0_{i+1})\in\mathcal{E}_{\mathrm{term}},i\in\{0,\ldots,k-2\}\ \middle|\ \mathcal{N}^{+}(u^0_{i+1})=\varnothing\right\}$，其中 $u^0$ 不存在任何出邻居集合，称为零出度终止节点。原始 branching-12hop 路径的 ErrorSource 互斥分解表（简称互斥表）对所有已观察到的 $\mathrm{TAC}=1\land \mathrm{PathValid}=0$ 的路径进行穷尽且互斥的错误来源分解，在具有足够错误样本的非思考模型与提示配置中，有 $97.3\%$-$99.7\%$ 的自洽但结构无效轨迹是先沿合法边进入终止分支，表明非法路径错误并非任意幻觉，而是有稳定状态链，模型首先沿图中合法边偏离黄金路径抵达零出度终止节点 $u^0$，随后产生终止状态响应 $Y_{\mathrm{term}}$。然而，原始 branching-12hop 路径同时包含两个过程：上游的终止分支选择过程，即模型是否沿图中合法但非黄金边进入终止分支；下游的终止状态响应过程，即模型抵达零出度终止节点后，在 exact-length 要求与逐边合法性要求下，选择产生哪种零出度终止状态响应，这正是 E2 关注的。互斥表给出的是两个过程耦合下观测到的整体 ErrorSource 分布，无法区分模型在抵达同一零出度终止状态后，终止状态响应差异究竟来自终止状态处理本身的局限，还是 exact-length 要求与逐边合法性要求的作用。为此，E2 通过给定模型终止前缀 $\tilde{p}=(v_0,\ldots,v_{10},u^0)$ 固定上游的终止分支选择过程，并在保持图、前缀和终止分支身份不变的条件下，控制是否施加 exact-length 要求与逐边合法性要求，诊断同一零出度终止状态的终止响应差异的来源。互斥表关注 $\mathrm{TAC}=1\land \mathrm{PathValid}=0$ 路径的整体 ErrorSource 分布，即无效轨迹主要经由哪些前置错误环节产生；E2 关注 exact-length 要求和逐边合法性要求如何改变终止响应类型，二者在诊断层次上互补。由于 E2 固定的是最后一个可分叉位置后的零出度终止状态，因此其直接解释范围是模型抵达该状态后的终止响应机制，应与原始数据中的 ErrorSource 分解联合解释：后者回答模型如何进入终止分支；E2 则回答进入终止分支后，不同输出约束如何改变停止、退出与非法续写之间的分配。将 exact-length 要求和逐边合法性要求映射为两个二值指标，$\mathrm{L}=\mathbb{1}\{\text{施加 exact-length 要求}\}$ $\mathrm{V}=\mathbb{1}\{\text{施加逐边合法性要求}\},\quad T=(\mathrm{L},\mathrm{V})\in\{0,1\}^2$
。在 E2 设定下，主分析估计量为 $p^r(t)=\Pr(Y_{\mathrm{term}}=r\mid \tilde p,T=t)$，其中 $t=(\ell,v)\in\{0,1\}^2$，$r\in\{\mathsf R,\mathsf S,\mathsf I,\mathsf O\}$。

对于请求成功且输出可解析的调用，互斥表已经给出了可观测 ErrorSource，在 E2 的固定前缀设定下，上游错误来源影响被消除， ErrorSource 上游类别退化，只剩下游相关类别可被观测，本文据此重新定义互斥且穷尽的终止状态响应变量 $Y_{\mathrm{term}}\in\{R,S,I,O\}$，互斥性、穷尽性依赖判定逻辑保证。其中，$R$：显式报告无合法后继边（显式停止）；$S$：输出固定前缀后停止（非显式停止）；$I$：输出固定前缀后非法续写；$O$：其他不合规响应。需要注意的是，$\mathsf O$ 总体很低，最高约 $1.5\%$，表明 $\mathsf R/\mathsf S/\mathsf I$ 对可解析终止响应的覆盖已经接近完整。由 PathValid 定义 $\mathrm{PathValid}^{(j)}=\mathbb{1}\!\left[\hat p^{(j)}\in\mathcal{W}(G^{(j)},s^{(j)},k)\right]=\mathbb{1}\!\left[\mathrm{PathStartOK}^{(j)}\land \mathrm{PathLengthOK}^{(j)}\land \mathrm{PathEdgesValid}^{(j)}\right]$ 可知 $\mathrm{PathValid}=0$ 的失败模式至少有两类：逐边非法，存在某条边 $(\hat v_j,\hat v_{j+1})\notin E$；长度不足，所有边都合法，但 $|\hat p|-1<k$。E2 的四类终止响应进一步讲其分解：长度不足拆分为 $\mathsf{R}$ / $\mathsf{S}$；逐边非法拆分为 $\mathsf{I}$。E2 的方法论贡献在于将固定零出度终止状态后的可观测响应分解为显式退出、非显式停止、非法续写以及其他不合规响应，并估计输出约束对这些响应概率的因果效应，使 $\mathrm{PathValid}$ 作为复合指标内部的失败模式从隐藏状态转化为可观测且可独立操纵的概念。$T=(\mathrm{L},\mathrm{V})$ 两个干预变量分别作用于不同子空间之间的转移概率，从而支持对每种失败成因的因果效应做独立识别。

对每个 branching-12hop 图实例，在最后一个可分叉节点 $v_{10}$ 处，生成器提供黄金边 $e_g$ 以及两条结构等价的终止分支 A / B。实验在两个终止分支中预选一个用于构造固定前缀 $\tilde{p}^{(j)}=(v_0^{(j)},\ldots,v_{10}^{(j)},u_{11}^{0,(j)})$，原任务要求模型完成 $12$ hops，固定前缀距离满足规定长度还差 $1$ hop，而模型继续生成任何从 $u_{11}^{0,(j)}$ 出发的边都必然违反图结构，若模型此时继续生成节点，则记其在 $u_{11}^{0,(j)}$ 后预测的第一个新节点为 $\hat u_{12}^{(j)}$。同一图实例跨模型、跨四个 E2 条件固定前缀完全相同；不同样本 $j$ 或 G1 / G2 图和固定前缀不同。实验采用 $2\times2$ 因子设计，为避免终止分支身份与处理条件混淆，E2 在生成处理条件之前，根据图实例标识的哈希值确定所使用的零出度终止分支，并在同一图实例的四个处理条件中保持不变。该选择先于 prompt 条件生成完成，因此与后续是否施加 exact-length 要求和逐边合法性要求独立；在样本层面，两个候选终止分支的使用频率近似平衡。四个处理条件使用相同的 keyed shuffle 图文本、边顺序、固定前缀和输出 schema，仅改变是否施加 exact-length 要求与逐边合法性要求。

E2 从与主实验共享的基础图池中选取 400 个独立的 branching-12hop 图实例，每个实例对应一个单独的 sample_id，不再构造反事实图对。候选实例首先接受与模型输出无关的静态结构验证：图中须存在唯一黄金 12-hop 路径；倒数第二个决策节点须同时具有黄金后继与零出度终止后继；选定终止后继后形成的固定前缀须由 11 条合法边组成，但其末节点不存在任何合法后继。通过验证的实例构成合格样本池，随后使用预先固定的随机种子从中无放回抽取 400 个实例。所有资格检查与样本抽取均在模型调用前完成，不使用模型在主实验或其他实验中的答案、错误类型或路径行为。对于每个入选实例，四个处理条件共享相同的图、固定前缀、边顺序与输出格式，仅改变 exact-length 要求与逐边合法性要求。实验采用 $2\times2$ 因子设计，且四个条件均允许模型输出 NO_LEGAL_CONTINUATION。因此，即使在 length-on × legality-on 条件下，模型也不必通过伪造边来满足长度要求，而可以显式报告当前不存在合法后继边。每个条件包含 $400$ 个图实例，每个模型共执行 $400\times4=1600$ 次调用。

| 输出约束       | edge-validity-off                               | edge-validity-on                                  |
| ---------- | ----------------------------------------------- | ------------------------------------------------- |
| length-off | 不要求 CONTINUED 路径补满至原任务规定的 12 hops；也不额外声明逐边合法性要求 | 不要求 CONTINUED 路径补满至 12 hops；但若继续生成，则每次转移均必须属于 $E$ |
| length-on  | 要求 CONTINUED 路径补满至原任务规定的 12 hops；但不额外声明逐边合法性要求  | 同时要求 CONTINUED 路径补满至 12 hops，且每次转移均必须属于 $E$       |
§ 3.1 中已经定义模型输出的预测路径为 $\hat p^{(j)}=(\hat v_0^{(j)},\hat v_1^{(j)},\ldots,\hat{v}_{m_j}^{(j)})$；预测答案为 $\hat y^{(j)}$，其中 $m_j$ 可能不等于 $k$。在此基础上进一步定义 E2 的主指标，固定前缀 $\tilde p$​ 严格前缀于模型输出 $\hat p^{(j)}$ 记为 $\tilde p ≺ \hat p^{(j)}$，即 $\tilde p ≺ \hat p^{(j)} \iff \hat p_{0:11}^{(j)} = \tilde p^{(j)} \land |\hat p^{(j)}| > |\tilde p^{(j)}|$，其中 $\hat p_{0:11}^{(j)} = \tilde p^{(j)}$ 为模型输出路径从下标 0 到下标 11 的子序列全等于固定前缀 $\tilde p^{(j)}$，$|\hat p^{(j)}| > |\tilde p^{(j)}|$ 表示模型输出路径的总长度严格大于 12。首先定义显式退出 $R$ 表示模型使用实验提供的显式退出选项，声明从终止节点不存在合法后继边，即 $\mathbb{1}\{Y_{\mathrm{term}}^{(j)}=\mathsf R\}=\mathbb{1}\{\widehat{\mathrm{status}}_j=\texttt{NO\_LEGAL\_CONTINUATION}\}$；其次定义非显式停止 $S$ 表示模型完整保留固定前缀且不再生成下一节点，但没有使用 NO_LEGAL_CONTINUATION 显式退出，即 $\mathbb{1}\{Y_{\mathrm{term}}^{(j)}=\mathsf S\}=\mathbb{1}\{R^{(j)}=0 \land \tilde p^{(j)} = \hat p^{(j)}\}$；最后定义非法续写 $I$ 表示模型完整保留固定前缀后继续生成，即 $\mathbb{1}\{Y_{\mathrm{term}}^{(j)}=\mathsf I\}=\mathbb{1}\{R^{(j)}=0 \land \tilde p^{(j)} ≺ \hat p^{(j)}\}$；未被上述类别覆盖的输出定义为其他不合规响应，即 $\mathbb{1}\{Y_{\mathrm{term}}^{(j)}=\mathsf O\} = 1-R^{(j)}-S^{(j)}-I^{(j)}$，包括修改或遗漏固定前缀、使用错误起点、返回不兼容 schema，以及其他无法解释为显式退出、前缀停止或前缀后续写的输出。此外，在非法续写 $I$ 中进一步区分两类不同类型失败：第一，乱凑型。模型只是为了继续写，随便生成节点，即 $|\hat p|\neq k+1$，其中 $k$ 是任务要求的 hop；第二，自洽型。$|\hat p| = k+1$，且末节点等于模型声明的答案 $\hat u_{12}^{(j)} =\hat y^{(j)}$（TAC = 1），记为 $F$。这种失败的迷惑性最强，表面自洽，只有逐边合法性出错。其中，F 进一步分为场景 A 和场景 B：满足 $F^A=\mathbb 1[I=1\land|\hat p|=k+1 \land \hat u_{12}^{(j)} = \hat y = y]$，即 § 3.3 中定义的场景 A；进一步定义形式完整但图上非法的续写为 以及场景 B，记 $F^B=\mathbb 1[I=1\land|\hat p|=k+1 \land \hat u_{12}^{(j)} = \hat y \neq y]$，两者满足 $|F|=|F^A|+|F^B|=\left|\left\{j:Y_{\mathrm{term}}^{(j)}=\mathsf I\land \mathrm{TAC}^{(j)}=1\land|\hat p|=k+1\right\}\right|$。

主分析中主要结果变量为 $R$、$S$、$I$，并额外报告 $F$，辅助结果变量为 $F^A$、$F^B$，作为 $F$ 场景内部的对应描述性细分指标,在每个 $T$ 条件下报告其绝对数与可解析占比，但不估计 $T$ 对 $F^A/F^B$ 比例的因果效应，因为模型在 no-target 设定下无法感知黄金答案 $y$，该比例不进入 $T$ 的因果路径。并将 $O$ 作为不合规响应审计项，分母为所有可解析输出，即 $P=1$；此外还报告条件于 $Y \neq \mathsf{O}$ 的敏感性分析，分母为可解析且能归入 $\mathsf{R}/\mathsf{S}/\mathsf{I}$ 三类核心终止响应的所有输出，即 $P=1 \land Y \neq \mathsf{O}$，用于排除主分析由于可能的 $\mathsf{O}$ 样本过多导致不再主要反映模型在终止状态下选择哪种终止响应，而是反映模型是否给出可分类的终止响应的问题。本文同时报告每格全部调用数、请求成功数、可解析响应数，以及各出口类别的有效计数。为避免因处理条件影响解析成功率而产生事后选择，全部调用口径作为主要审计口径；基于可解析响应的条件比例作为行为分解结果，并与解析率联合报告。API timeout 或无返回单独归为技术失败，不解释为模型选择了某种出口。此外，$P$ 本身可能受到处理条件 $T$ 影响。DS-Flash 在 length-off 条件下解析失败率为 $31\%-39\%$，显著高于其他模型与条件。因此,E2 同时在全调用口径报告 request failure、parse failure 与各条件下的 $N_{\mathrm{effective}}$，使读者能够独立评估主分析的 $P=1$ 子样本是否对处理条件的处理效应估计构成隐性筛选。

定义辅助变量 $C\in\{A,B\}$ 表示每个图实例中使用了两条终止分支中的哪一条，尽管样本层面终止分支身份近似平衡（§B.2 实验设计部分），为消除有限样本下身份不平衡造成的残余偏差，估计量层显式对 $C$ 做对称化平均，与 §A 中 E1 对边顺序 $R$ 的处理对称。在处理条件 $t$ 下，所有可解析输出中终止响应类别为 $r$ 的比例记为基础格点概率，即 $p^r(\ell,v,c)=\Pr(Y_{\mathrm{term}}=r\mid \mathrm{Parseable}=1,\ L=\ell,\ V=v,\ C=c)$；为消除两条终止分支身份的影响，记对 $C$ 平均后的格点概率为 $\bar p^{r}(\ell,v)=\frac{1}{2}\sum_{c\in\{A,B\}}\Pr(Y_{\mathrm{term}}=r\mid L=\ell,V=v,C=c)$；为分析 exact-length 要求对响应类别 $Y$ 变化的总体影响，固定 $V$ 计算总体主效应 $\mathrm{RD}^{\mathrm{total}}$，即 $RD_{\mathrm{L}}^{\mathrm{total},r}=\frac{1}{2}\sum_{V\in\{0,1\}}\left[\bar p^r(1,V)-\bar p^r(0,V)\right]$；随后，固定 $\mathrm{V}=v$​，分析是否存在逐边合法性要求两种情况下的 exact-length 对非法续写的局部效应，即 $RD_{\mathrm{L}\mid V=v}^{\mathrm{cond},r}=\bar p^{r}(1,v)-\bar p^{r}(0,v)$，其中 $v\in\{0,1\}$；最后，计算交互效应 $\mathrm{INT}^{r}$，分析逐边合法性要求是否改变了 exact-length 要求的效应，$\mathrm{INT}^{r}=RD_{\mathrm{L}\mid V=1}^{\mathrm{cond},r}-RD_{\mathrm{L}\mid V=0}^{\mathrm{cond},r}$，正值表示在开启逐边合法性要求时，exact-length 要求更容易增加响应类型 $r$ 的概率；负值相反。逐边合法性要求同理，为节省篇幅不再赘述。

## B.3 固定正文与终点边位置（删除）

每个 branching-$k$ hop 图记为一个  $\mathrm{sample\_id\ j}$  ，E3 检验图 $\mathrm{G}$ 中终点边 $e_{k}=(v_{k-1},y)$ 在边列表中的文本位置是否因果影响模型在最后分叉点 $v_{k-2}$ 选择正确后继黄金节点 $v_{k-1}$ 的概率，即是否存在全局文本位置效应。该实验首先对原始 branching 整体 shuffle 一次，随后仅移除终点边 $e_{k}$ 并保持 body 内部不同边相对顺序不变，最后在六个互异位置重新插入终点边 $e_{k}$ 得到六种终点边位置控制样本，简称控制样本，其中 canonical 插入原位作为对照。通过代码对每个图实例和 shuffle seed（简记为 $\mathrm{s}$） 进行核验保证六个控制样本满足互异位置约束，若六个条件下 $e_{k}$ 位置不互异，则丢弃并重新抽取，之后重复上述过程，直至符合要求的 shuffle 达到 $K$；若六个位置互异，则核验通过。除 $e_{k}$ 外，六个条件共享同一固定正文顺序，从而排除整体 shuffle 导致的不同图文本顺序差异的影响。为降低状态追踪难度对实验结果的干扰，主实验采用 4 hop，并以 6 hop 作为稳健性检验。因为在原始主实验中，模型正确到达最后分支前缀的概率在 4-hop 明显较高（0.843-0.932）；6-hop 对较弱模型仍约为 0.5 以上；8-hop 开始 GPT 与 Qwen 的 $\mathrm{C_{j,g,s,pos}}$ 值跌破 0.5，此时机制诊断样本的幸存者效应显著。对每个固定 shuffle seed，六个条件下 fixed body 的内部相对顺序保持一致，风险差 $\mathrm{RD}_{t}$ 反映 $e_k$ 位置由 canonical 移到 $t$ 所引起的总效应（包含 $e_k$​ 自身绝对位置变化、以及 fixed body 中各边因 $e_k$​ 占位变化而产生的绝对位置平移）。对 $K$ 个独立 shuffle seed 取平均后，特定 shuffle 实现下的位置耦合被 marginalize 为 shuffle 分布上的平均效应。六种控制版本除 $e_{k}$ 的位置外，其他条件完全相同，且均使用 jsoncot_strict。本主实验共 $\mathrm{J}=400$ 个独立 sample_id（稳健性实验 200 个），每个 $\mathrm{sample\_id}$ 分别执行六个位置条件，共有 $400 \times 6 = 2400$ 次调用。实验具体插入位置如下表。

| global-last（简称 last）       | 边列表最后一行       | 将终点边 $e_{k}$ 插入整个边列表最后一个位置                    |

为避免将早期路径错误归因于终点边干预，主实验只统计模型正确到达黄金路径的倒数第三个节点 $v_{k-2}$（生成器限制 $v_{k-2}$ 为最后一个存在同源边的分叉节点；稳健性实验同理）。因此，首先定义正确抵达指示变量为 $\mathrm{C_{j,s,pos}}=\mathbb 1[\tilde p_{0:k-2}\prec\hat p]$，其中 $\tilde{p}^{(j)}_{0:k-2}$ 表示模型前 $k-2$ hop 沿黄金路径，$\mathrm{pos} \in \{\mathrm{first}, \mathrm{center}, \mathrm{before}, \mathrm{after}, \mathrm{last}, \mathrm{canonical}\}$；随后定义抵达率 ${q}_{\mathrm{reach,pos}}=\frac{\sum_{(j,s)\in \mathcal{I}_{\mathrm{pos}}}C_{j,s,\mathrm{pos}}}{\left|\mathcal{I}_{\mathrm{pos}}\right|}$，$|\mathcal{I}_{\mathrm{pos}}|$ 表示该 $\mathrm{pos}$ 下可纳入分析的样本集合。黄金后继选择指示变量为 $S_{j,s,\mathrm{pos}}=\mathbb{1}\!\left[\hat{v}_{k-1}^{(j,s,\mathrm{pos})}=v_{k-1}^{(j)}\right]$，条件局部正确率为 $\hat{p}_{\mathrm{cond,pos}}=\frac{\sum_{(j,s)\in\mathcal{I}_{\mathrm{pos}}}C_{j,s,\mathrm{pos}}S_{j,s,\mathrm{pos}}}{\sum_{(j,s)\in\mathcal{I}_{\mathrm{pos}}}C_{j,s,\mathrm{pos}}}$，同时报告以 $|\mathcal{I}_{\mathrm{pos}}|$ 为分母的稳健性指标 ${p}^{\mathrm{all}}_{\mathrm{local,pos}}=\frac{\sum_{(j,s)\in\mathcal{I}_{\mathrm{pos}}}C_{j,s,\mathrm{pos}}S_{j,s,\mathrm{pos}}}{\left|\mathcal{I}_{\mathrm{pos}}\right|}$，二者关系为 ${p}^{\mathrm{all}}_{\mathrm{local,pos}}={q}_{\mathrm{reach,pos}} \cdot {p}_{\mathrm{cond,pos}}$。实验诊断指标为 $\Delta p_{\mathrm{cond},t}={p}_{\mathrm{cond},t}-{p}_{\mathrm{cond},\mathrm{canonical}}$，其中 $t \in \mathrm{T} = \mathrm{pos}\setminus\{\mathrm{canonical}\}$，同时以全口径下的 $\Delta p^{\mathrm{all}}_{\mathrm{local},t}={p}^{\mathrm{all}}_{\mathrm{local},t}-{p}^{\mathrm{all}}_{\mathrm{local},\mathrm{canonical}}$ 作为稳健性诊断。定义共同幸存集 $\mathcal{H}=\left\{(j,s):C_{j,s,\mathrm{pos}}=1,\ \forall\,\mathrm{{pos}}\in\mathcal{T}_{\mathrm{pos}}\right\}$ 作为敏感性分析，即仅保留在全部位置条件下均正确抵达 $v_{k-2}$ 的样本。对于任意非 canonical 位置 $t$，在 $\mathcal{H}$ 上重新计算条件局部正确率 ${p}^{\mathrm{hard}}_{\mathrm{cond},t}=\frac{1}{|\mathcal{H}|}\sum_{(j,s)\in\mathcal{H}}S_{j,s,t}$，并定义共同幸存集上的配对差为 $\Delta p^{\mathrm{hard}}_{\mathrm{cond},t}={p}^{\mathrm{hard}}_{\mathrm{cond},t}-{p}^{\mathrm{hard}}_{\mathrm{cond},\mathrm{canonical}}$。置信区间通过按 sample_id 聚类的 paired cluster bootstrap 估计。若 $\Delta p^{\mathrm{hard}}_{\mathrm{cond},t}$ 与主分析的 $\Delta p_{\mathrm{cond},t}$ 在方向和量级上保持一致，则表明主要位置效应不太可能由不同条件下的幸存样本组成差异所驱动；若二者明显不一致，则报告该差异，并相应限制对条件局部选择效应的解释。

## B.4：终点边文本支持

主实验 GFI 已经验证了模型存在位置锚定现象，E4 则希望进一步检验模型是否存在边出现频次锚定现象（简称频次锚定）。在理想的简单图观察者零基线下，边列表首先被恢复为去重后的有向边集合 $\mathrm{E}$。因此，同一条边重复出现不会改变 $\mathrm{E}$，也不会增加新的图结构信息。换言之，重复边在图语义上不提供额外证据。E4 并不假设 LLM 的 token processing 满足该理想条件；相反，本实验正是检验模型是否偏离这一去重图语义零基线，即是否会把边出现频次这一序列化层面的非结构线索用于最后分叉选择。同时合成图排除可解释的自然语言的语义因素，重复无法传达语义信息。

每个 branching-$k$ hop 图记为一个  $\mathrm{sample\_id\ j}$ ，E4 以 6 hop 做主实验，8 hop 做稳健性诊断，检验图 $\mathrm{G}$ 中终点边 $e_{k}=(v_{k-1},y)$ 在边列表中的总出现次数（edge multiplicity，简记为重复次数 $\mathrm{M}$），是否因果影响模型在最后分叉点 $v_{k-2}$ 选择后继黄金节点 $v_{k-1}$ 的概率，即是否存在频次锚定。本实验在设计思路上沿用 § B.3（实验 E3） 的六个控制样本作为基线（$\mathrm{M = 1}$），但所有 E4 样本均重新生成，不复用 E3 数据或输出。首先改变边 $e_{k}$ 的重复次数 $\mathrm{M}\in\{1,2,3,4\}$，得到四个频次控制样本；为排除读取噪声（漏读、错读或注意力分散）+ 冗余纠错这一竞争假设，即模型重复观察 $e_k$​ 后能进行更准确解析，而非真的对频次敏感，设计结构对照样本。以原始 branching 整体 shuffle 后得到的样本为底图，在 $v_{k-2}$ 的两条等价终止分支 $e^{\mathrm{A}}_{\mathrm{dead}}$ 与 $e^{\mathrm{B}}_{\mathrm{dead}}$ 中任选一条（本实验选择 $e^{\mathrm{A}}_{\mathrm{dead}}$），对应的零出度终止节点为 $v_{\mathrm{dead}}^{\mathrm{0}}$，修改其重复次数 $\mathrm{M}\in\{1,2,3,4\}$。设计结构对照样本，令分散重复作为对照组。定义二值变量 $\mathrm{R}$ 表示重复方式，其中 $R\in\{\mathrm{clustered},\mathrm{evenly-dispersed}\}$，$\mathrm{clustered}$ 表示被操纵边的 $\mathrm{M}$ 次出现连续的放在一起，$\mathrm{evenly-dispersed}$ 表示被操纵边的 $\mathrm{M}$ 次出现在边列表允许槽位中尽量均匀分布，上述实验条件记为 $\mathrm{clustered}$ 条件下的频次控制样本。$\mathrm{evenly\text{-}dispersed}$ 条件以原始 branching 整体 shuffle 后得到的样本为底图，设插入 $\mathrm{M}$ 个出现实例后的边列表总行数为 $\mathrm{L}$，即 $\max\{\text{edge-list index}\}=\mathrm{L}$。首先，从边列表抽出终点边 $e_{k}=(v_{k-1},y)$，将边列表划分为 $\mathcal{B} = M$ 个区域，每个区域宽度为 $\omega=\frac{\mathrm{L}}{M}$。其中，第 $b$ 个区域定义为 $\mathcal{B}_b=\left\{i\in\{1,\ldots,\mathrm{L}\}:\left\lfloor(b-1)\cdot\omega\right\rfloor<i\le \left\lfloor b\cdot\omega\right\rfloor\right\}$，其中 $b=1,\ldots,M$，$\left\lfloor b\Omega\right\rfloor$ 简记为 $\ell_b$。随后，在每个区域 $\mathcal{B}_b$ 的区域中心 $p_b=\left\lfloor\frac{\ell_{b-1}+1+\ell_b}{2}\right\rfloor$ 处插入一条终点边 $e_{k}$，得到 $\mathrm{evenly\text{-}dispersed}$ 条件下的频次控制样本。

在同一 $(j,  s, \text{pos})$ 单元内,除被操纵边的重复次数 $\mathrm{M}$ 外，其余边及其相对顺序保持不变，且均使用 jsoncot_strict。本实验中，主实验共 $\mathrm{J}=400$ 个独立 sample_id（稳健性实验为 200 个，以下报告主实验数据，稳健性实验同理）， $\mathrm{clustered}$ 条件下，每个 $\mathrm{sample\_id}$ 执行 6 $\mathrm{pos}$ × 4 $\mathrm{M}$ 全因子设计，频次控制样本调用数 $400 \times 6 \times 4= 9600$；频次对照样本只在 canonical 条件下运行 4 $\mathrm{M}$，调用数 $400 \times 4= 1600$，E4 主实验总调用数 $9600 + 1600 = 11200$。$\mathrm{evenly-dispersed}$ 条件下的结构对照样本有 $400 \times 4 = 1600$ 次调用，全实验共 $11200 + 1600 = 12800$ 次调用。为避免将早期路径错误归因于终点边干预，主实验只统计模型正确到达黄金路径的倒数第三个节点 $v_{k-2}$（生成器限制 $v_{k-2}$ 为最后一个存在同源边的分叉节点；稳健性实验同理）。作为 Appendix 中的补充缓解实验，本文另设指令对照样本，指令为 duplicate-edge instruction $\mathrm{Z} \in \{0,1\}$。其中 $\mathrm{Z=0}$ 表示使用主实验 prompt，$\mathrm{Z=1}$ 表示使用下列 prompt。该 instruction 条件不进入 E4 主矩阵，也不计入主实验调用数；其目的仅是检验显式去重规则是否能够缓解主实验中观察到的频次锚定现象。prompt指令如下：
```
Graph interpretation rules:
1. Treat the edge list as a simple directed graph.
2. If the same directed edge appears multiple times, treat it as a single edge.
3. Duplicate edge rows do not indicate higher importance, larger weight, or additional evidence for the correct path.
```

先做抵达-条件分解，定义抵达率为 $q^{\mathrm{reach}}(m)=\Pr(C=1\mid,M=m)$，其中 $\mathrm{C}=\mathbb 1[\tilde p_{0:k-2}\prec\hat p]$ ，表示模型前 $k-2$ hop 沿黄金路径。抵达后的条件选择率为 $p_{\mathrm{support}}^{\mathrm{cond}}(m)=\Pr(\hat v_{k-1}=v_{k-1}\mid C=1,A=\mathrm{support},M=m)$ 与 $p_{\mathrm{dead}}^{\mathrm{cond}}(m)=\Pr(\hat v_{k-1}=v_{\mathrm{dead}}^{0}\mid C=1,A=\mathrm{dead},M=m)$，三者关系为 $p_{\mathrm{support}}^{\mathrm{all}}(m)=\Pr(C=1\land \hat v_{k-1}=v_{k-1}\mid A=\mathrm{support},M=m) = q_{\mathrm{reach}}(m) \cdot p_{\mathrm{support}}^{\mathrm{cond}}(m)$；同理 $p_{\mathrm{dead}}^{\mathrm{all}}(m)=q_{\mathrm{reach}}(m) \cdot p_{\mathrm{dead}}^{\mathrm{cond}}(m)$，其中 $q_{\mathrm{reach}}(m)$ 在各 arm 内分别计算，为简化记号省略 arm 下标；未抵达 $v_{k-2}$ 的样本在全样本指标中记为 0。随后定义两套频次效应，条件效应作为主统计量 $\Delta_{\mathrm{support}}^{\mathrm{cond}}(m)=p_{\mathrm{support}}^{\mathrm{cond}}(m)-p_{\mathrm{support}}^{\mathrm{cond}}(1)= F_{\mathrm{support}} + L_{\mathrm{support}}$；$\Delta_{\mathrm{dead}}^{\mathrm{cond}}(m)=p_{\mathrm{dead}}^{\mathrm{cond}}(m)-p_{\mathrm{dead}}^{\mathrm{cond}}(1)= F_{\mathrm{dead}} + L_{\mathrm{dead}}$，其中 F、L 的分解仅用于陈述跨 arm 比较所需的可比性假设。如果 $q_{\mathrm{reach}}​$ 稳定，且共同幸存集结果与主条件结果一致，那么频次改变局部选择的解释就更可信。全样本效应为 $\Delta_{\mathrm{support}}^{\mathrm{all}}(m)=p_{\mathrm{support}}^{\mathrm{all}}(m)-p_{\mathrm{support}}^{\mathrm{all}}(1)$；$\Delta_{\mathrm{dead}}^{\mathrm{all}}(m)=p_{\mathrm{dead}}^{\mathrm{all}}(m)-p_{\mathrm{dead}}^{\mathrm{all}}(1)$，作为稳健性诊断。其中 $\Delta^{\mathrm{cond}}_{\mathrm{dead}}(m)$ 作为冗余纠错竞争解释的主诊断指标，若 $\Delta^{\mathrm{cond}}_{\mathrm{dead}}(m) > 0$，则模型因为 $e^{\mathrm{A}}_{\mathrm{dead}}$ 重复次数更多就更容易选中该终止分支，单纯的读取噪声与冗余纠错假设不能充分解释该结果。因为冗余纠错假设重复只能帮助模型更准确识别黄金边，失败率应降低（或不变）。由于 support arm 与 dead arm 在 $M=1$ 时的基线概率及剩余改善空间明显不同，直接比较 $\Delta^{\mathrm{cond}}_{\mathrm{support}}(m)$ 与 $\Delta^{\mathrm{cond}}_{\mathrm{dead}}(m)$ 可能受到概率上界压缩的影响，因此进行归一化处理。将各 arm 的实际增量除以其从 $M=1$ 基线升至 1 的剩余空间，即 $G_{\mathrm{support}}^{\mathrm{cond}}(m)=\frac{\Delta_{\mathrm{support}}^{\mathrm{cond}}(m)}{1-p_{\mathrm{support}}^{\mathrm{cond}}(1)}$；$G_{\mathrm{dead}}^{\mathrm{cond}}(m)=\frac{\Delta_{\mathrm{dead}}^{\mathrm{cond}}(m)}{1-p_{\mathrm{dead}}^{\mathrm{cond}}(1)}$。

为区分一般的 token-level 频次吸引与对被重复边图角色敏感的差异效应，定义 $\Delta_{\mathrm{net}}^{\mathrm{cond}}(m)=\Delta_{\mathrm{support}}^{\mathrm{cond}}(m)-\Delta_{\mathrm{dead}}^{\mathrm{cond}}(m)$。该指标仅在两个 arm 中由 $M$ 变化引起的序列长度与一般任务难度效应近似相等，即 $L_{\mathrm{support}} \approx L_{\mathrm{dead}}$ 时，辅助诊断频次效应是否随被重复边的图角色而异；否则仅表示两侧归一化增量的描述性差异。若 $\Delta^{\mathrm{cond}}_{\mathrm{net}}(m)\approx 0$，则 support 和 dead 对重复的反应强度接近，更像一般 token-level frequency salience；如果 $\Delta^{\mathrm{cond}}_{\mathrm{net}}(m)>0$ 显著（在 $\Delta^{\mathrm{cond}}_{\mathrm{dead}}(m)>0$ 前提下），则重复 support 边产生的吸引增强效应大于重复 dead 边产生的吸引增强效应，模型对重复对象的图角色敏感（graph-role-sensitive frequency anchoring）；如果 $\Delta^{\mathrm{cond}}_{\mathrm{dead}}(m)\le 0$ 且 $\Delta^{\mathrm{cond}}_{\mathrm{support}}(m)>0$，则模式与冗余纠错预测相容；如果两者均未达到显著性，则当前实验未检测到明确的频次效应，但不能据此证明模型完全不受重复影响。同时以 
$G_{\mathrm{net}}(m) = G_{\mathrm{support}}^{\mathrm{cond}}(m)-G_{\mathrm{dead}}^{\mathrm{cond}}(m)$ 作为敏感性指标，用于描述两侧相对 headroom 响应的差异。E4 仍然关注图忠实性问题，且为黑盒诊断，因此设置对照实验的目的不是对该现象进行模型内部状态转移分析，而是排除模型读取能力噪声，区分不忠实性与冗余纠错现象。


$\mathrm{evenly-dispersed}$ 为描述重复边在文本序列中的分布形态，理想图遍历器看到一次 $e_i$ 后就会将其加入边集合 $E$，对重复边去重后，六个条件对应完全相同的有向图。$\Delta p^{\mathrm{all}}=q^{\mathrm{reach}}_m \cdot \Delta p^{\mathrm{cond}}+p_1^{\mathrm{cond}} \cdot \Delta q_{\mathrm{reach}}$，其中 $q^{\mathrm{reach}}_m$ 表示 $M=m$ 时的抵达率，$p_1^{\mathrm{cond}}$ 表示基线 $M=1$ 时的条件成功率。$q^{\mathrm{reach}}_m \cdot \Delta p^{\mathrm{cond}}$ 称为局部选择项，表示已经抵达最后分叉后，条件选择率变化带来的贡献，$p_1^{\mathrm{cond}} \cdot \Delta q_{\mathrm{reach}}$ 称为抵达率项 ，表示抵达率变化带来的贡献。如果模型抵达率不变，只是抵达后更容易选对，那么变化主要来自第一项；如果抵达后选择率没变，但更不容易抵达最后分叉，那么变化主要来自第二项。若模型忠实地遍历并恢复去重后的图结构，则在图结构、起点、跳数与边位置模板保持不变时，边重复次数 $\mathrm{M}$ 不应系统性改变输出；若模型不忠实于图，则分四种情况：由于集中重复能提高同一局部块的候选显著性，如果集中重复强，分散重复弱，则说明模型行为更符合逐步游历过程中依赖局部文本块检索候选边的机制；由于分散重复能增强全局可检索性和多位置命中率，如果分散重复强，集中重复弱，则说明模型更可能在全局文本序列中进行多位置检索或证据聚合；如果两者都强，则 frequency salience 和 global retrievability 都在起作用；如果两者都弱，则该模型不太受边重复影响。

| 集中重复 | 分散重复 | 更符合的行为         |
| ---- | ---- | -------------- |
| 强    | 弱    | 依赖局部文本块检索      |
| 弱    | 强    | 依赖全局多位置检索      |
| 强    | 强    | 局部显著性和全局检索共同作用 |
| 弱    | 弱    | 基本不受重复影响       |
## B.5：长路径失败的状态维护与终端分支诊断

为诊断有向图 $G = (V,E)$ 在 jsoncot_strict 设置下，导致长路径中 branching-$k$ hop 出现低 accuracy 现象的两类可能困难：a 类困难是模型能力不足导致状态维护失败。随着路径变长，模型需要维护的决策链长度也随之增加，这使得模型更可能在抵达最后分支节点 $v_{k-2}$ 前就已经偏离黄金路径；b 类困难是局部决策困难，最后分支节点 $v_{k-2}$ 属性特殊。模型在之前的分叉点处主要面对同源边候选竞争，然而在 $v_{k-2}$ 节点处，模型额外面对两个挑战，紧张的剩余 hop 数约束（horizon）与终点对齐约束（由于 $v_{k-1}$ 直接通向黄金答案 $y$，不存在终点对齐困难，因此终点对齐约束主要作用于节点 $v_{k-2}$ 处）。可以证明，在本文 § 3 的唯一黄金路径 $\mathcal W(G,s,k)=\{p^*\}$ 设定下，horizon 与终点对齐约束在任务信息层面构成等价约束，换言之，二者在任务信息层面不可作为两个独立因素分离，因此之后统称为终端约束。证明如下，沿用 § 3.1 的任务路径集合定义。记 $\mathcal W(G,v_i,r)$ 为从节点 $v_i$ 出发、长度为 $r$、终点为 $y$ 的合法有向任务路径集合。若任务满足唯一黄金路径条件 $\mathcal W(G,s,k)=\{p^*\}$，其中 $p^*=(v_0=s,v_1,\ldots,v_k=y)$，则对任意黄金路径节点 $v_i$，都有 $\mathcal W(G,v_i,k-i)=\{(v_i,v_{i+1},\ldots,v_k)\}$。因此，在给定当前状态为 $v_i$ 的条件下，剩余 hop 数 $k-i$ 与该剩余预算下的合法终点 $y$ 共同指向同一个唯一后缀，因此，剩余预算约束与终点对齐约束在任务信息层面不可作为两个独立因素分离。由上述可知，b 类困难包括同源候选竞争与终端约束，其中同源候选竞争于 E6 / E7 两个实验中诊断。branch 主实验的 accuracy 矩阵如下：

| Qwen-Max            | 68.7% | 56.9% | 39.4% | 20.1%  | 13.8%  |

主实验虽然进行了 hop 长度扫描，但仅凭不同 hop 下的 $\mathrm{{\Delta_{Accuracy}}}$ 无法诊断上述两类困难。其中，a 类困难无法诊断的原因在于路径长度 $k$ 与局部决策次数天然耦合，即当 $k$ 增加时，额外决策次数 $\mathrm{\Delta k}$ 同时增加。在理想情况下，在每个黄金节点 $v_i$ 处选中黄金后继的概率为常数 $p$，则 Accuracy 曲线天然呈现 $p^k$ 的几何衰减。此时，Accuracy 随 hop 增加而下降，可能是由于自身数学特性，也可能是由于模型在靠后的 $v_i$ 处出现状态维护能力退化，即真的出现了 a 类困难。且实际中 $p$ 可能并非常数，这就引入更多需要考虑变量；同时，直接比较不同 $k$ hop 曲线各自在 $v_{k-2}$ 处选中黄金后继的概率，会引入幸存者效应，即​ hop 数越长，抵达 $v_{k-2}$ 的前缀难度越高，该 $k$ hop 类别的幸存子集越少（例如 8 hop 中 GPT / Qwen 通过前缀的比例已跌破 0.5）。因此跨 $k$ hop 比较的是不同筛选强度下的非配对子集，存在误差。对此，E5 不再比较最终 Accuracy，而是比较四种条件下 $v_{k-2}$ 处选中黄金后继的诊断性 $2\times2$ 边界设计，用 $\mathrm{T}$ 代表不同任务设定。需要强调的是，E5 并非严格的单因素因果消融。O-local / O-full 在移除前缀状态维护负担的同时也改变了输入分布与有效搜索空间；R-task 并非完全移除终端约束，而是将原始 2-hop 终端窗口替换为后续延展窗口。因此，E5 的估计量应解释为诊断性边界对比，而非对终端约束因果效应的无偏识别。四个实验设计如下：

第一个实验，将原始 branching-$k$ hop 主实验定义为完整状态基线实验（Full-task baseline，F-task），同时存在 a 类与 b 类两类困难。第二个实验，目标替换任务（Target-Replacement Task，R-task）实验，设计目的为对比终端约束对 $v_{k-2}$ 处黄金后继选择概率的影响。首先使用相同生成规则（1 条 $e_{\mathrm{gold}}$ + 2 条 $e_{\mathrm{dead}}^{A,B}$）生成一定长度的 $z$ 链，即 $z_1\to z_2\to\cdots\to z_{\ell}$，放置于原始 branching-$k$ hop 的 $v_{k-1}$ 节点与 $v_{k}$ 节点之间，得到 $v_{0}\to\cdots\to v_{k-2}\to v_{k-1}\to z_1\to\cdots\to z_{\ell}\to y$。随后需要保证边列表元素数量相同，调整指向非黄金节点的干扰边的数量，干扰边生成规则沿用原始 branching 的干扰边生成规则；需要缓解 $v_{k-2}$ 节点决策环境差异导致的干扰，应保证 $v_{k-2}$ 处的局部候选窗口逐字一致、候选数量一致、$v_{k-1}$ 的相对位置一致、$e_{\mathrm{dead}}^{A,B}$ 一致、shuffle 顺序一致，下列实验沿用此设定。对于 task 系列实验，定义 cell-level 主统计量为 $p_F$ 与 $p_R$，未抵达 $v_{k-2}$ 的样本记为 0。$p_F$ 表示任务设定为 $F$ 时，模型从 $v_0$ 出发，成功抵达 $v_{k-2}$ 且下一跳选中 $v_{k-1}$ 的概率，即 $p_F=\Pr(\text{前 }k-2\text{ hop 正确} \land \hat v_{k-1}=v_{k-1} \mid \mathrm{T = F} )$；$p_R$ 表示任务设定为 $R$ 时，模型从 $v_0$ 出发，成功抵达 $v_{k-2}$ 且下一跳选中 $v_{k-1}$ 的概率，即 $p_R=\Pr( \text{前 }k-2\text{ hop 正确} \land \hat v_{k-1}=v_{k-1} \mid \mathrm{T = R} )$。同时定义幸存者版本统计量用于辅助诊断，$p_F^{\mathrm{cond}}=\Pr(\hat v_{k-1}=v_{k-1}\mid \mathrm{T}=F \land \text{前 }k-2\text{ hop 正确})$；$p_R^{\mathrm{cond}}=\Pr(\hat v_{k-1}=v_{k-1}\mid \mathrm{T}=R \land \text{前 }k-2\text{ hop 正确})$。其中 $p_F= \Pr(\text{前 } k-2 \text{ hop 正确}) \times \Pr(\hat v_{k-1}=v_{k-1}\mid \text{前 } k-2 \text{ hop 正确}) = q_{\mathrm{reach}} \times p_F^{\mathrm{cond}}$，其中 $q_{\mathrm{reach}}$ 称为到达率，作为辅助诊断指标，表示模型沿黄金路径正确走完前 $k-2$ 跳、抵达 $v_{k-2}​$ 的概率。同理，对于 $T = R$，有相应分解指标 $q_R,p_R^{\mathrm{cond}}$，不再赘述。前者衡量长序列状态维护失败，后者衡量幸存样本中的终端局部决策困难（表 X）。该切片不依赖 oracle 干预，因而不引入输入分布或搜索空间的改变，也不声称识别两类机制的纯因果效应，而用于刻画主要失败质量在前段状态维护与终端局部选择之间的分布。

第三个实验，理想信息条件下的局部任务（Oracle-local，O-local），以 $v_{k-2}$ 为起点，要求模型完成剩余 $2$ hop 后缀并选中黄金答案。通过在 branching-$k$ hop 主实验中，仅保留图 $G$ 中 $v_{k-2}$ 节点之后的（包含 $v_{k-2}$）黄金节点 $v_i$，以及 $v_i$ 对应的两个同源终止分支节点，保证边列表元素数量相同，干扰边数量调整至对应水平。由于此时抵达最终分支节点 $v_{k-2}$ 的路径前缀被移除，因此前段状态维护负担被卸载，但同时也缩小了输入图的有效搜索范围；第四个实验，理想信息条件下的全部任务（Oracle-full，O-full），对于 R-task 中得到的长链，仅节选 $v_{k-2}\to v_{k-1}\to z_1\to\cdots\to z_{\ell}\to y$ 及其对应终止分支部分（z 链相同长度），为保证边列表元素数量相同，干扰边数量调整至对应水平。由于 O 系列实验直接从 $v_{k-2}$ 出发，因此不存在幸存者效应，因此可以定义主统计量为 $p_{\mathrm{local}}$ 与 $p_{\mathrm{full}}$。$p_{\mathrm{local}}$ 表示模型从 $v_{k-2}$ 出发，下一步选中黄金后继 $v_{k-1}$ 的概率，即 $p_{\mathrm{local}} = \Pr(\hat v_{k-1} = v_{k-1} \mid \mathrm{T = local} \land start = v_{k-2})$；$p_{\mathrm{full}}$ 表示模型从 $v_{k-2}$ 出发，下一步选中黄金后继 $v_{k-1}$ 的概率，即 $p_{\mathrm{full}}=\Pr(\hat v_{k-1}=v_{k-1}\mid \mathrm{T = full} \land start=v_{k-2})$。

| 条件 $\mathrm{T}$ | 起点 /幸存者效应     | 状态维护负担 | 终端约束（horizon + 终点对齐） | 后续延展负担 | 主统计量 / 辅助统计量                  |
| --------------- | ------------- | ------ | -------------------- | ------ | ----------------------------- |
| F-task          | $v_{0}$ / 有   | 有      | 有                    | 无      | $p_F$ / $p_F^{\mathrm{cond}}$ |
| R-task          | $v_{0}$ / 有   | 有      | 弱化                   | 有      | $p_R$ / $p_R^{\mathrm{cond}}$ |
| O-local         | $v_{k-2}$ / 无 | 无      | 有                    | 无      | $p_{local}$ / N/A             |
| O-full          | $v_{k-2}$ / 无 | 无      | 弱化                   | 有      | $p_{full}$ / N/A              |
对于 a 类困难，由实验矩阵可知，应对比 F-task & O-local 样本，以及 R-task & O-full 样本。将状态维护边界定义为基于 sample_id 配对的（下同）oracle 当前状态与完整前缀状态之间的差异 $\Delta_{\mathrm{state}}^{\mathrm{terminal\text{-}on}}$ 与 $\Delta_{\mathrm{state}}^{\mathrm{terminal\text{-}off}}$。其中，$\Delta_{\mathrm{state}}^{\mathrm{terminal-on}}$ 表示原始终端约束存在时，状态维护负担造成的局部选择损失，即 $\Delta_{\mathrm{state}}^{\mathrm{terminal-on}} = p_{\mathrm{local}} - p_{F}$；$\Delta_{\mathrm{state}}^{\mathrm{terminal\text{-}off}}$ 表示终端约束被弱化时，状态维护负担造成的局部选择损失，即 $\Delta_{\mathrm{state}}^{\mathrm{terminal\text{-}off}}=p_{\mathrm{full}}-p_R$。$\Delta_{\mathrm{state}}$ 应解释为移除前缀状态维护与空降当前状态后的总恢复效应，而不是固定样本状态下的纯状态维护消融。若两个 $\Delta_{\mathrm{state}}$ 均较大，说明状态维护负担在两类终端环境下都会显著降低局部后继选择概率。

对于 b 类困难中的终端约束效应，由实验矩阵可知，应对比 F-task & R-task 样本，以及 O-local & O-full 样本。将终端约束效应定义为弱化终端窗口后，$v_{k-2}$ 处黄金后继选择概率的提升 $\Delta_{\mathrm{terminal}}^{\mathrm{state-on}}$ 与 $\Delta_{\mathrm{terminal}}^{\mathrm{state\text{-}off}}$。其中，$\Delta_{\mathrm{terminal}}^{\mathrm{state-on}}$ 表示有前缀状态维护负担时，弱化终端约束带来的联合概率变化，即 $\Delta_{\mathrm{terminal}}^{\mathrm{state-on}}=p_{\mathrm{R}}-p_{\mathrm{F}}$；$\Delta_{\mathrm{terminal}}^{\mathrm{state\text{-}off}}$ 表示无前缀状态维护负担时，弱化终端约束带来的第一跳提升，即 $\Delta_{\mathrm{terminal}}^{\mathrm{state\text{-}off}}=p_{\mathrm{full}}-p_{\mathrm{local}}$。若两个 $\Delta_{\mathrm{terminal}}$ 均较大，说明终端位置约束本身带来稳定额外困难。同时，$\Delta_{\mathrm{terminal}}^{\mathrm{state-on}}=p_R-p_F=q_R \cdot r_R-q_F \cdot r_F$，同时包含抵达最后分叉点概率的变化 $q$ 与抵达后局部选择概率的变化 $r$，因此同时报告 $\Delta_{\mathrm{terminal}}^{\mathrm{state-on}}$ 的幸存者辅助指标 $r_R-r_F=p_R^{\mathrm{cond}}-p_F^{\mathrm{cond}}$。

由 $2\times2$ 结构，前缀条件与窗口替换之间的差分之差的两种算法等价（算术恒等）：$\Delta_{\mathrm{interaction}}=\Delta_{\mathrm{terminal}}^{\mathrm{state\text{-}on}}-\Delta_{\mathrm{terminal}}^{\mathrm{state\text{-}off}}=\Delta_{\mathrm{state}}^{\mathrm{terminal\text{-}on}}-\Delta_{\mathrm{state}}^{\mathrm{terminal\text{-}off}}$。即 $\Delta_{\mathrm{interaction}}=(p_R-p_F)-(p_{\mathrm{full}}-p_{\mathrm{local}})$。由于二者相减可能包含状态维护与终端窗口的真实交互与 task 系列独有的可达性筛选效应，因此不将其理解成干净的因果交互。若 $\Delta_{\mathrm{interaction}}$ 显著偏离 0，说明终端约束效应依赖前缀状态维护负担，或等价地，状态维护边界对比依赖终端窗口是否存在。若上述效应均较小，则低 accuracy 更可能来自其他机制或任务构造因素。

实验采用 400 个图实例（200 个 sample_id × 2 个图侧 G1/G2），设定 $k=8, \ell=6$。每个图实例生成四个条件：full-state / oracle-state × original-terminal / counterfactual-terminal，构成 2×2 诊断设计。对不可解析、路径长度错误或未抵达 $v_{k-2}$ 的输出，在全样本指标 $p_F, p_R$ 中均记为 0。置信区间以 sample_id 为聚类单位进行 95% bootstrap 计算。幸存者条件统计量单独报告其分母与共同幸存集大小，不与全样本指标混用。
## B.6：同源候选数量与输出约束

E6 检验 chain 是否可以看作没有同源终止分支候选竞争（简称同源竞争）的退化 branching 情形，通过控制出度，考察同源竞争是否降低选中黄金后继的概率。通过与 E2 协同诊断，刻画同源竞争如何影响模型选中 $e_{dead}$ ，以及 $e_{dead}$ 如何在接口的作用下进一步呈现为非法路径的传导机制。

令 $D$ 表示每个 branch $k$ hop 黄金节点的出度候选集合，$d \in D\{1,2,3,4,5\}$：$d = 1$ 时只保留黄金路径，此时 branching 退化为 chain，$d = 3$ 时为主实验设定，记为 canonical，$d = \{2,4,5\}$ 留作扫描，用于揭露演化趋势。为保证边列表元素数量一致，E6 使用位置守恒的确定性重排。为避免 edge list 内容差异导致的跨 $d$ 排序结果不可比，E6 不使用依赖列表长度的 random shuffle，而采用 keyed 排序。对每条边 $e$ 被赋予确定性分数 $\mathrm{score}(e)=\mathrm{SHA256}(\mathrm{seed}_{\mathrm{sample}}\Vert \mathrm{src}(e)\to \mathrm{dst}(e))$。边列表按 $\mathrm{score}(e)$ 升序排列。由于 $\mathrm{score}(e)$ 仅依赖边的内容标识与样本种子，任意在多个 $d$ 条件下共有的边，其相对顺序在所有 $d$ 下保持一致。$d$ 增大时，新增的同源终止分支按同一公式插入确定位置；为保持总边数守恒而删除的背景干扰边，不改变其余边的相对顺序。同时，对于边数守恒（边列表元素数量守恒，则调整 $d$ 必然影响干扰边数量，进而影响黄金节点处竞争纯度）与竞争纯度守恒（干扰边数量不变，则调整 $d$ 比如影响边列表元素数量）问题，本实验采用折中处理，即增加背景干扰边总量，使得边数守恒下调整 $d$ 引发的干扰边变化占比较低。

同时，背景干扰边总量太多会加重 Lost-in-the-Middle，进而压低 $q_{\mathrm{reach}}$，并且放大 position effect ，因此干扰边具体数量判据为 $q_{\mathrm{reach}}$ 实测稳定性：在固定 $d=3$ 下，对 deepseek flash 在 jsoncot_strict 接口下进行背景扰动控制。该控制用于检验删除/重排背景边本身是否足以解释 E6 中观察到的跨 $d$ 效应。具体而言，在不改变任何路径节点出度与同源候选集合的前提下，在固定 $d=3$ 的条件下，随机替换数量等于主实验高出度条件中被替换数量的背景 distractor edges，并使用 3 个独立 seed 重新排列边列表，且 3 个 seed 使用同一组 200 个 sample_id。每个 seed 包含 200 张 G1 单图，共 $200 \times 3 = 600$ 次调用。若量级明显小于主 E6 中跨 $d$ 的 $q_{\mathrm{reach}}$ 变化，则说明主结果中的 $q_{\mathrm{reach}}$ 变化不能由背景边删除与重排构成的联合扰动解释。诊断指标如下：第一，主实验跨 d 的 $\Delta q_{reach}$ 变化，即 $\Delta q_{reach}=\max_d q_{\mathrm{reach}}(d)-\min_d q_{\mathrm{reach}}(d)$；第二，背景扰动控制中的 $q_{\mathrm{reach}}$ 波动。首先统计 background-perturbation control 下，$q_{\mathrm{reach}}$ 的 seed 间波动，即 $\mathrm{SD}_{q,\mathrm{BP}}=\operatorname{SD}_s\left(q_{\mathrm{reach}}^{\mathrm{BP}}(s)\right)$。其次统计在所有 background-perturbation control seed 里，$q_{\mathrm{reach}}$ 最大波动范围，即 $\mathrm{Range}_{q,\mathrm{BP}}=\max_sq_{\mathrm{reach}}^{\mathrm{BP}}(s)-\min_s q_{\mathrm{reach}}^{\mathrm{BP}}(s)$。如果 $\rho_{\mathrm{range}}=\frac{\mathrm{Range}_{q,\mathrm{BP}}}{\Delta q_{\mathrm{reach}}} \ll 1$ 且 $\rho_{\mathrm{sd}}=\frac{\mathrm{SD}_{q,\mathrm{BP}}}{\Delta q_{\mathrm{reach}}} \ll 1$，则 BP control  的影响不足以解释主实验中的 $q_{\mathrm{reach}}$ movement。

要注意的是，随调整 $d$ 同步调整的 $v_i​$ 出现次数是任务结构的自然产物，因为模型不知道干扰边不包括黄金节点这条生成规则，无法区分 $v_i​$ 后继多是因为是黄金节点还是碰巧干扰边都包含该节点。为排除地板效应与天花板效应，参考 E5 给出的 $q_{\mathrm{reach}}(k)$ 以及 $p_F^{cond}​(k)$，选取实验采用 $6$ hop，随后分别结合三种接口因子：direct_minimal（仅输出答案，不纳入 reach-conditioned 主指标）、jsoncot_basic（输出路径与答案，但不逐条强调约束）、jsoncot_strict（要求正确起点、恰好 $k+1$ 个节点、逐边合法和答案等于路径末节点），观察 prompt 对同源竞争的影响，每格调用 $400$ 次，即 $400$ 个 sample_id，共 $5200$ 次。

## B.7：同源候选竞争对位置锚定的瓦解

E7 的目的是用同一个最小干预，将答案层锚定与路径层非法联系起来，通过操纵 $v_{k-2}$ 节点的局部出度，从 direct_minimal 中的答案层锚定，到 jsoncot 中的终止/非法路径，二者共同构成联合诊断。$G = (G_1,G_2,G_3)$ 构造方法是，对于同一 chain $k$ hop，$G_3$ 使用原始链式图，与 $d$ 无关；$G_1,G_2$ 则仅控制 $v_{k-2}$ 节点的出度 $d$，称为修改后的链式图（modified chain，m-chain），且对于在 $v_{k-2}$ 注入的每个同源候选 $v_{k-1}^{\mathrm{dead},i},i\in\{1,\ldots,d-1\}$，应满足零出度 $\mathcal{N}^{+}(v_{k-1}^{\mathrm{dead},i})=\varnothing$ 与不指向黄金节点，从而 $|\mathcal{W}(G,s,k)|=1$ 在 $d\ge 2$ 下仍成立，其中 $d \in \mathcal{D} = \{1,2,3,4\}$，且当 $d = 1$ 时退化为原始 chain。全部的同源候选构成同源候选集合，即 $Z_{\mathrm{dead}}(v_{k-2},d)=\left\{v_{k-1}^{\mathrm{dead},i}\right\}_{i=1}^{d-1}$。$G_1$ 的末节点为黄金答案，$G_2$、$G_3$ 末节点则是在黄金答案后加一个 decoy last 节点 $z$。由于 $d=1$ 时不存在额外同源候选，因此 $G_2(1)\equiv G_3$；同时 $G_1​(1)$ 退化为无 decoy 的原始 chain，即 $G_1(1)\equiv G_{\mathrm{chain}}$。$G_1$ 用于诊断 b 类困难中的同源竞争，$G_2,G_3$ 用于计算同源竞争对位置捷径瓦解的影响。随着 $d$ 增加，应相应调整干扰边数量，以保持边列表元素总量不变。对于 $G_2(d)$ 与 $G_3$，首先将诱饵边 $e_z=(y,z)$ 从待排序边集合中移除，其余边按照与 E6 相同的 keyed SHA256 规则确定性排序，随后将 $e_z$ 固定追加为边列表最后一行。$G_1(d)$ 不包含 $e_z$，其全部边按照相同 keyed 规则排序。为保证跨 E 实验结果具有可比性，均使用同一 $\mathrm{keyed_{k,d,E}}$ 进行确定性重排。三种图的守恒规则不同，${G}_1(d)$ 和 $G_2(d)$ 要求边列表长度不随 $d$ 改变，由于 ${G}_1$ 不包含诱饵边 $e_z$，因此其边数比 ${G}_2/{G}_3$ 少一条。

E7 覆盖 4 / 6 / 8 hop 以及（direct_minimal、jsoncot_basic、jsoncot_strict）这三种 prompt 接口，$G_2/G_3$ 用于检测答案层，direct_minimal 足够；$G_1$ 用于检测路径层，必须依赖显式路径，故需 jsoncot。对每个基础样本 $j$ 和深度 $k$，构造共享节点池、黄金链与序列化种子的配对三图组 $G = (G_1,G_2,G_3)$，其中 $G_3$ 为 chain + decoy-last，作为答案层基线；$G_2(d)$ 是在 $G_3$ 上注入同源终止候选；$G_1(d)$ 与 $G_2(d)$ 共享同源候选，但移除 decoy edge，并切换到路径输出接口。对于某一 $k$ hop 图，每个 cell 包含 $400$ 次调用，$G_1$ 两个接口，每个接口四档 $d$，$2 \times 4 \times 400 = 3200$；$G_2$ 一个接口，四档 $d$，$1 \times 4 \times 400 = 1600$；$G_3$ 一个接口，无 $d$ 扫描，$1 \times 400 = 400$；每个 hop 下共 $3200 + 1600 + 400 = 5200$。由于 $G_2(1)\equiv G_3$、$G_1(1)\equiv G_{\mathrm{chain}}$ 因此调用数为 $5200 - 400 - 400 \times 2 = 4000$，三种 hop 下总次数为 $4000\times3=12000$。对于单一模型的完整单一 hop 的实验矩阵如下。

需要注意的是，由于 decoy last 位于 $k+1$ hop，因此 $G_3$ 中 EAR 揭示的是 hop 约束与末位显著节点间的竞争（模型要选 $z$ 必须违背恰好 $k$ 跳的约束），而 $G_2$ 在 $G_3$ 的基础上引入了同源终止分支，因此测量的是同源终止分支对末尾显著节点的瓦解作用，而 $G_1$ 由于检测的是 $v_{k-1}$ 处的正确率（即 b 类困难中的同源竞争），关闭了 decoy 通道，从而降低了末尾显著节点对实验指标的干扰。

$G_1$ 的主指标为 $p^{\mathrm{cond}}(d)$ 和 $p_{\mathrm{error}}(d)$，其中 $p^{\mathrm{cond}}(d)$ 表示$v_{k-1}$ 的局部正确率，即 $p^{\mathrm{cond}}(d)={\Pr}(\hat v_{k-1}=v_{k-1}\mid d,\text{前 }k-2\text{ hop 正确})$；$p_{\mathrm{error}}$ 的两个子指标为：终止分支 $p_{\mathrm{dead}}(d) = {\Pr}(\hat v_{k-1} \in Z_{\mathrm{dead}}(v_{k-2},d) \mid d,\text{前 } k-2 \text{ hop 正确})$ 与图外非法跳转率 $p_{\mathrm{illegal}}(d) = {\Pr}((v_{k-2},\hat{v}_{k-1})\notin E \mid d,\text{前 } k-2 \text{ hop 正确})$。指标及分析在 E2 / E5 / E6 中已作详细说明，此处不再赘述。$G_2$ 的统计指标为同源竞争下的 EAR（Same-Source Endpoint Anchoring Rate，SS-EAR），首先定义单样本指示变量为 $S_j(d)=\mathbf{1}\!\left[\hat{y}_{G_2(d)}^{(j)}=z^{(j)}\right]$，随后定义 $\mathrm{SS\text{-}EAR}(d)=\frac{1}{J}\sum_{j=1}^{J}S_j(d)$。主指标使用全样本有符号配对差 $\Delta\mathrm{EAR}_{\mathrm{ss}}^{\mathrm{all}}(d)=\frac{1}{J}\sum_{j=1}^{J}\left[E_j-S_j(d)\right] = \mathrm{EAR}_{G_3}-\mathrm{SS\text{-}EAR}(d)$，大于 0 表示加入同源竞争后，整体末位锚定减少；等于 0 表示整体锚定率不变。辅助指标为基线锚定子集中的瓦解率 $\mathrm{SS\text{-}EAR}^{\mathrm{cond}}(d)=\Pr\!\left(S_j(d)=1\mid E_j=1\right)$，$\Delta\mathrm{EAR}_{\mathrm{ss}}^{\mathrm{cond}}(d)=1-\mathrm{SS\text{-}EAR}^{\mathrm{cond}}(d)$，用于诊断已经发生末位锚定的样本中，有多少在注入同源竞争后不再锚定，并按 bootstrap 计算 95% CI。若 $\mathrm{SS\text{-}EAR}^{\text{cond}} \approx 1$，则位置捷径显著，模型更侧重直接使用末尾节点，而不论图中是否存在局部同源终止候选；若 $\mathrm{SS\text{-}EAR}^{\text{cond}} < 1$ 显著，则同源竞争瓦解位置捷径，同源终止候选成为局部可达但非 $k$-hop 合法答案的竞争项，激活了路径遍历。实验报告 95% 置信度下的 bootstrap CI。作为按基线行为分层的描述性分解，而不解释为独立因果效应

综上，$G_3$ 负责测量原始 decoy-last EAR；$G_2$ 负责在保持末位诱饵节点 $z$ 的同时，额外注入同源终止竞争，测量位置锚定是否被瓦解；$G_1$ 负责关闭 decoy-last 通道，仅保留同源终止竞争，用显式路径输出测量该结构是否转化为 dead-branch choice 与 illegal continuation。
