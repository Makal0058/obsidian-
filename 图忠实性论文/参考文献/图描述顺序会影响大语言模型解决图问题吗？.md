# 一、研究背景（前人做到哪一步）

## 1.1 大语言模型推理

大语言模型的推理能力和常识能力，已经被应用于多个领域的决策与行动任务。

- Yao 等人（2022）提出了 ReAct，**将推理与行动结合起来的提示方法**，尤其适用于需要自主规划和探索的复杂问题。

- Madaan 等人（2023）提出了 Self-Refine，通过反馈驱动的迭代改进机制，在推理过程中修正大语言模型产生的错误和幻觉。

- Shinn 等人（2023）提出了 Reflexion，**将语言形式的反馈存储在情景记忆中**，以提升语言智能体的决策能力。

- Sun 等人（2023）提出了 AdaPlanner，这是一种闭环规划方法，使大语言模型智能体能够根据环境反馈，自适应地调整原有计划。该方法结合了计划内调整和计划外调整策略，以改进序列决策能力。

- Zhou 等人（2023）提出了 Language Agent Tree Search，LATS，将蒙特卡洛树搜索、大语言模型驱动的价值函数和自我反思机制结合起来，通过整合推理、行动和规划，使语言智能体能够作出更加审慎和自适应的决策。
## 1.2 使用大语言模型进行图推理

- Wang 等人（2023a）提出了 NLGraph，是一个以自然语言形式描述图问题的基准，并提出了 Build-a-Graph 和 Algorithmic Prompting 等提示方法，以提高大语言模型在图推理任务中的表现。

- Fatemi 等人（2023）首次对如何将图结构数据编码为文本、供大语言模型处理进行了全面研究。发现，大语言模型在图任务上的表现取决于多个因素，包括：图的文本编码方式、具体的图任务、图本身的结构。

- Zhao 等人（2023）提出了 GraphText，**利用图语法树将图转换为自然语言**，从而促进人类与大语言模型之间围绕图结构进行交互式交流。

- Wei 等人（2024）提出了 GITA，是一个端到端框架，将视觉形式的图整合到一般图推理任务中。

- Das 等人（2023）使用多种模态对图进行编码，以提高大语言模型处理复杂图结构时的效率。

# 二、创新点与贡献

## 2.1 首次证明图描述顺序会显著影响大语言模型的图推理表现

过去研究主要关注：图怎么编码成文本、用什么提示词、用什么推理方法。但普遍忽视了一个变量：同一张图中的边，以什么顺序写进提示词

因此，论文把“图描述顺序”单独拿出来作为研究对象，并声称这是**首次全面分析**这一因素对 LLM 图推理表现的影响。
## 2.2 系统分析不同顺序对不同图任务的差异化影响

设计了四种结构化顺序：BFS、DFS、PageRank、Personalized PageRank。然后在六种图任务、六种主流模型和多种提示方式下进行实验。

论文声称发现：

- 有序描述通常优于随机顺序；
- 不同任务对顺序的敏感程度不同；
- 不存在对所有任务都统一最优的顺序；
- BFS 更适合连通性、环检测和最短路径；
- DFS 更适合哈密顿路径与拓扑排序；
- PageRank 类顺序更适合节点分类。

# 三、实验与结论（数据说明了什么、有什么局限性）

## 3.1 图描述顺序会显著影响 LLM 的图推理准确率

同一张图不改变节点和边，只改变边在文本中的排列顺序，模型表现就会明显变化。整体上，BFS、DFS、PageRank、PPR 等结构化顺序通常优于随机顺序。

例如：

- 连通性：随机 **78.36%**，BFS **89.43%**
- 环检测：随机 **64.50%**，BFS **72.71%**
- 哈密顿路径：随机 **31.50%**，DFS **52.43%**
- 拓扑排序：随机 **46.93%**，DFS **63.21%**
- 最短路径：随机 **30.14%**，BFS **51.29%**

因此，模型并不具备理想的**图序列化不变性**。
## 3.2 任务越复杂，对描述顺序通常越敏感

连通性、环检测等相对简单、偏局部的任务，在不同顺序下准确率波动较小。哈密顿路径、拓扑排序、最短路径等需要整合全局结构的任务，顺序造成的性能差异更大。

其中最短路径任务对顺序尤其敏感。作者将其解释为：加权图中的路径和权重关系更复杂，模型更依赖文本排列来重建结构。

值得注意的是：加入 CoT 并没有明显消除这种顺序敏感性。也就是说，让模型“逐步思考”，并不等于它就能稳定地忽略边的文本位置。
## 3.3 不同任务适合不同的描述顺序

论文没有找到一种对所有任务都最优的顺序，而是发现了明显的任务匹配关系：

- **BFS**：更适合连通性、环检测、最短路径；
- **DFS**：更适合哈密顿路径、拓扑排序；
- **PageRank 类顺序**：在节点分类中通常更好。

作者认为，这是因为：

- BFS 把局部邻接关系和层级结构组织得更清楚；
- DFS 把长路径和深层依赖连续放在一起；
- PageRank 更容易突出重要节点和有代表性的邻域。
## 3.4 性能提高有一部分来自“排序与答案重合”

作者专门在最短路径任务中设计了两种极端顺序：

- **Shortest Path Order**：把正确最短路径上的边优先排列；
- **Longest Path Order**：把一条较长、非最短路径优先排列。

结果是：

- 正确最短路径顺序达到 **78.57%**
- 比 BFS 还高
- 最长路径顺序则与随机顺序接近

这说明：排序是否与正确答案重合，是性能提高的重要因素。不是边排得“整齐”就一定有帮助，而是把正确答案相关的边排得连续、显眼，才特别有效。
## 3.5 顺序效应在多个模型上都存在，但强度不同

作者还在 Vicuna、Qwen2、Mistral、LLaMA2 等开源模型上复现实验。

总体规律仍然存在：

- 随机顺序通常较差；
- BFS、DFS 等结构化顺序通常有所帮助；
- 不同任务偏好的顺序不同。

因此，顺序敏感性不是 GPT-3.5 独有现象。

不过开源小模型上的改善通常弱于 GPT-3.5。作者认为，能力较弱的模型可能无法充分利用排序提供的结构线索。
