# 1.1 问题定义

**多臂老虎机问题（MAB 问题）：在未知奖励分布的多个动作中，通过不断试错学习，在有限步数内最大化累计奖励的问题。**
   
1. 符号定义：多臂老虎机问题可以表示为一个元组 $\langle\mathcal{A},\mathcal{R}\rangle$
   
- $\mathcal{A}$：动作集合，其中一个动作表示拉动一根拉杆。若多臂老虎机一共有 $K$ 根拉杆，那么动作空间就是集合 ${a_1,\cdots,a_i,\cdots,a_K}$，用 $a_t\in\mathcal{A}$ 表示任意一个动作

- $\mathcal{R}$ ：奖励概率分布，拉动每一根拉杆的动作 $a$ 都对应一个奖励概率分布 $\mathcal{R}(r\mid a)$，拉动不同拉杆的奖励分布通常是不同的。

2. 每个时间步只能拉动一根拉杆，多臂老虎机的目标为**最大化一段时间步 $T$ 内累积的奖励：$\max\sum_{t=1}^{T}r_t, r_t\sim\mathcal{R}(\cdot\mid a_t)$**，其中 $a_t$ 表示在第 $t$ 个时间步拉动某一拉杆的动作，$r_t$ 表示动作 $a_t$ 获得的奖励。

3. 懊悔：拉动当前拉杆的动作 $a$ 与最优拉杆的期望奖励差，即 $R(a)=Q^*-Q(a)$

累积懊悔（cumulative regret）：操作 $T$ 次拉杆后累积的懊悔总量，对于一次完整的 $T$ 步决策 ${a_1,a_2,\ldots,a_T}$，累积懊悔为 $\sigma_R=\sum_{t=1}^{T}R(a_t)$。MAB 问题的目标为最大化累积奖励，**等价于最小化累积懊悔**。

4. 期望奖励估值：$\hat{Q}(a_t)=\hat{Q}(a_t)+\frac{1}{N(a_t)}\left[r_t-\hat{Q}(a_t)\right]$

新估计值 = 旧估计值 + 步长 × 误差（$\hat{Q}_{\text{新}}=\hat{Q}_{\text{旧}}+\frac{1}{N}\left(r-\hat{Q}_{\text{旧}}\right)$），其中 $r-\hat{Q}_{\text{旧}}$ 表示实际奖励与之前平均奖励之间的差距，也叫“估计误差”或“预测误差”。

$\frac{1}{N}$ 表示这次奖励对平均值有多大影响

# 导入需要使用的库
# numpy 支持数组和矩阵运算，matplotlib 是绘图库
import numpy as np
import matplotlib.pyplot as plt

*注：matplotlib 是数据可视化库、pyplot 是 matplotlib 里用来画图的模块


class BernoulliBandit:
    """伯努利多臂老虎机，输入 K 表示拉杆个数"""

    def __init__(self, K):
    
    *注：self.变量 表示该对象自己的变量；self.方法() 表示调用该对象自己的方法
    
        # 随机生成 K 个 0～1 之间的数，作为每根拉杆的获奖概率
        self.probs = np.random.uniform(size=K)

        # 获奖概率最大的拉杆编号
        self.best_idx = np.argmax(self.probs)

        # 最大的获奖概率
        self.best_prob = self.probs[self.best_idx]
        
        *注：[self.best_idx] 表示用 self.best_idx 作为下标，从数组中取出对应位置的元素

        # 拉杆数量
        self.K = K

    def step(self, k):
        """
        拉动第 k 根拉杆。

        根据第 k 根拉杆的获奖概率：
        获奖返回 1，未获奖返回 0。
        """
        if np.random.rand() < self.probs[k]:
            return 1
        else:
            return 0


# 设置随机种子，使实验结果可以重复
np.random.seed(1)

# 创建一个 10 臂老虎机
K = 10
bandit_10_arm = BernoulliBandit(K)

print("随机生成了一个%d臂伯努利老虎机" % K)

print(
    "获奖概率最大的拉杆为%d号，其获奖概率为%.4f"
    % (bandit_10_arm.best_idx, bandit_10_arm.best_prob)
)

import numpy as np


class Solver:
    """多臂老虎机算法基本框架"""

    def __init__(self, bandit):
        self.bandit = bandit

        # 每根拉杆的尝试次数
        self.counts = np.zeros(self.bandit.K)
        
        *注：np.zeros(长度)，创建一个全是 0 的数组

        # 当前累积懊悔
        self.regret = 0.0

        # 记录每一步选择的动作
        self.actions = []

        # 记录每一步的累积懊悔
        self.regrets = []

    def update_regret(self, k):
        """
        计算并保存累积懊悔
        k 为本次选择的拉杆编号
        """
        self.regret += (
            self.bandit.best_prob
            - self.bandit.probs[k]
        )
        
        *注：
        1. += 表示把右边的值加到左边原来的值上，再保存回左边。
        
        2. 换行只是为了让代码更容易看懂，外面有一对圆括号，括号没结束，择下一行仍然属于同一条语句
        
        3. self.bandit.best_prob - self.bandit.probs[k] 表示最优拉杆的中奖概率 − 当前选择的第 k 根拉杆的中奖概率

        self.regrets.append(self.regret)
        
        *注：self.regret 表示当前的累积懊悔值，是一个数字；self.regrets 表示保存每一步累积懊悔的列表

    def run_one_step(self):
        """
        返回当前选择的拉杆编号，
        由具体的算法子类实现
        """
        raise NotImplementedError
        
        *注：raise NotImplementedError 表示这个方法在父类中还没有具体实现，必须由子类重新编写。

    def run(self, num_steps):
        """
        运行算法 num_steps 次
        """
        for _ in range(num_steps):
            # 运行一步，得到选择的拉杆编号
            k = self.run_one_step()

            # 记录该拉杆被选择的次数
            self.counts[k] += 1

            # 记录本次动作
            self.actions.append(k)

            # 更新累积懊悔
            self.update_regret(k)
