# 一、研究背景
## 1.1 前人做到哪一步

近年来，强化学习（Reinforcement Learning，RL）已成为大语言模型后训练的重要方法。以 DeepSeek-R1 等模型为代表的研究表明，**即使仅使用最终结果奖励（Outcome Reward），模型也能够通过强化学习提升数学推理、代码生成等任务的表现**。这说明模型不仅能够通过监督微调模仿已有答案，还能够通过探索和奖励反馈学习解决问题的策略。

在此基础上，研究者逐渐将强化学习扩展到多轮交互的智能体任务（Agentic RL）。典型方法采用 ReAct 框架，使模型按照**思考（Thought）→ 行动（Action）→ 观察（Observation）** 的流程与外部环境交互，并通过工具调用逐步完成复杂任务。与此同时，GRPO（组相对策略优化）等方法通过对同一问题采样多条完整轨迹，比较不同轨迹的最终奖励，从而估计优势并优化模型策略。
## 1.2 现有方法的主要问题

**第一个问题是多轮智能体强化学习的采样成本过高。** 现有方法通常为同一任务独立生成多条完整交互轨迹，每条轨迹都需要模型反复推理、调用工具并处理环境反馈。由于不同轨迹可能包含大量相同的前期操作，独立采样会产生严重的重复计算和工具调用开销，限制强化学习的训练效率。

**第二个问题是最终结果奖励难以提供细粒度的过程监督。** 传统方法通常只在整条轨迹结束后给出一个奖励，再将由此估计的优势分配给轨迹中的所有步骤。然而，一条轨迹可能同时包含正确决策和错误决策，仅凭最终结果难以判断哪些中间操作真正促进了任务成功。这种粗粒度的信用分配（Credit Assignment）使长序列决策的学习更加困难，甚至可能导致训练不稳定或崩溃。

已有研究尝试利用过程奖励模型（Process Reward Model，PRM）提供中间步骤的监督信号，但这通常需要额外的过程标注或奖励模型训练，增加了数据与计算成本。因此，**如何在不引入额外过程奖励的情况下，从有限的最终结果奖励中提取更细粒度的学习信号，成为智能体强化学习的重要问题。**
## 1.3 本文的研究切入点

针对上述问题，本文提出 Tree-GRPO（基于树搜索的组相对策略优化），其核心思想是：**将传统的独立链式轨迹采样改为共享前缀的树状采样，同时利用树结构中不同分支的结果差异构造过程级学习信号**。

在采样阶段，方法首先生成若干条完整交互轨迹，再随机选择已有轨迹中的中间节点，从该节点继续生成新的后续轨迹，形成树状结构。与以 Token 或句子为节点的树搜索方法不同，Tree-GRPO 将一次完整的思考、行动和观察过程作为树节点。这使不同轨迹能够共享此前已经完成的推理与工具调用，从而降低采样成本。

在策略优化阶段，本文利用树结构中的分支关系，将最终奖励转化为对中间决策的相对偏好。具体而言，方法根据各分支最终获得的奖励，分别计算树内优势（Intra-tree Advantage）和树间优势（Inter-tree Advantage），并将两者结合用于策略更新。**树内比较提供隐式的步骤级偏好监督，树间比较则有助于稳定优势估计**。

因此，本文并非通过训练额外的过程奖励模型来解决奖励稀疏问题，而是**通过重新组织强化学习的采样结构，使最终结果奖励同时承担轨迹评价和中间决策比较的作用**，从而在控制采样成本的同时提升多轮智能体强化学习的效果。
# 二、创新点与贡献
## 2.1 基于智能体交互步骤的树状采样机制

本文的第一个创新点是**将传统强化学习中相互独立的链式轨迹采样，改为共享历史前缀的树状采样（Tree-based Rollout）**，从而减少重复推理与工具调用产生的开销。

传统 GRPO 针对同一问题独立生成多条完整轨迹，每条轨迹都需要从初始状态执行到最终结果。Tree-GRPO 则首先生成若干条完整轨迹作为初始树，再随机选择树中的非叶子节点，从该节点继续生成新的后续轨迹。这样，新轨迹可以直接复用已有的历史交互过程，而不必重新执行此前的所有步骤。

与已有基于 Token 或句子进行分支的树搜索方法不同，**Tree-GRPO 将一次完整的智能体交互步骤作为树节点**，即思考（Thought）、行动（Action）和观察（Observation）的组合。这种设计既符合智能体与环境交互的自然结构，也使树搜索能够同时减少 Token 生成和外部工具调用的成本。

具体而言，树状采样包含三个阶段：

1. **初始化（Initialization）**：针对同一问题生成 $M$ 条独立的完整轨迹，构建 $M$ 棵初始树。
2. **节点采样（Sampling）**：在每棵树中随机选择 $N$ 个非叶子节点，作为新的分支起点。
3. **分支扩展（Expansion）**：保留从根节点到选中节点的历史上下文，由策略模型继续生成后续交互轨迹，并将结果添加到原树中。

重复上述采样和扩展过程 $L$ 轮后，最终得到的完整轨迹数量为：$G=M(LN+1)$

**该机制的核心优势是通过复用已有轨迹的前半部分，以较低的额外成本产生更多训练样本。** 论文指出，在一定的树结构配置下，相同采样预算能够获得约 1.5 倍的完整轨迹样本。
## 2.2 结合树内与树间比较的优势估计

本文的第二个创新点是**利用树结构中的分支关系，将传统的轨迹级优势估计扩展为树内与树间两个层次的相对优势估计**，从而改善长序列决策中的信用分配问题。

传统 GRPO 根据同一问题下多条完整轨迹的最终奖励计算相对优势，并将同一轨迹的优势用于其中各个生成步骤。这种方法只能评价整条轨迹的总体表现，无法充分区分不同中间决策的贡献。

Tree-GRPO 引入两个互补的优势估计：

**（1）树内优势（Intra-tree Advantage）**

树内优势通过比较同一棵树中不同完整轨迹的最终奖励，衡量它们相对于树内其他轨迹的表现。由于这些轨迹可能共享相同的历史前缀，因此，它们的结果差异能够提供关于分支决策优劣的学习信号。

例如，两条轨迹在前三步完全相同，但从第四步开始选择不同的搜索行动，最终一条成功、一条失败。通过比较两条轨迹的最终奖励，模型便能够获得关于分叉后决策方向的相对偏好信息。

**（2）树间优势（Inter-tree Advantage）**

树间优势则将同一问题生成的所有树中的完整轨迹放在同一个组内，根据整体奖励分布计算相对优势。由于单棵树中的分支数量可能较少，仅使用树内奖励估计容易产生较大的方差，甚至导致训练不稳定。因此，树间优势提供了覆盖范围更大的比较基准，用于稳定策略更新。

对于完整轨迹 $H_i$，本文将最终优势定义为：$\hat A_{\mathrm{tree}}(H_i)=\hat A_{\mathrm{intra}}(H_i)+\hat A_{\mathrm{inter}}(H_i)$。其中，两种优势均通过对应分组内的奖励均值和标准差进行归一化计算。

**这种设计使 Tree-GRPO 既能够利用共享前缀下的分支差异进行局部比较，又能够通过全局分组维持优势估计的稳定性。**
## 2.3 利用最终奖励实现隐式的步骤级偏好学习

本文的第三个创新点是**证明树内 GRPO 与步骤级直接偏好优化（Step-level DPO）具有相同形式的偏好梯度结构，从而解释树状采样为什么能够从最终奖励中产生过程监督信号。**

传统强化学习的结果奖励只能直接反映完整轨迹的成功或失败。若希望判断某个中间步骤是否合理，通常需要额外设计过程奖励模型，或者构造步骤级偏好数据。

Tree-GRPO 则利用共享前缀形成的树结构，在分叉节点之后比较不同后续轨迹的最终结果。例如，在相同历史状态下，模型可以选择行动 A 或行动 B。如果行动 A 对应的后续轨迹成功，而行动 B 对应的后续轨迹失败，那么两者便形成了一组隐式偏好关系。

论文进一步从理论上分析了这种机制。在二元奖励假设下，树内 GRPO 与步骤级 DPO 的梯度均可以表示为：$\nabla_\theta J=w\left[\nabla_\theta\log p_\theta(H_{\ge t}^{\mathrm{win}})-\nabla_\theta\log p_\theta(H_{\ge t}^{\mathrm{loss}})\right]$。其中，$H_{\ge t}^{\mathrm{win}}$ 和 $H_{\ge t}^{\mathrm{loss}}$ 分别表示从某个中间节点出发的成功与失败后续轨迹，$w$ 表示对应的梯度权重。

两种方法的主要区别在于权重项的计算方式，而偏好梯度的基本结构相同。这意味着，**Tree-GRPO 能够在不额外构造步骤级偏好数据的情况下，通过在线强化学习隐式地优化中间决策的相对偏好。**

需要明确的是，这种过程监督是通过共享前缀和后续轨迹比较间接形成的，并不意味着算法为每个中间步骤都预测了独立、准确的奖励值。此外，理论等价性针对特定的二元偏好假设与梯度结构，并不意味着完整的 Tree-GRPO 训练目标与 DPO 完全相同。
## 2.4 提高有限采样预算下的强化学习效率

在上述机制基础上，本文进一步将树状采样和双层优势估计整合到 GRPO 的在线强化学习框架中，形成完整的 Tree-GRPO 算法。

**本文的贡献不仅在于减少采样成本，还在于改变相同训练预算所能提供的监督信息。** 一方面，共享历史前缀减少重复计算，使有限预算能够支持更多完整轨迹；另一方面，树结构保留了不同轨迹之间的分叉关系，使模型能够从原本粗粒度的最终奖励中提取更细粒度的偏好信息。

论文在单跳问答、多跳问答和网络智能体问答等任务中验证了上述设计。实验表明，Tree-GRPO 相比传统链式 GRPO 通常能够获得更好的任务表现，尤其是在需要多轮交互、训练预算受限以及模型规模较小的情况下，改善更加明显。

**总体而言，本文的核心贡献是将树搜索从一种轨迹探索和采样手段，进一步转化为强化学习中的隐式过程监督机制，实现了采样效率与学习信号质量的共同改善。**
# 三、实验与结论
## 3.1 实验数据与设置

本文在 **11 个数据集、3 类问答任务**上评估 Tree-GRPO，主要检验树状采样能否提高强化学习的训练效率，以及基于树结构的优势估计能否改善多轮智能体的决策能力。

实验任务分为三个类别：

1. **单跳问答（Single-Hop QA）**：包括 NQ、TriviaQA 和 PopQA，共 3 个数据集。训练使用 NQ 的 79,168 个问答样本，主要考察模型通过一次信息检索回答问题的能力。
2. **多跳问答（Multi-Hop QA）**：包括 HotpotQA、2WikiMultiHopQA、MuSiQue 和 Bamboogle，共 4 个数据集。训练使用 HotpotQA 的 90,447 个样本，主要考察模型通过多轮搜索、整合不同信息完成推理的能力。
3. **网络智能体问答（Web-Agent QA）**：包括 SimpleQA、GAIA、WebWalkerQA 和 BrowseComp，共 4 个数据集。训练使用 2,200 个问答样本，主要考察模型在真实网络搜索环境中解决复杂问题的能力。

实验采用 Qwen2.5 和 Llama3.2 系列模型，涵盖 1.5B、3B、7B 和 14B 等参数规模。对比方法包括直接推理、ReAct、Search-o1、GRPO 和 GSPO。其中，**GRPO 是最主要的对照方法，用于检验树状采样相对于传统独立链式采样的优势**。

单跳和多跳问答使用基于维基百科的本地检索工具，网络智能体任务则使用真实搜索接口。前两类任务采用精确匹配率（Exact Match，EM）评价结果，网络智能体任务采用 F1 分数。默认采样预算相当于每个问题生成 4 条完整轨迹的成本，并在不同预算、树结构和优势估计方式下开展消融实验。
## 3.2 实验数据说明了什么
### 3.2.1 树状采样显著改善多轮推理表现

实验结果表明，**Tree-GRPO 在多跳问答任务上的提升明显高于单跳问答，且对小规模模型尤其有效**。

在 Qwen2.5-1.5B 上，传统 GRPO 的多跳问答平均准确率为 11.3%，Tree-GRPO 提升至 19.1%，相对提高约 69%。在 Qwen2.5-3B 上，平均准确率由 31.8% 提升至 36.8%；在 Llama3.2-3B 上，则由 26.7% 提升至 36.8%。

相比之下，单跳问答的提升相对有限。例如，Qwen2.5-3B 的平均准确率由 48.1% 提升至 50.0%。这说明树结构提供的学习信号更适合需要多次交互的任务，因为轨迹越长，不同中间决策之间的差异越值得单独学习。
### 3.2.2 树状采样提高了有限预算下的训练效率

论文进一步在不同采样预算下比较链式采样与树状采样，发现**训练预算越紧张，树状采样在多跳问答任务上的优势越明显**。

以 Qwen2.5-3B 为例，当每个问题的预算仅相当于 2 条完整轨迹时，传统链式 GRPO 的多跳问答平均准确率为 14.9%，Tree-GRPO 达到 31.6%，相对提升约 112%。

当采样预算增加至 4 条完整轨迹时，Tree-GRPO 达到 36.8%，仍高于传统 GRPO 的 31.8%。即使将传统 GRPO 的预算提高至 16 条完整轨迹，其准确率也只有 33.9%，低于预算为 4 的 Tree-GRPO。

**这表明 Tree-GRPO 不仅减少了重复采样的开销，还能够在相同预算下提供更有效的训练信号。** 其收益并非单纯来自生成更多轨迹，也与共享前缀形成的分支比较有关。
### 3.2.3 树内与树间优势具有互补作用

论文通过消融实验验证了两种优势估计方式的作用。在采样预算为 4 的条件下，仅使用树内优势会导致训练崩溃；仅使用树间优势时，多跳问答平均准确率为 33.8%；而将两者结合后，准确率达到 36.8%。

当采样预算提高至 8 时，仅使用树内优势能够达到 34.6%，仅使用树间优势为 33.4%，两者结合则达到 36.4%。

这些结果说明，**树内优势能够提供有价值的局部分支比较信号，但需要足够的分支样本才能形成稳定估计；树间优势则能够补充更可靠的全局比较基准。** 两者结合，使模型能够兼顾过程偏好学习和训练稳定性。

此外，论文比较了不同粒度的树搜索。在相同预算下，基于 Token 或句子级节点的树搜索仅取得 22.2% 的多跳问答平均准确率，低于传统 GRPO 的 31.8%；而以完整智能体交互步骤为节点的 Tree-GRPO 达到 36.8%。

这一结果进一步支持了本文的设计：**对于具有明确行动和环境反馈结构的智能体任务，以完整交互步骤作为树节点，比任意选择 Token 位置进行分叉更加有效。**
### 3.2.4 树状强化学习促进了多轮交互能力

除回答准确率外，论文还分析了模型的工具调用行为。实验发现，在多跳问答任务中，树状强化学习能够使模型平均工具调用次数由约 2.4 次增加至 3.0 次，同时获得更高的训练奖励。

这一结果说明，Tree-GRPO 不仅改善最终答案的质量，还能够促使模型学习更充分的多轮信息检索行为。对于需要多次搜索才能找到答案的任务，模型不再那么容易过早结束交互。

在网络智能体任务中，Tree-GRPO 同样取得改善。例如，Qwen2.5-14B 在 GAIA 上的平均 F1 分数由 16.4 提升至 21.0，相对提高约 28%。不过，在更加困难的 BrowseComp 上，F1 分数仅由 2.4 提升至 2.6，说明其在复杂长程任务上的绝对表现仍然有限。
## 3.3 本论文的局限性
### 3.3.1 对复杂长程任务的验证仍然有限

本文虽然研究多轮智能体强化学习，但实验主要集中于搜索问答场景，尚未充分覆盖复杂的长期规划与决策任务。实验中，单跳和多跳问答最多允许 3 次工具调用，网络智能体任务最多允许 5 次工具调用。

对于需要十几次甚至几十次交互才能完成的复杂任务，现有实验还不能充分说明 Tree-GRPO 的优势能否保持。此外，网络智能体训练集仅包含 2,200 个样本，作者也明确指出训练数据的规模和难度限制了模型在高难度测试集上的提升。
### 3.3.2 树搜索仍采用随机扩展策略

Tree-GRPO 通过随机选择已有轨迹中的非叶子节点产生新分支，而不是根据节点的不确定性、预期收益或潜在信息价值决定在哪里展开搜索。

这种方式实现简单，但**没有直接学习哪些中间决策值得投入更多搜索预算**。论文的树结构实验也表明，减少独立初始树的数量虽然能够节省预算，却可能限制探索多样性，进而影响最终性能。

因此，如何在探索不同思路和深入比较已有思路之间动态分配计算资源，仍然是可以进一步研究的问题。
### 3.3.3 过程监督仍然依赖最终奖励

虽然 Tree-GRPO 能够利用分支比较获得隐式过程监督，但这些信号本质上仍由最终结果奖励推导出来，并不是对每一步决策质量的直接评价。

**共享前缀能够减少不同轨迹之间的干扰因素，但最终结果的差异仍可能由分叉后的多个步骤共同造成。** 因此，该方法可以优化不同后续轨迹的相对偏好，却不能保证准确识别某个具体步骤对最终结果的独立贡献。

此外，论文关于树内 GRPO 与步骤级 DPO 的理论联系建立在特定二元偏好假设下，其结论主要是两者具有相同形式的偏好梯度结构，并不意味着所有实际训练条件下都具有完全相同的优化行为。

总体而言，**Tree-GRPO 的主要贡献是证明树结构可以同时提高采样效率和强化学习监督信号的有效性，而其尚未完全解决的问题，是如何自适应地选择探索分支，以及如何进一步准确地评价中间决策。**
