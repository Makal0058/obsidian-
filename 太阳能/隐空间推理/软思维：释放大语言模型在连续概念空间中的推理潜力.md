# 一、研究背景（前人做到哪一步）
## 1.1 传统方法：大模型主要在离散语言空间中进行推理

目前，大语言模型最常用的推理方式是 **思维链（Chain-of-Thought, CoT）**。它的基本过程是 $x \rightarrow t_1 \rightarrow t_2 \rightarrow \cdots \rightarrow t_m \rightarrow y$，其中每一步 $t_i$ 都是一个**离散 token**。也就是说，在每一步推理时，模型都会先预测整个词表上的概率分布：$p(t_i\mid x,t_{<i})$，然后再从这个概率分布中选择一个 token，继续下一步推理。 
## 1.2 问题一：每一步都必须“硬选”一个 token

传统 CoT 的核心限制在于**模型每一步必须从多个可能性中选出唯一一个 token**。例如模型下一步可能认为：$P(A)=0.4,\quad P(B)=0.35,\quad P(C)=0.25$，传统 CoT 最后只能选 $A$，那么 $B$ 和 $C$ 所包含的信息就被直接丢掉了。因此，模型一旦在早期选错，就可能沿着错误路径一直走下去。
## 1.3 问题二：语言 token 本身限制了推理表示能力

传统 CoT 不仅是“逐步推理”，它还有一个更深层的限制：**所有中间思维都必须被表达成人类语言 token**。例如一个模型内部可能存在某种复杂、模糊或尚未完全确定的概念，但最终必须被压缩成：$\text{一个具体 token}$

论文认为，这可能限制模型表示：
- 抽象概念
- 模糊状态
- 多个可能含义
- 多条候选推理路径

因此，作者提出：推理不一定必须发生在离散自然语言空间中，也可以发生在连续概念空间中。
## 1.4 前人已经开始研究连续空间推理

在 Soft Thinking 之前，已经有一些工作开始探索：$\text{离散 token 推理} \rightarrow \text{连续表示推理}$

已有研究发现：
- 多跳推理信息可以存在于模型 hidden representation 中；
- 可以直接干预 hidden state 改变推理结果；
- 模型内部可能同时存在多个并行推理路径；
- 也有方法尝试在抽象表示空间，而不是普通 token 空间中进行推理。 

其中比较典型的是 **COCONUT**，COCONUT 的思路是：$h_t \rightarrow \text{作为下一步输入}$，也就是直接把上一轮模型的最后层 hidden state 作为下一轮推理的输入 embedding。 
## 1.5 现有连续推理方法仍存在表示空间不匹配

论文指出，直接使用 hidden state 也存在一个重要问题：$\text{hidden state space} \neq \text{input embedding space}$，对于部分大型模型而言：**输出 hidden state 所在空间与输入 token embedding 所在空间并不天然一致**。

如果直接把 hidden state 塞回输入层，就会出现**representation mismatch（表示空间不匹配）**。因此，一些连续推理方法往往需要额外训练进行对齐，而额外训练又可能导致：

- 过拟合；
- 灾难性遗忘；
- 训练成本增加；
- 实际效果不稳定。 Soft_Thinking_Unlocking_the_Rea…
## 1.6 Soft Thinking 要解决的问题

所以这篇论文真正想解决的是：**能不能在不重新训练模型的情况下，让模型从离散 token 推理转向连续空间推理**？作者的核心想法不是直接使用 hidden state，而是利用模型本身已经输出的：$\text{Vocabulary Probability Distribution}$ 作为中间桥梁。

也就是说，从 $\text{选一个 token}$ 改成 $\text{保留整个 token 概率分布}$，再将多个 token embedding 加权混合，形成一个连续的 **concept token（概念 token）**，继续进行推理。 

因此，这篇工作的出发点可以概括为：$\boxed{\text{离散单路径 CoT} \rightarrow \text{连续、概率混合的概念空间推理}}$，并且作者希望做到：$\boxed{\text{Training-Free Continuous Reasoning}}$，也就是**不额外训练模型，就让现有 LLM 在连续概念空间中推理**。
# 二、创新点与贡献
## 2.1 提出 Soft Thinking：把离散 token 推理改成连续概念空间推理

这篇论文最核心的创新是提出 **Soft Thinking**。传统 CoT 每一步都会从词表概率分布中选出一个具体 token $p_t \rightarrow t_t$，而 Soft Thinking 不再立刻把概率分布压缩成一个 token，而是保留整个分布 $ct_t := p_t$，作者把这个完整的概率向量称为 $\boxed{\text{Concept Token}}$，也就是“概念 token”。

因此，模型中间推理过程从 $\text{离散 token} \rightarrow \text{离散 token}$ 变成 $\text{概率分布} \rightarrow \text{连续向量} \rightarrow \text{概率分布}$，从而让推理发生在连续概念空间中。
## 2.2 用概率加权 token embedding 构造 Concept Token

Soft Thinking 并不是直接把概率向量本身送进 Transformer，而是用概率对所有 token embedding 做加权 $\tilde e_{t+1} = \sum_{k=1}^{|V|} p_t[k],e(k)$，也就是说，如果模型认为 $P(A)=0.5,\quad P(B)=0.3,\quad P(C)=0.2$，那么下一步输入不是单独的 $A$，而是 $0.5e(A)+0.3e(B)+0.2e(C)$。因此，一个中间状态可以同时包含多个 token 所代表的语义。

论文把所有这种概率加权得到的向量集合定义为 $\mathcal{C}=\left\{\sum_k \alpha_k e(k)\mid \alpha\in\Delta^{|V|-1}\right\}$，也就是 token embedding 的**凸组合空间**。 
## 2.3 不直接使用 hidden state，而用词表概率分布作为桥梁

这是这篇论文和 COCONUT 很关键的区别。COCONUT 类方法可以直接把上一轮的 hidden state：$h_t$ 作为下一轮输入。但论文指出 $\text{hidden state space} \neq \text{input embedding space}$，尤其在部分大型模型中，hidden state 和输入 embedding 不天然对齐，直接回灌可能产生表示空间不匹配。

Soft Thinking 则改成 $h_t \rightarrow p_t \rightarrow \sum_k p_t[k]e(k)$，也就是先通过模型本身的输出头得到词表概率，再重新回到原始 embedding 空间。因此作者把 $\boxed{\text{词表概率分布}}$ 当作 hidden representation 和 input embedding 之间的桥梁。
## 2.4 Training-Free：不需要重新训练模型

Soft Thinking 的另一个主要贡献是：$\boxed{\text{Training-Free}}$

也就是说，它不需要：
- 额外微调；
- 增加新网络层；
- 修改模型参数；
- 专门训练 latent reasoning。

它直接复用模型已有的：
- embedding matrix；
- vocabulary distribution；
- Transformer 本体。

论文明确说明，没有权重更新，也没有额外训练流程，只需要修改推理时的数据流。 这也是它相较很多连续推理方法最大的工程优势之一。
## 2.5 用“软分布”保留多个可能推理方向

传统 CoT 每一步：$p_t \rightarrow \text{sample one token}$，一旦选了一个 token，其他概率质量就被丢掉；Soft Thinking 则保留 $p_t$ 的多个高概率候选。因此作者认为，一个 concept token 可以同时保留多个可能的语义和推理方向。比如 $P(A)=0.45,\quad P(B)=0.35,\quad P(C)=0.20$，传统 CoT 只能继续 $A$。而 Soft Thinking 下一步输入 $0.45e(A)+0.35e(B)+0.20e(C)$，于是 $A,B,C$ 三种可能性都在后续状态中留下影响。

作者把这种机制解释为 $\boxed{\text{隐式并行探索多条推理路径}}$，而不是显式枚举多条 CoT。
## 2.6 提出 Cold Stop：利用熵控制何时停止连续推理

Soft Thinking 还有一个很重要的配套机制 $\boxed{\text{Cold Stop}}$，问题在于，模型训练时从来没有真正见过这种概率加权的连续 concept token。所以推理时间一长，就可能进入 OOD 状态，出现：
- 重复；
- 不稳定；
- generation collapse。

为此作者计算每一步词表分布的熵 $H(p) = -\sum_k p[k]\log p[k]$，如果熵持续较低，说明模型已经非常确定。于是 $H(p)<\tau$，连续出现 $k$ 步后，就提前结束 thinking 阶段。论文把这种低熵、高置信度状态称为“cold”，因此叫 Cold Stop。
## 2.7 给出 Soft Thinking 对多路径求和的理论解释

论文不仅提出方法，还给了一个理论解释。标准 CoT 最理想的情况其实应该对所有可能的推理路径求和：$p(y|x) = \sum_{t_1} \sum_{t_2} \cdots \sum_{t_m} p(t_{1},y|x)$，但如果真的枚举所有路径，计算量会指数增长。

Soft Thinking 的想法是用每一步 token 分布的期望 $ct_t=\mathbb E[t_t]$ 代替对所有离散路径逐个计算。经过逐步的一阶线性近似，作者得到 $p(y|x) \approx p(y|x,ct_1,\dots,ct_m)$，也就是说用一个连续 concept token 序列，近似聚合大量离散推理路径。

这给“为什么一个加权 embedding 可能同时保留多条路径信息”提供了理论解释。 
## 2.8 实验上同时提高准确率和推理效率

作者最后强调的贡献不是只提升准确率，而是同时改善 $\text{Accuracy}$ 和 $\text{Generation Efficiency}$，在 QwQ-32B 上，数学任务平均 Pass@1 从 $83.84\% \rightarrow 86.32\%$，提升 $+2.48$ 个百分点。同时不同模型上，生成长度最多减少 $22.4\%$，而且数学和代码任务上都观察到了类似趋势。 

注：
- $\text{多路径+剪枝}$ 是真的维护 $z^{(1)},z^{(2)},z^{(3)}$
- Soft Thinking 更像 $\bar z=\sum_i \alpha_i z^{(i)}$
前者保留“**多样性**”更好，后者保留“**效率**”更好。
# 三、实验与结论（数据说明了什么、有什么局限性）
## 3.1 实验设置

作者主要在数学和代码任务上验证 Soft Thinking，包括：
- 数学：MATH500、AIME 2024、GSM8K、GPQA-Diamond
- 代码：HumanEval、MBPP、LiveCodeBench

使用的模型包括：
- QwQ-32B
- DeepSeek-R1-Distill-Qwen-32B
- DeepSeek-R1-Distill-Llama-70B

主要比较：
- 标准 CoT
- Greedy CoT
- Soft Thinking

评价指标主要是 $\text{Pass@1}$ 以及 $\text{Generation Length}$，也就是同时看**准确率**和**推理生成长度**。    
## 3.2 准确率：有稳定提升，但幅度并不大

Soft Thinking 在数学和代码任务上整体都比标准 CoT 更好。

以 QwQ-32B 的数学任务为例 $83.84\% \rightarrow 86.32\%$，平均提升 $+2.48$ 个百分点；DeepSeek-R1-Distill-Qwen-32B：$81.32\% \rightarrow 83.03\%$，提升 $+1.71$ 个百分点；DeepSeek-R1-Distill-Llama-70B $81.31\% \rightarrow 82.42\%$，提升 $+1.11$ 个百分点。代码任务上的提升更小，大约只有 $+0.48\sim+0.90$ 个百分点。    

因此实验更合理的结论不是 Soft Thinking 大幅提高了推理能力，而是 $\boxed{\text{Soft Thinking 带来了稳定但有限的准确率提升}}$
## 3.3 推理效率：比准确率提升更明显

相比准确率，Soft Thinking 在减少生成长度方面效果更明显。

数学任务中，相比标准 CoT：

- QwQ-32B：减少约 $11.6\%$
- DeepSeek-Qwen-32B：减少约 $22.4\%$
- DeepSeek-Llama-70B：减少约 $17.9\%$

代码任务中减少约 $16.1\%\sim19.1\%$。因此这篇论文实验上真正比较突出的结果是 $\boxed{\text{准确率小幅提升}+\text{推理长度明显降低}}$，说明 Soft Thinking 的优势更偏向**用更短的推理过程达到相同或略高的正确率**。
## 3.4 为什么 Greedy CoT 不行：单纯“缩短”并不是关键

论文还专门比较了 Greedy CoT，Greedy CoT 每一步都选概率最大的 token，因此也可能减少生成长度。但是它在不少任务上准确率明显下降。例如 DeepSeek-R1-Distill-Qwen-32B 在代码任务上 $83.23\% \rightarrow 72.70\%$，下降超过 $10$ 个百分点。

这说明 Soft Thinking 的效果并不能简单归因于“推理变短”。作者认为关键在于 Soft Thinking 保留了多个候选 token 的概率信息，而 Greedy decoding 很早就把所有可能性压缩成唯一一个 token。因此 $\boxed{\text{效率提升并不等于简单剪短 CoT}}$，而是和“软分布表示”有关。
## 3.5 可视化说明：不确定时分布更散，确定时接近 one-hot

论文 Figure 4 对 Soft Thinking 每一步的 token 概率分布进行了可视化。作者发现，在探索阶段 $p_t$ 比较分散，也就是多个 token 同时有较高概率。例如 $P(A)=0.4,\quad P(B)=0.3,\quad P(C)=0.2$，说明模型还在多个方向之间犹豫。

而在明确计算步骤中，概率分布会逐渐变得接近 $[0,0,\dots,1,\dots,0]$，也就是接近 one-hot。

论文据此认为 Soft Thinking 在不确定阶段能够保留多种候选语义，而在确定阶段又可以逐渐收敛到具体 token。这个现象支持了作者“连续 concept token 可以进行软路径探索”的解释。
## 3.6 消融实验：直接用 hidden state 基本失败

作者还专门比较了三种连续输入方式：
1. **Training-free COCONUT**

直接把上一层 hidden state 当成下一步输入。结果在 AIME 2024 和 LiveCodeBench 上 $\text{Accuracy}=0$，而且输出一直达到最大生成长度。这说明**不经过训练，直接把 hidden state 塞回输入 embedding 位置并不可行**。这正好支持前面所说的 $\text{hidden state space}\neq\text{input embedding space}$
あるじさま，给您重写成完整、顺一点的版本。🌿

2. **Average Embedding**

第二种方法不使用 hidden state，而是先取概率最高的 top-$n$ 个 token，然后直接对它们的 embedding 做普通平均 $\tilde e = \frac{1}{n} \sum_{i=1}^{n}e_i$，这种方法已经回到了 input embedding 所在的空间，因此比直接使用 hidden state 稍微好一些。但是结果仍然很差。

在表 3 中：
- $\text{AIME 2024 Accuracy}=6.66\%$
- $\text{LiveCodeBench Accuracy}=7.49\%$

同时生成长度依然非常大，接近最大生成长度。这说明**只把多个 token embedding 混在一起还不够**，因为普通平均会把所有候选 token 当成同等重要，因此模型原本的**置信度信息被丢掉了**。

3. **Soft Thinking：概率加权 Embedding**

Soft Thinking 则不是普通平均，而是按照模型原本预测的 token 概率进行加权 $\tilde e = \sum_i p_i e_i$。例如 $P(A)=0.8,\quad P(B)=0.15,\quad P(C)=0.05$，那么 $\tilde e = 0.8e(A)+0.15e(B)+0.05e(C)$。这样既保留了多个 token 的信息，也保留了模型对这些候选的相对置信程度。

实验结果明显更好，不使用 Cold Stop 时：
- $\text{AIME 2024}=73.33\%$
- $\text{LiveCodeBench}=56.98\%$

加入 Cold Stop 后进一步达到：
- $\text{AIME 2024}=83.33\%$
- $\text{LiveCodeBench}=62.72\%$
## 3.7 普通平均 embedding 也不行，概率权重很重要

作者还测试了 $\frac{1}{n}\sum_{i=1}^{n}e_i$，也就是直接把 top-$n$ token embedding 做普通平均，结果虽然比直接 hidden state 好一点，但准确率仍然很低，而且输出特别长。因此实验说明并不是“随便把多个 embedding 平均一下”就能获得 Soft Thinking 的效果。Soft Thinking 需要保留 $p_i$，也就是每个 token 原本的概率权重 $\sum_i p_i e_i$，概率分布本身包含了模型对不同候选的置信程度。
## 3.8 Cold Stop 很重要，否则容易出现 generation collapse

消融实验中，去掉 Cold Stop 后：
- 输出长度明显增加；
- 容易发生重复；
- 长推理过程中更容易 collapse。

加入 Cold Stop 后，整体生成长度下降，同时准确率提高。    

作者认为原因是 Soft Thinking 输入的是训练阶段没有见过的连续 concept token，因此推理时间越长 $\text{OOD risk}\uparrow$，模型越容易进入异常区域。Cold Stop 就是在模型已经低熵、高置信度时提前结束，从而避免继续在 OOD 空间中漂移。
## 3.9 局限
### 3.9.1 Concept Token 本身是 OOD 输入

这是这篇论文最重要的局限，也是作者自己明确承认的。模型在预训练和微调阶段见到的是 $e(t_1),e(t_2),\dots$，也就是正常 token embedding。但 Soft Thinking 推理时输入的是 $\tilde e=\sum_k p_k e(k)$，模型训练时并没有真正见过这种概率加权的 embedding。因此 $\boxed{\text{Soft Thinking 的连续输入天然存在 OOD 问题}}$。

这可能导致：
- 不稳定；
- 重复；
- generation collapse；
- 长推理性能恶化。

Cold Stop 只能缓解这个问题，并没有从根本上解决。作者明确提出，未来可以通过训练阶段主动让模型接触 concept token 来改善这一问题。
### 3.9.2 所谓“多路径推理”实际上只是近似混合

Soft Thinking 宣称能够隐式探索多条推理路径。但它实际上并没有真正分别维护 $A\rightarrow A_1$、$B\rightarrow B_1$、$C\rightarrow C_1$ 这些独立路径。它做的是 $0.5e(A)+0.3e(B)+0.2e(C)$ 把它们混成一个向量。因此 $\boxed{\text{Soft Thinking 并不是真正的显式多路径搜索}}$，而只是用线性近似 $\mathbb E[f(t)]\approx f(\mathbb E[t])$ 来近似多路径求和。

而神经网络本身是非线性的，所以一般并不能保证 $f\left(\sum_i p_i e_i\right)=\sum_i p_i f(e_i)$，因此“一个混合 embedding 能完整保留多条独立推理路径”这个说法实际上是有限的。
### 3.9.3 不同思路可能被“平均掉”

如果两个候选代表完全不同的推理方向 $z_A$ 和 $z_B$，Soft Thinking 会直接形成 $\alpha z_A+(1-\alpha)z_B$。但这个中间状态可能既不是思路 A，也不是思路 B。

例如：
- $\text{路径 A：使用代数}$
- $\text{路径 B：使用几何}$

直接平均以后得到的表示，不一定对应一个有意义的第三种推理方式。这也是 Soft Thinking 与真正维护多个独立 latent candidate 的一个根本区别。
## 3.10 总结

这篇论文的实验可以概括为 $\boxed{\text{准确率稳定小幅提升}+\text{推理长度明显降低}}$，实验也支持了三个重要结论：
1. **概率加权 embedding 比直接 hidden state 或普通 embedding 平均更有效；**
2. **Cold Stop 对稳定连续推理非常重要；**
3. **Training-free 连续推理可行，但 OOD 是核心瓶颈。**

但它还没有解决一个更根本的问题：

$\boxed{\text{如何既保留连续 latent reasoning 的效率，又真正保留多个彼此独立的推理候选}}$
# 四、对我的启发（对我的研究有什么值得参考的）
## 4.1 连续推理是可行的，但不应该只满足于“一个混合向量”

Soft Thinking 最直接证明了一件事：中间推理不一定非要经过离散 token，它可以把词表概率分布转成 $\tilde e_t=\sum_i p_i e_i$，再把这个连续表示送回模型继续推理。实验说明，即使不额外训练，这种连续推理也可以正常工作，并且在部分任务上同时降低推理长度、略微提高准确率。 

这支持了我研究中的一个基本前提 $\boxed{\text{推理状态可以脱离显式自然语言 token}}$，但 Soft Thinking 的问题在于，它最终仍然只有**一个连续状态**：$\tilde e_t$，即使这个状态由多个候选 token 混合而成，本质上仍然把多个可能性压缩进同一个向量。

因此，对我的启发不是简单复制 Soft Thinking，而是进一步考虑：$Z_t=\left\{z_t^{(1)},z_t^{(2)},\dots,z_t^{(K)}\right\}$，也就是同时保留多个彼此独立的潜在候选，而不是过早平均成一个状态。
## 4.2 “加权平均”虽然高效，但可能造成候选坍缩

Soft Thinking 的关键操作是 $0.6e(A)+0.3e(B)+0.1e(C)$，它的好处非常明显：只需要进行一次后续计算，就能把多个候选信息压进一个连续表示。但问题也正好在这里，如果：
- $A=\text{代数解法}$
- $B=\text{几何解法}$

那么 $0.5z_A+0.5z_B$ 不一定代表一种有意义的新解法，它可能既不像 A，也不像 B。而论文所谓“用一个连续状态近似多条路径”，依赖的是一阶线性近似：$\mathbb E[f(t)]\approx f(\mathbb E[t])$，作者自己也只是把它作为对完整路径求和的一种近似，而不是严格等价。
这对我的启发是 $\boxed{\text{不要过早把不同思路平均掉}}$，更合理的方向可能是 $z_A,\ z_B,\ z_C$ 先独立演化，在必要的时候再：
- 竞争；
- 通信；
- 筛选；
- 合并。

而不是从第一步开始 $z=\alpha z_A+\beta z_B+\gamma z_C$，这正好给“多候选 latent reasoning”留下了空间。
## 4.3 可以把“概率分布”从 token 层提升到 latent candidate 层

Soft Thinking 的一个很好借鉴的思想是**不要只保存最终选择，还要保存不确定性**。它保存 $p(t)$ 而不是只保存 $\arg\max_t p(t)$，这让我可以进一步考虑：

- Soft Thinking 是 $p(\text{token})$
- 我的方法可以变成：$q_1(z),\ q_2(z),\dots,q_K(z)$，或者至少为每个 latent candidate 保留 $(z_i,w_i)$。其中 $w_i$ 表示该候选当前的可信度。这样就不只是 $\text{候选 1、候选 2、候选 3}$，而是 $(z_1,0.6),\quad(z_2,0.3),\quad(z_3,0.1)$。但与 Soft Thinking 不同的是，**权重存在，不代表马上把三个候选求平均**。它们仍然可以保持独立。

这样既吸收了 Soft Thinking 的“保留概率信息”，又避免了它的“直接混合”。
## 4.4 Cold Stop 提供了“什么时候停止思考”的一个重要信号

Soft Thinking 使用概率分布的熵 $H(p)=-\sum_i p_i\log p_i$，来判断当前模型是否已经足够确定。

低熵意味着 $p\approx[0,\dots,1,\dots,0]$，也就是模型已经非常确定，于是可以提前结束推理。这个思想对我的方法很有参考价值，但我不一定只把熵用于 $\text{Stop / Continue}$，还可以把它扩展成 $\boxed{\text{什么时候需要更多候选、什么时候需要候选交流}}$。

例如低不确定性，如果 $H_t<\tau_1$，说明某个候选已经比较确定 $\rightarrow \text{减少通信 / 合并 / 提前结束}$；高不确定性，如果 $H_t>\tau_2$，说明当前思路不确定 $\rightarrow \text{生成更多候选 / 开启通信 / 增加探索}$

于是熵不再只是 $\text{什么时候停}$，而可以变成 $\boxed{\text{控制整个 latent reasoning 计算资源的门控信号}}$。这和我原本考虑的 entropy gating 很接近。

注：**把熵提供给一个可训练的控制器，由它决定下一步怎么分配计算**。例如 $a_t\sim\pi_\theta(H_t,\Delta H_t,\text{候选分歧},\text{剩余预算})$，其中动作 $a_t$ 可以是：继续推理、增加候选、开启候选间通信，或者停止。这样，截图中的两个固定阈值就可以换成学到的决策策略。

但要先明确**计算哪个分布的熵**：

- **候选内部的 token 熵**：这个候选对下一步预测有多犹豫。
- **候选权重的熵**：多个候选之间是否已有明显胜者。权重需要先归一化。

这两个信号不同：几个候选可能各自非常确定，却给出互相冲突的答案。因此，**低熵不等于正确，高熵也不一定说明通信有用**；控制器还应该看到候选之间的分歧。

训练时，可以奖励“答对且少花资源” $R=\text{答案正确性}-\lambda\,\text{计算成本}-\mu\,\text{通信成本}$，不要直接把“降低熵”作为奖励，否则它可能学会变得自信，却没有提高正确率。已有方法覆盖了部分思路：[Soft Thinking](https://proceedings.neurips.cc/paper_files/paper/2025/file/f7396d1c54d51416958d63e285377103-Paper-Conference.pdf) 用连续低熵触发停止，[SwiReasoning](https://arxiv.org/abs/2510.05069) 用熵趋势控制显式与潜在推理的切换。你的方案需要验证的是：**学到的控制器，能否比固定阈值更准确地决定何时增加候选、何时通信，并在相同预算下提高效果。**
## 4.5 OOD 问题说明：真正做 latent reasoning，最好最终还是要训练

Soft Thinking 最大的限制之一就是模型训练时只见过 $e(\text{token})$，但推理时突然输入 $\sum_i p_i e_i$ 这种连续混合 embedding。因此模型实际上是在处理一种训练时没有见过的输入，也就是 OOD。

作者明确承认 Cold Stop 只能缓解这个问题，并没有真正解决；未来一个重要方向就是在训练阶段主动让模型接触 concept token。

- Soft Thinking 的目标是 $\boxed{\text{training-free}}$，但我的目标不必被这个约束限制。如果真正希望 latent state $z_t$ 成为模型天然能够理解和操作的推理单位，那么更合理的思路可能是 $\boxed{\text{训练模型本身适应 latent reasoning}}$，而不是训练结束以后再强行把新的连续表示塞进去。

也就是说：Soft Thinking 更像是在证明“**这种方向哪怕不训练都有一点效果**”，
而对我来说，这反而意味着**如果专门训练 latent dynamics，潜力可能更大**。
## 4.6 可以借鉴它解决 hidden state 与 embedding 不匹配的方法

COCONUT 类方法直接做 $h_t\rightarrow\text{next input}$，而 Soft Thinking 做 $h_t\rightarrow p_t\rightarrow\sum_i p_i e_i$。通过词表概率分布，把 hidden state 重新投影到模型熟悉的 embedding 空间。这一点对我的架构设计也有启发，如果以后有 $z_t^{(i)}$ 需要在不同模块、候选甚至不同 reasoning agent 之间传递，不能默认 $z_A$ 和 $z_B$ 天然处于完全兼容的表示空间。可能需要一个显式的 $\boxed{\text{communication / projection interface}}$。

例如：$m_{A\rightarrow B}=G(z_A)$ 而不是 $z_A$ 原封不动塞给 B。这也是以后设计“候选之间通信”时一个值得提前注意的问题。
## 4.7 Soft Thinking 给出了一个很好的 baseline

如果以后我要验证自己的多候选 latent reasoning，那么 Soft Thinking 很适合作为 baseline。

可以比较：
- $\text{普通 CoT}$
- $\text{Soft Thinking 单混合状态}$
- $\text{多候选 latent，无通信}$
- $\text{多候选 latent + 通信}$
- $\text{多候选 latent + 动态剪枝/合并}$

这样实验真正回答的问题就是**保留多个独立 latent candidate，是否真的比把所有候选压缩成一个概率加权状态更好**？这比单纯证明“latent reasoning 比 CoT 好”更具体，也更容易形成明确的研究问题。
# 4.8 对我的研究最重要的启发

Soft Thinking 已经走到了 $\text{多个 token 候选}\rightarrow\text{概率加权}\rightarrow\boxed{\text{一个连续状态}}$，而我可以考虑继续往前走，$\text{多个潜在候选}\rightarrow\boxed{z_t^{(1)},z_t^{(2)},\dots,z_t^{(K)}}$。然后研究：$\text{何时探索}$、$\text{何时通信}$、$\text{何时竞争}$、$\text{何时合并}$、$\text{何时剪枝}$、$\text{何时停止}$。因此，这篇论文对我最有价值的地方并不是它的“概率加权 embedding”本身，而是它暴露出了一个很自然的下一步问题：$\boxed{\text{如何在保持连续 latent reasoning 效率的同时，避免把多个不同思路过早平均掉？}}$。这其实比“再设计一种加权平均”更接近您现在真正可以往论文方向推进的问题。
