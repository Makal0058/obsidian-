# 一、研究背景（前人做到哪一步）

## 1.1 显式思维链（Explicit CoT）

传统大语言模型主要依靠显式思维链（Chain-of-Thought，CoT）完成复杂推理，即通过生成自然语言或数学符号，将复杂问题分解为多个中间步骤，最终得到答案。在此基础上，研究者提出了多种改进方法：

1. **Self-Consistency（自一致性）**：采样多条推理路径，通过聚合结果提高答案的可靠性。
2. **Tree-of-Thought（思维树）**：将推理过程扩展为树状搜索结构，探索不同的中间推理路径。
3. **Least-to-Most（由简到繁）**：将复杂问题拆分为较简单的子问题，再逐步求解。
4. **工具增强推理**：在推理过程中调用外部工具或环境，提高复杂任务的求解能力。

这些方法提高了模型的推理能力，但大多依赖离散 Token 生成。

**其核心局限在于：**

- **信息损失**：模型每次生成一个具体 Token，会将完整的概率分布压缩为单个离散选择，舍弃其他潜在可能性。
- **表达限制**：中间推理必须经过自然语言或符号表达，受到离散词表的约束。
- **计算开销**：复杂问题通常需要生成较长的推理链，增加推理 Token 数量和计算成本。
- **过早收敛**：模型可能在推理早期选择某条路径，从而失去探索其他潜在解法的机会。

因此，研究者开始探索不依赖离散文本生成的隐空间推理方法。
## 1.2 隐空间推理（Latent Reasoning）

隐空间推理尝试让模型直接在连续向量空间中进行中间计算，而不必将每一步推理转换为自然语言 Token。与显式 CoT 相比，隐空间推理具有两个潜在优势：

1. **更高的表示带宽**：连续隐状态可以承载比单个离散 Token 更丰富的信息。
2. **保留推理不确定性**：连续表示可以保留多个潜在推理方向的信息，而不必立即选择唯一的离散结果。

现有隐空间推理方法主要分为两类。

1. **需要训练的方法（Training-required）**

这类方法通过预训练、微调或蒸馏，使模型学习如何利用连续隐状态进行推理。代表性研究包括：
- **Coconut**：通过课程学习，逐渐使用连续隐状态替代显式推理步骤。
- **CODI**：通过蒸馏显式推理轨迹，帮助模型学习隐式推理表示。

这些方法证明了连续隐状态能够参与多步推理，但通常需要额外训练。对于参数量较大的推理模型，训练成本较高。

2. **免训练的方法（Training-free）**

这类方法不修改模型参数，而是在推理阶段直接操作模型的隐状态、Embedding 或概率分布。其中具有代表性的是 **Soft Thinking**。

传统自回归生成通常选择一个具体 Token 作为下一步输入，而 Soft Thinking 根据完整的 Token 概率分布，构造加权平均 Embedding：$\tilde{e}_t=\sum_{v\in V}p_t[v]e(v)$

其中：
- $V$：词表。
- $p_t[v]$：第 $t$ 步生成 Token $v$ 的概率。
- $e(v)$：Token $v$ 对应的 Embedding。
- $\tilde{e}_t$：所有 Token Embedding 的概率加权表示。

随后，模型将 $\tilde{e}_t$ 作为下一步输入，而不是选择某一个离散 Token。这种方法保留了下一 Token 概率分布中的部分信息，使模型能够在连续空间中继续推理，同时避免重新训练模型。

但需要注意，**Soft Thinking 只是使用一个连续向量混合不同 Token 的信息，并没有显式维护多条相互独立的推理路径。**
## 1.3 现有隐空间推理的主要问题

尽管隐空间推理具有更高的信息表示能力，但作者指出，完全依赖连续隐空间进行推理仍存在两个重要问题。
### 1.3.1 推理难以收敛

隐空间表示可以保留多种潜在推理方向，但保留更多信息并不一定意味着更准确的推理。由于预训练语言模型通常没有专门学习如何长期处理连续隐状态输入，因此，纯隐空间推理可能产生分布偏移。

随着推理持续进行：

- 概率质量可能分散在多种潜在推理方向上。
- 不确定信息和噪声不断积累。
- 模型难以形成单一、稳定且高置信度的解题路径。
- 推理结果可能逐渐偏离正确方向，降低最终准确率。

因此，**隐空间推理虽然有利于探索，但缺少可靠的收敛机制。**

### （2）过度思考（Overthinking）

隐空间推理不需要生成可读的中间文本，但这并不意味着它一定更加高效。

模型仍然可能在连续空间中反复计算，产生冗余的推理步骤。

对于已经具有足够信息的问题，继续推理可能：

- 增加不必要的计算开销。
- 延长推理过程。
- 引入额外噪声。
- 降低 Token 使用效率。

因此，仅仅将显式 Token 替换为连续表示，并不能从根本上解决过度思考问题。
## 1.4 SwiReasoning 的研究切入点

针对上述问题，作者认为显式推理与隐空间推理具有互补性：
- **隐空间推理偏向探索（Exploration）**：在模型不确定时保留更多潜在推理信息。
- **显式推理偏向利用与收敛（Exploitation）**：在模型置信度提高时形成更加确定的推理路径。

因此，作者提出一个核心问题：**能否根据模型推理过程中的不确定性，动态决定何时使用隐空间推理、何时使用显式推理，并控制推理何时结束？**

由此，SwiReasoning 将预测概率分布的信息熵作为切换依据，同时利用切换次数控制机制抑制过度思考。与需要额外训练隐空间推理能力的方法不同，SwiReasoning 主要通过修改推理阶段的生成策略，实现两种推理模式的动态切换，不需要更新模型参数。

**研究背景总结：**

前人已经证明，隐空间推理能够利用连续表示保留更丰富的信息，Soft Thinking 等方法甚至可以在不重新训练模型的情况下进行连续推理。但纯隐空间推理仍然面临推理漂移、难以收敛和过度思考等问题。

SwiReasoning 的研究重点不是提出一种全新的隐状态表示，而是通过动态切换显式与隐式推理模式，在探索能力、推理准确率和计算效率之间实现更好的平衡。
# 二、创新点与贡献

## 2.1 基于信息熵的动态推理模式切换（Dynamic Mode Switching）

**核心创新：不再要求模型始终采用单一推理模式，而是根据推理过程中的不确定性，动态切换显式 CoT 与隐空间推理。**

作者认为，两种推理模式具有互补性：
- **隐空间推理（Latent Thinking）**：保留更多潜在推理信息，适合不确定性较高、需要探索多种可能性的阶段。
- **显式推理（Explicit Thinking）**：通过生成离散 Token，逐渐形成确定的推理路径，适合置信度提高、需要收敛的阶段。

为了实现自动切换，作者使用下一个 Token 预测分布的信息熵衡量不确定性：$H_t=-\sum_{v\in V}p_t[v]\log p_t[v]$。其中，$p_t[v]$ 表示第 $t$ 步预测 Token $v$ 的概率。

同时，作者引入参考熵 $\bar H$，用于记录当前推理块（Thinking Block）的参考不确定性。参考熵在推理块开始时初始化，并在模式切换时更新。

**切换规则：**
1. **Latent $\to$ Explicit**：当 $H_t<\bar H$ 时，说明预测熵降低，模型的预测分布更加集中，切换到显式推理，以促进收敛。
2. **Explicit $\to$ Latent**：当 $H_t>\bar H$ 时，说明预测熵升高，模型的不确定性增加，允许重新进入隐空间探索。
这一机制使模型能够在推理过程中动态调整探索与收敛的比例，而不必预先固定显式推理和隐空间推理的长度。

**防止频繁切换：Switch Window**

如果仅依靠瞬时熵变化，模型可能频繁切换推理模式，导致推理不稳定。因此，作者引入驻留窗口（Dwell Window），要求模型在当前模式下持续一定步数，才能切换到另一种模式。具体采用非对称设计：
- **Latent $\to$ Explicit**：允许立即切换，避免模型在置信度恢复后继续进行不必要的隐空间探索。
- **Explicit $\to$ Latent**：需要满足最小驻留步数，避免短暂的熵波动导致模型过早重新进入隐空间。
论文实验中，显式推理切换到隐空间的窗口通常设置为 512 步。**创新意义：** 将隐空间推理中的探索与收敛问题转化为一种由模型预测不确定性驱动的动态控制问题。
## 2.2 通过思考信号混合实现推理模式衔接（Thinking-Related Signal Mixing）

作者不仅控制推理模式的切换时机，还设计了切换过程中连续表示的调整机制。SwiReasoning 沿用 Soft Thinking 的概率加权 Embedding：$\tilde e_t=\sum_{v\in V}p_t[v]e(v)$

在此基础上，作者利用推理模型已有的特殊 Token（例如 `<think>` 和 `</think>`），在模式切换时对连续表示进行混合。
### 2.2.1 进入隐空间推理

当模型从显式推理切换到隐空间推理时，将连续表示与 `<think>` 的 Embedding 混合：$\tilde e_{t^*}\leftarrow\alpha_{t^*}\tilde e_{t^*}+(1-\alpha_{t^*})e_{\langle\mathrm{think}\rangle}$。目的是引导模型进入新的思考阶段。
### 2.2.2 退出隐空间推理

当模型从隐空间推理切换到显式推理时，将连续表示与 `</think>` 的 Embedding 混合：$\tilde e_{t^\dagger}\leftarrow\beta_{t^\dagger}\tilde e_{t^\dagger}+(1-\beta_{t^\dagger})e_{\langle/\mathrm{think}\rangle}$，目的是引导模型结束当前隐空间探索，向明确的推理路径或答案生成过渡。

其中，$\alpha_t$ 和 $\beta_t$ 是动态变化的混合系数，作者根据当前生成位置与最大生成长度调整其取值。这一机制不需要修改模型架构，也不需要训练额外的切换网络。

**创新意义：** 利用模型已经学习过的思考标记，在连续表示层面引导推理模式转换，从而促进隐空间推理与显式推理之间的衔接。
## 2.3 基于切换次数的过度思考抑制（Switch Count Control）

**核心创新：将隐空间到显式推理的切换节点作为潜在的提前回答时机，通过限制切换次数控制推理预算。**

传统推理通常受到最大 Token 长度限制，但固定 Token 预算无法充分适应不同问题的难度。对于简单问题，模型可能在已经得到正确答案后继续思考；对于困难问题，又可能需要更长的探索过程。

作者认为，每次从隐空间切换到显式推理，都意味着模型完成了一个探索阶段，并开始尝试收敛。因此，这些切换节点可以作为提前生成答案的检查点。

作者定义：
- $C_t$：截至当前步骤，已完成的 Latent $\to$ Explicit 切换次数。
- $C_{\max}$：允许的最大切换次数。
- $B$：强制进入答案生成后允许继续生成的 Token 预算。
具体设计了两个触发机制：
### 2.3.1 收敛触发（Convergence Trigger）

当切换次数达到预设预算的一半，并且尚未超过最大切换次数时：$\frac{1}{2}C_{\max}\le C_t\le C_{\max}$，系统尝试注入 `</think>`，引导模型结束思考并生成答案。这一操作旨在促进模型提前收敛，而不是保证模型一定完成推理。
### 2.3.2 终止触发（Termination Trigger）

当下一次 Latent $\to$ Explicit 切换使计数超过最大预算时：$C_t>C_{\max}$，系统注入答案生成前缀：
`</think>` $\to$ `The final answer is`。随后最多允许模型继续生成 $B$ 个 Token，用于输出最终答案。这一机制能够限制无休止的推理模式切换，减少冗余计算。

**创新意义：** 不仅控制隐空间推理与显式推理之间如何切换，还进一步控制模型何时停止思考，使推理过程能够适应不同的计算预算。

注：SwiReasoning 不允许模型无限地在隐空间推理和显式推理之间来回切换。当切换次数达到一定数量时，就开始催促模型给出答案；如果还不结束，就强制它回答。
## 2.4 免训练的即插即用框架（Training-Free Framework）

SwiReasoning 的另一项重要贡献，是将上述机制整合为无需额外训练的推理框架。与 Coconut、CODI 等需要训练的隐空间推理方法不同，SwiReasoning：
1. 不需要修改模型参数。
2. 不需要重新预训练或微调。
3. 不需要额外训练辅助解码器或监督网络。
4. 通过修改推理阶段的生成策略，实现显式与隐空间推理的动态切换。

作者在附录中指出，该框架可以作为 Hugging Face `model.generate()` 接口的一种替代实现。不过，免训练并不意味着没有额外的运行开销。模型仍然需要计算概率分布、信息熵，并执行模式切换控制。

**创新意义：** 降低了将隐空间推理机制应用到现有大规模推理模型上的训练成本，使方法更容易迁移到不同模型。
## 2.5 实验验证与主要贡献

作者在四种推理模型上验证了 SwiReasoning：
- Qwen3-1.7B
- Qwen3-8B
- Qwen3-32B
- DeepSeek-R1-Distill-Llama-8B
实验覆盖 11 个基准，涉及数学、STEM、编程与一般推理任务。

主要结果包括：

1. **提高推理准确率**

在无严格 Token 预算限制时，SwiReasoning 相较于标准 CoT，在不同模型和任务设置下取得约 1.8～3.1 个百分点的平均准确率提升。

例如，在 Qwen3-8B 上：

- GSM8K：95.60% $\to$ 96.06%
- MATH500：96.00% $\to$ 98.40%
- GPQA Diamond：59.60% $\to$ 61.11%
- AIME 2024：75.83% $\to$ 79.17%
- AIME 2025：67.50% $\to$ 70.00%

作者观察到，困难推理任务通常能够获得更明显的准确率改善。

2. **提高 Token 使用效率**

在受限 Token 预算下，论文报告相较标准 CoT，平均 Token 效率提升约 57%～79%。这里的 Token 效率主要依据单位生成 Token 对应的准确率衡量，不等同于实际运行速度或 GPU 计算效率。

3. **验证跨模型与跨任务的有效性**

实验表明，SwiReasoning 不仅适用于数学推理，也能够改善编程、多跳问答和常识推理任务的表现。这说明动态结合隐空间与显式推理，具有一定的跨任务适用性。
## 2.6 核心贡献总结

这篇论文的核心贡献可以概括为三个方面：

1. **提出动态显隐推理切换机制**：利用 Token 预测熵的变化，在隐空间探索和显式推理收敛之间进行动态切换。
2. **提出切换次数控制机制**：利用推理模式切换节点引导模型提前回答，并限制最大切换次数，缓解过度思考。
3. **验证免训练混合推理框架的有效性**：在不同模型规模和多个推理领域中，实现准确率与 Token 使用效率的共同改善。

**总体而言，SwiReasoning 的主要创新并不在于设计新的隐状态表示或训练目标，而在于为现有隐空间推理方法引入基于不确定性的动态控制机制，从而协调探索、收敛与推理预算。**

# 三、实验与结论（数据说明了什么、有什么局限性）
## 3.1 实验设置
### 3.1.1 实验模型

作者选择了四种不同规模的大语言模型：
- Qwen3-1.7B
- Qwen3-8B
- Qwen3-32B
- DeepSeek-R1-Distill-Llama-8B

所有实验均不修改原模型参数，而是在推理阶段应用 SwiReasoning 的动态模式切换机制。
###  3.1.2 实验数据集

实验覆盖 11 个基准测试，主要包括四个领域：

| 领域   | 数据集                                           |
| ---- | --------------------------------------------- |
| 数学推理 | GSM8K、MATH500、AIME 2024、AIME 2025             |
| 科学推理 | GPQA Diamond                                  |
| 代码生成 | HumanEval、LeetCode-Contest、MBPP、LiveCodeBench |
| 综合推理 | 2WikiMultihopQA、CommonsenseQA                 |
###  3.1.3 对比方法

作者设置了三种基线方法：

1. **CoT（显式思维链）**：使用采样策略生成完整的显式推理过程。
2. **CoT Greedy（贪心显式思维链）**：每一步选择概率最大的 Token。
3. **Soft Thinking（软思考）**：通过概率加权 Embedding，在连续表示空间中进行推理。

通过对比，作者希望验证动态结合显式推理与隐空间推理，是否优于始终采用单一模式。
### 3.1.4 评价指标

主要使用以下指标：

- **Pass@1（单次回答准确率）**：衡量模型生成一次答案时的正确率。
- **Pass@k（多次采样成功率）**：衡量生成 $k$ 个候选答案时，至少一个正确的比例。
- **Token Efficiency（Token 使用效率）**：衡量给定生成长度下的准确率与 Token 消耗之间的关系。
- **推理延迟与计算量**：在附录中进一步使用实际运行时间和 TFLOPs 评价效率。

需要注意，论文中的 Token 效率不是简单的推理速度，而是基于准确率与生成 Token 数量构造的相对指标。
## 3.2 主要实验结果

### 3.2.1 动态切换能够提高推理准确率

| Qwen3-32B | 82.38% | 84.30% | +1.92 |
| DeepSeek-R1-Distill-Llama-8B | 59.46% | 61.26% | +1.80 |
以上提升均为百分点，结果为五个数学与科学推理基准的平均值。

**数据说明：**

1. SwiReasoning 在四种模型上都提高了平均准确率，说明动态结合显式推理与隐空间推理具有一定有效性。
2. 这种改进不仅出现在小模型上，在 32B 模型上同样存在，说明方法具有一定的跨模型适用性。
3. 准确率提升整体较为有限，并不是大幅提高模型的推理能力。
###  3.2.2 困难任务中的提升更加明显

以 Qwen3-8B 为例：

| 数据集 | CoT | SwiReasoning | 提升 |
|---|---|---|---|
| GSM8K | 95.60% | 96.06% | +0.46 |

对于 GSM8K 这种模型已经具有较高准确率的数据集，进一步提升的空间较小。而 AIME 等需要较长推理过程的困难任务，通常能够从动态推理模式切换中获得更明显的收益。

作者认为，困难任务包含更多不确定的中间步骤，因此交替进行隐空间探索与显式收敛可能更加有效。但这只是与实验结果一致的一种解释，不能证明所有困难问题都需要更多隐空间探索。
### 3.2.3 提高 Token 使用效率

论文图 2 和图 4 比较了不同推理预算下的准确率。

主要发现：
- SwiReasoning 在受限 Token 预算下，通常能够比标准 CoT 更早获得较高准确率。
- 论文摘要报告，平均 Token 使用效率提升约 57%～79%。
- 在部分设置中，推理预算越紧张，相对效率优势越明显。
- 对于较简单的问题，提前结束冗余推理能够节省大量 Token。
- 对于 AIME 等困难问题，过早结束推理可能导致明显的准确率损失。

作者还在附录 C.2 中测试了实际计算开销。以 Qwen3-8B 在 MATH500 上的结果为例：

| 目标准确率 | TFLOPs 改善 | 实际推理速度 |
|---|---|---|
| 90% | 计算量减少至 CoT 的约 1/1.36 | 约快 1.36 倍 |
| 80% | 计算量减少至 CoT 的约 1/2.18 | 约快 2.17 倍 |
**数据说明：**

SwiReasoning 的效率优势不只是 Token 数量上的变化。在附录测试的特定模型和任务上，实际推理延迟和浮点计算量也有所下降。

不过，不能将这些结果直接推广到所有模型、硬件与推理任务。

作者在 Qwen3-8B 上测试了 Pass@k，采样次数范围为 1～64。
实验发现：
- AIME 2024：SwiReasoning 在 $k=13$ 时达到其最高准确率，而 CoT 需要 $k=46$。
- AIME 2025：SwiReasoning 在 $k=16$ 时达到其最高准确率，而 CoT 需要 $k=22$。

**数据说明：**

SwiReasoning 在这些实验中能够以更少的候选采样达到自身最高准确率，说明动态推理模式切换可能提高单次采样的有效性。但这不等于模型内部确实维护了多条独立的隐空间推理路径。
## 3.3 消融实验
### 3.3.1 隐空间推理是否真的有效？

附录 C.6 专门测试了移除隐空间模式后的效果。作者比较了完整 SwiReasoning 与保留预算控制、但禁用隐空间推理的版本。实验模型为 Qwen3-1.7B。

| 方法 | 平均准确率 | 平均生成长度 |
|---|---|---|
| 不使用 Latent | 36.64% | 936 |
| 完整 SwiReasoning | 39.88% | 907 |

完整方法的平均准确率提高了 3.24 个百分点，平均生成长度减少约 3.10%。

**数据说明：**
实验支持隐空间模式本身确实提供了额外收益，而不只是切换次数控制机制带来了改善。但实验仍然无法确定，性能提升具体来自保留更多 Token 分布信息、改变推理轨迹，还是其他机制。
### 3.3.2 切换窗口的影响

作者测试不同的显式推理驻留窗口。

| 窗口大小 | 平均准确率 |
|---|---|
| 64 | 61.06% |
| 128 | 60.98% |
| 256 | 61.26% |
| 512 | **62.88%** |
| 1024 | 61.74% |

**数据说明：**

切换窗口过小，模型可能频繁进入隐空间，破坏尚未完成的显式推理过程。切换窗口过大，则可能使模型无法及时重新进入隐空间进行探索。实验中 512 表现最好，但这是经验超参数，并不能保证适合所有模型和任务。

附录 C.7 进一步表明，完全取消驻留窗口会使 GSM8K 与 MATH500 的平均准确率从默认设置的 91.92% 降至 89.10%。说明防止频繁模式振荡具有实际意义。
### 3.3.3 `<think>` 与 `</think>` 混合的影响

论文第 9 页表 2 分别测试了进入隐空间和退出隐空间时的 Embedding 混合系数。

**进入隐空间：**

| 混合系数 $\alpha_0$ | 平均准确率 |
|---|---|
| 0.0 | 59.31% |
| 0.5 | 60.97% |
| 0.9 | 61.36% |
| 1.0 | **61.85%** |

当 $\alpha_0=1$ 时，实际上完全不使用 `<think>` Embedding 混合。该设置在这组独立消融中获得了最高平均准确率。因此，实验并未证明进入隐空间必须依赖 `<think>` 向量。

**退出隐空间：**

| 混合系数 $\beta_0$ | 平均准确率 |
|---|---|
| 0.0 | 39.00% |
| 0.5 | 61.55% |
| 0.7 | **62.88%** |
| 1.0 | 60.04% |

退出隐空间时，适度混入 `</think>` 的 Embedding 能够取得更好的结果。此外，附录 C.7 直接测试了完全取消思考信号混合：在 GSM8K 和 MATH500 上，平均准确率由 91.92% 降至 91.32%。

**数据说明：**

进入与退出隐空间时，对特殊 Token 的依赖并不对称。进入隐空间时，混合 `<think>` 的收益不明显；退出隐空间时，适度混合 `</think>` 更有利于模型表现。但是，这一结果也说明 SwiReasoning 的模式衔接部分仍然依赖原模型对特殊思考 Token 的既有学习。
### 3.3.4 最大切换次数的影响

附录 C.7 的表 10 研究了最大切换次数与准确率、生成长度之间的关系。在 Qwen3-1.7B 的 MATH500 测试中：

|---|---|---|
| 4 | 72.40% | 1189 |
| 8 | 81.00% | 2222 |
| 20 | 87.80% | 3597 |
| 32 | 89.20% | 4186 |
| 44 | 91.80% | 4602 |
| 无限制 | 93.00% | 4924 |

**数据说明：**

1. 减少最大切换次数能够显著降低生成长度。
2. 切换次数限制过于严格，会明显损害准确率。
3. 更大的推理预算通常有利于提高性能，但同时增加 Token 开销。

这一实验说明，固定切换次数控制实际上是在准确率和推理成本之间进行权衡。它能够防止过度思考，但并不能保证自动找到每个问题最合适的计算预算。
### 3.3.5 隐空间模式是否增加了探索多样性？

附录 C.1 对 Qwen3-8B 在 MATH500 上的预测分布进行分析。

结果如下：

|---|---|---|
| 平均预测熵 | 0.444 | 0.213 |
| Top-5 候选 Embedding 平均余弦相似度 | 0.118 | 0.185 |
隐空间模式的平均预测熵约为显式模式的 2.08 倍，同时候选 Token 的平均表示相似度更低。

**数据说明：**

隐空间模式下，下一 Token 预测分布更加分散，候选表示也具有更明显的差异。但这些指标并不能证明模型已经真正形成多条独立、具有因果作用的推理路径。因此，这些结果支持隐空间模式具有更强的候选分布探索特征，而不是直接证明其实现了多路径推理。
## 3.4 研究局限性
### 3.4.1 动态控制仍然依赖人为规则

SwiReasoning 使用预测熵的变化决定模式切换，并通过固定驻留窗口限制切换频率。这些机制都由人工设计，不是通过训练自主学习得到的。

模型不能直接根据任务结果优化切换策略，也没有训练一个与 Transformer 内部计算共同优化的控制模块。这是该方法在动态计算控制方面的局限。
### 3.4.2 推理预算缺乏自主适应机制

作者通过最大切换次数控制过度思考，但不同问题的实际计算需求并不相同。简单问题可能只需要少量推理步骤，困难问题则需要更长的探索。固定切换次数无法确保每个样本都得到最合适的计算预算。

论文的窗口消融和切换次数消融也表明，推理性能对这些超参数较为敏感。因此，自适应推理预算仍是值得研究的问题。
### 3.4.3 隐空间表示依赖 Soft Thinking

SwiReasoning 并没有设计新的隐空间计算架构，而是沿用 Soft Thinking 的概率加权 Embedding。该方法将 Token 预测分布映射为一个连续向量，继续作为模型输入。

这种方式虽然能够保留预测分布中的部分信息，但不能保证不同候选推理方向被独立计算。论文也没有证明混合向量内部形成了明确分工的多个推理状态。

因此，SwiReasoning 的主要贡献属于推理阶段的动态控制，而不是新的隐状态学习机制。
### 3.4.4 预测熵不等于推理进展

论文以预测熵变化作为模型不确定性的近似信号。但预测熵主要反映下一 Token 分布的集中程度，并不能直接衡量推理步骤是否有效。

因此，熵降低并不必然意味着推理已经取得进展，熵升高也不一定意味着模型需要重新探索。论文展示了熵驱动切换策略的经验有效性，但没有证明预测熵是衡量推理进展的充分指标。
### 3.4.5 对严格约束推理的适应性有限

作者在附录 C.4 中给出了一个三维空间最短路径问题的失败案例。模型理解了将三维表面展开为二维平面的总体思路，但没有严格遵守只能沿天花板和墙面移动的约束，最终得出错误距离。

作者认为，连续概率混合可能模糊某些严格的几何和拓扑约束。这说明隐空间探索并非始终有利，尤其是在需要精确保持离散约束的任务中。
### 3.4.6 缺乏可训练推理控制机制的对比

论文主要比较显式 CoT、Soft Thinking 与 SwiReasoning，并对切换窗口、信号混合、最大切换次数等进行消融。但没有系统研究通过监督学习或强化学习训练控制模块是否能够替代人工规则，也没有比较将控制模块直接嵌入 Transformer 后的效果。

因此，不能根据本文结果判断固定熵规则与可学习神经网络控制器哪一种更优。这属于尚未验证的研究方向，而不是论文已经证明的缺陷。
## 3.5 总体结论

SwiReasoning 证明了，在不重新训练大语言模型的情况下，动态结合显式推理与隐空间推理，可以在多个任务中改善推理准确率与 Token 使用效率。

实验主要支持以下结论：

1. **动态结合显式与隐空间推理具有实用价值。** 相比始终使用单一推理模式，SwiReasoning 在多个模型和数据集上取得了更高准确率。
2. **隐空间探索与显式收敛具有互补性。** 隐空间模式能够保留更分散的预测信息，而显式模式有助于形成确定的生成路径。
3. **推理预算控制能够缓解过度思考。** 限制切换次数可以减少生成长度，但过度限制会损害准确率。
4. **现有切换策略仍依赖经验规则。** 信息熵、驻留窗口、混合系数和最大切换次数均需要人工设计或选择。
5. **连续表示的有效性存在边界。** 概率混合有利于探索，但可能不利于某些需要严格保持离散约束的任务。

**总结：SwiReasoning 的核心贡献不是让模型学会一种全新的隐空间计算能力，而是证明了对显式推理和隐空间推理进行动态调度，可以改善已有模型的准确率与推理效率。其主要研究空间在于如何将人工设计的切换策略进一步发展为可训练、自适应、能够与 Transformer 内部计算协同优化的机制。**
# 四、对我的启发

## 4.1 从人工规则控制转向可学习的推理控制
### 4.1.1 SwiReasoning 的启发

SwiReasoning 证明了动态结合隐空间推理（Latent Reasoning）与显式推理（Explicit CoT），能够在多个任务上改善推理准确率和 Token 使用效率。但它的控制机制主要依赖人工设计的规则：
1. 根据预测熵变化决定推理模式。
2. 使用固定驻留窗口防止模式频繁切换。
3. 使用最大切换次数限制过度思考。
4. 使用特殊 Token 的 Embedding 混合引导模式转换。

这些规则并非由神经网络通过训练自主学习得到。论文的消融实验表明，切换窗口、混合系数和最大切换次数都会影响模型表现，不同问题也可能需要不同的计算预算。因此，一个值得研究的问题是：**能否让神经网络自主学习推理模式的切换策略，而不是依赖固定的信息熵阈值、驻留窗口和切换次数？**
### 4.1.2 引入可训练的推理模块

考虑直接修改 Transformer 架构，在原有注意力模块与前馈网络之外，增加一个可训练的推理模块（Trainable Reasoning Module，TRM）。这一模块不应只是附加在 Transformer 外部的控制器，而应参与原模型内部的隐藏状态计算，并通过反向传播更新参数。

对于现代预归一化 Transformer，可以考虑在原有子层之后增加一条可训练的残差计算分支：$h'=h+\operatorname{Attention}(\operatorname{LN}(h))$，$h''=h'+\operatorname{FFN}(\operatorname{LN}(h'))$，$h_{\mathrm{out}}=h''+g_\phi(h'')\odot U_\phi(\operatorname{LN}(h''))$。
其中：

- $U_\phi$：新增的隐状态更新网络。
- $g_\phi$：可学习的门控函数。
- $\phi$：新增模块的可训练参数。
- $h_{\mathrm{out}}$：经过新增模块更新的隐藏状态。

由于新增模块的输出会继续参与 Transformer 后续计算，因此任务损失能够通过计算图反向传播到新增模块。**研究重点不仅是学习什么时候切换推理模式，还包括学习如何改变隐状态，使新增模块真正参与推理计算。**

需要注意，在 Transformer Block 内加入可训练模块，并不自动意味着模型具备多轮隐空间推理能力。若希望在不生成中间 Token 的情况下反复思考，还需要设计内部循环计算机制。
## 4.2 不依赖 Soft Thinking，直接在隐藏状态空间中推理
### 4.2.1 Soft Thinking 的局限

SwiReasoning 沿用 Soft Thinking 的概率加权 Embedding：$\tilde e_t=\sum_{v\in V}p_t[v]e(v)$。该方法将多个候选 Token 的 Embedding 加权平均，形成一个连续向量作为下一步输入。

它能够保留部分概率分布信息，但存在两个值得研究的问题：

1. 多个候选 Token 的加权表示并不等于多条相互独立的推理路径。
2. 这种连续表示仍然由词表概率分布构造，尚未证明能够充分利用隐藏状态空间的表达能力。

因此，我不希望将概率加权 Embedding 作为新架构的主要隐空间推理方式。
### 4.2.2 直接学习隐状态演化

可以考虑让新增推理模块直接对 Transformer 隐状态进行计算：$\Delta z_t=U_\phi(z_t,m_t,x)$，$z_{t+1}=z_t+g_t\odot\Delta z_t$。

其中：
- $z_t$：当前隐空间推理状态。
- $m_t$：内部推理记忆。
- $U_\phi$：可训练隐状态更新网络。
- $g_t$：控制隐状态更新的门控信号。

该公式是一种待验证的架构设计，并非 SwiReasoning 原论文提出的方法。这样，隐空间推理不再依靠输出词表概率的加权平均，而是直接学习连续状态之间的变换。如果采用内部循环计算，则可以让模型执行：$z_0\to z_1\to z_2\to\cdots\to z_T$，在完成内部推理后，再通过语言模型输出层生成最终答案。

这里必须解决隐状态如何保持输入上下文信息、内部循环如何使用注意力，以及计算何时终止等问题。
## 4.3 通过监督学习与强化学习训练推理模块
### 4.3.1 使用 SIM-CoT 式逐步监督

SwiReasoning 不需要训练，但它也没有为隐空间推理提供额外的逐步监督信号。可以借鉴 SIM-CoT 的方法，在训练阶段引入辅助解码器，将每一步隐状态与对应的显式推理步骤联系起来。

逐步监督损失可以表示为：$\mathcal L_{\mathrm{step}}=-\sum_{k=1}^{K}\log p_\psi(s_k\mid z_k)$。

其中：
- $z_k$：第 $k$ 步隐状态。
- $s_k$：对应的显式推理步骤。
- $p_\psi$：辅助解码器。

这一损失可以通过反向传播影响隐状态更新网络，促使不同推理步骤保留有意义的信息。不过，SIM-CoT 式监督并不能直接保证隐状态是正确的，也不能保证模型真正利用这些隐状态完成推理。因此，还需要最终答案监督，以及删除、替换或干预隐状态的实验。

另外，逐步文本监督可能限制隐空间表示的自由度，因此可以将其作为辅助训练目标，而不必永久要求每个隐状态严格对应一个自然语言步骤。
### 4.3.2 使用强化学习训练模式切换

SwiReasoning 通过预测熵和人工阈值决定切换模式。可以考虑让新增推理模块输出一个可训练的动作策略：$\pi_\phi(a_t\mid z_t,m_t)$，其中动作空间初步设计为：$a_t\in\{\mathrm{Latent},\mathrm{Explicit},\mathrm{Stop}\}$。

三个动作分别代表：
- **Latent**：继续执行隐空间计算。
- **Explicit**：切换到显式 Token 推理。
- **Stop**：结束中间推理，进入最终答案生成。

需要强调，Stop 是新架构的拟议动作，并不是 SwiReasoning 显式提出的第三种推理模式。由于离散动作选择不可直接求导，可以使用策略梯度等强化学习方法更新控制网络参数。奖励函数可以设计为：

$R=\mathbb{1}[\hat y=y]-\lambda C_{\mathrm{compute}}-\mu N_{\mathrm{switch}}$

其中：

- 第一项奖励最终答案正确。
- 第二项惩罚计算成本。
- 第三项惩罚不必要的模式切换。

这样，控制模块需要在准确率和计算效率之间学习决策，而不是简单模仿预先规定的熵阈值。
## 4.4 利用 KL 散度约束动态推理过程
### 4.4.1 使用 KL 散度分析模式振荡

SwiReasoning 采用固定驻留窗口和最大切换次数，防止模型在两种推理模式之间反复切换。一种可能的改进是将 KL 散度（Kullback–Leibler Divergence，相对熵）作为推理状态变化的特征。

例如，比较相邻推理阶段的预测分布：$D_t=D_{\mathrm{KL}}(P_t\parallel P_{t-1})$，当 $D_t$ 较小时，表示预测分布变化较小；当 $D_t$ 较大时，表示预测分布变化明显。

但需要注意，KL 散度不能单独保证停止推理：
- 分布稳定可能只是模型陷入了固定思路。
- 分布持续变化也不一定表示有效探索。
- 如果模式不断振荡，KL 散度可能持续较大。

因此，更合理的方案是让控制网络同时接收隐藏状态、KL 散度变化、模式历史和剩余计算预算，自主学习停止策略。
### 4.4.2 使用 KL 正则化稳定控制策略

在强化学习阶段，可以使用 KL 正则化限制当前策略与参考策略之间的差异：$\mathcal L_{\mathrm{KL}}=D_{\mathrm{KL}}(\pi_\phi(\cdot\mid z_t)\parallel\pi_{\mathrm{ref}}(\cdot\mid z_t))$。其中参考策略可以是上一训练阶段保存的控制器。这样可以减小策略更新幅度，降低训练不稳定的风险。

但 KL 正则化并不能自动防止模式坍缩。如果参考策略本身过度偏向 Explicit，过强的正则化反而可能限制 Latent 模式的探索。因此，需要结合策略熵、动作使用比例与最终任务表现进行评估。

**KL 正则化主要用于稳定策略优化；KL 分布变化可以作为推理控制信号。两者应当区分**。同时，应保留最大计算预算作为硬性约束，避免推理过程无法终止。
## 4.5 采用三阶段训练策略
### 4.5.1 第一阶段：冻结原始 Transformer

冻结原模型参数 $\theta$，只训练新增推理模块参数 $\phi$。$\phi^*=\arg\min_\phi\mathcal L(\theta_0,\phi)$。目标是让新增模块初步学习隐状态更新及推理策略。可以采用 SIM-CoT 式逐步监督、最终答案监督，以及必要的控制策略初始化训练。
### 4.5.2 第二阶段：冻结新增模块

固定已经训练的新增模块 $\phi^*$，解冻原始 Transformer 参数：$\theta^*=\arg\min_\theta\mathcal L(\theta,\phi^*)$，目标是让 Transformer 逐渐适应新增模块产生的隐空间表示。

为了减少预训练能力退化，可以采用较小学习率、LoRA 或参考模型约束。
### 4.5.3 第三阶段：联合优化

最后同时训练 Transformer 和新增模块：$(\theta^{**},\phi^{**})=\arg\min_{\theta,\phi}\mathcal L(\theta,\phi)$，可以将逐步监督损失、最终答案损失与强化学习目标结合起来。

完整训练过程为：$\text{冻结 Transformer}\to\text{训练新增模块}\to\text{冻结新增模块}\to\text{训练 Transformer}\to\text{联合优化}$

这是拟议的训练流程，并非 SwiReasoning 已验证的方法。需要通过实验比较三阶段训练、直接联合训练和短周期交替训练，判断分阶段训练是否确实带来稳定性和性能收益。
